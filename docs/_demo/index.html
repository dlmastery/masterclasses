  1. The model reads the instruction and the history. It returns text or a function call.
  2. The runner executes the tool. The tool returns a result.
  3. The result goes into the event history and the session state.
  4. The loop stops when the model returns a final answer.

Your first agent in 12 lines

agent.py

from google.adk.agents import Agent

def get_weather(city: str) -> dict:
    """Returns the current weather for a city."""
    if city.lower() == "london":
        return {"status": "success", "report": "Cloudy, 15 °C"}
    return {"status": "error", "message": f"No data for {city}"}

root_agent = Agent(
    name="weather_agent",
    model="gemini-2.5-flash",
    instruction="Answer weather questions. Use get_weather.",
    tools=[get_weather],
)

from rank_bm25 import BM25Okapi
import numpy as np

def rrf(rankings, k=60):
    scores = {}
    for ranking in rankings:
        for rank, doc_id in enumerate(ranking):
            scores[doc_id] = scores.get(doc_id, 0) + 1 / (k + rank + 1)
    return sorted(scores, key=scores.get, reverse=True)

Best practices

  • Fuse ranks (RRF, k=60) when score scales differ.
  • Measure recall@k on a labelled set before and after.
  • Do not add raw BM25 and cosine scores.
  • Do not tune k on the test set.
