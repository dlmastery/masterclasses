Interview · Foundations

Choose RAG for facts, tuning for behaviour, and check recall first

When do you choose RAG over fine-tuning or one long prompt?
Facts → RAG. Behaviour → fine-tune. A small, static, one-ACL corpus fits one cached prompt. Only RAG filters per user at query time.
Your RAG bot gives wrong answers. What do you check first?
Recall@k on a golden set. No gold chunk in the top-k: no fix downstream. Then split retrieval failures from reasoning failures.
Can an agent with grep and file tools replace the index?
Not at scale. BM25 overtakes a file-system agent above ~10M corpus tokens. Rank first, then let the agent reason.

Interview · Chunking

Chunking answers need an eval, a token budget and an update cost

How do you choose a chunk size?
Sweep 2-3 sizes in embedder tokens on the golden set. Pick by recall@k. Cut at real headings.
Why can you afford Contextual Retrieval on every chunk, and how does it fail silently?
Prompt caching: the document is the cached prefix. Under 512 tokens on Haiku 5.5, nothing is cached and no error is returned.

ingest_acme.py
import hashlib, sys
import chromadb
from docling.chunking import HybridChunker
from docling.document_converter import DocumentConverter
from docling_core.transforms.chunker.tokenizer.huggingface import HuggingFaceTokenizer
from sentence_transformers import SentenceTransformer
EMBED = "Qwen/Qwen3-Embedding-0.6B"           # chunk with the embedder's own tokenizer
model = SentenceTransformer(EMBED)
chunker = HybridChunker(tokenizer=HuggingFaceTokenizer.from_pretrained(
    model_name=EMBED, max_tokens=512))
col = chromadb.PersistentClient(path="./acme_index").get_or_create_collection(
    name="acme_qwen3", embedding_function=None)    # we pass our own vectors
doc = DocumentConverter().convert(sys.argv[1]).document
src, fresh = doc.origin.filename, {}
for ch in chunker.chunk(dl_doc=doc):
    text = chunker.contextualize(chunk=ch)    # heading path + text; no LLM call
    fresh[hashlib.sha256(f"{EMBED}|{text}".encode()).hexdigest()[:32]] = text
old = set(col.get(where={"source": src}, include=[])["ids"])   # empty on run 1
new = [c for c in fresh if c not in old]
gone = sorted(old - fresh.keys())             # chunks of the previous version
if new:
    vecs = model.encode_document([fresh[c] for c in new], normalize_embeddings=True)
    col.upsert(ids=new, embeddings=vecs, documents=[fresh[c] for c in new],
               metadatas=[{"source": src}] * len(new))
if gone: col.delete(ids=gone)                 # stale text must not be cited
print(f"chunks={len(fresh)} reused={len(fresh) - len(new)} "
      f"embedded={len(new)} deleted={len(gone)}")

Embeddings and vector indexes

Memory maths, recall against exact search, and silent failures from model swaps and filters.

This chapter drills the index questions: memory maths, ANN parameters, embedding-model migration and filtered search. ANN means approximate nearest neighbour: the index scores some vectors instead of all of them, and you measure what it misses. Walk the build one click at a time. Step 1: layer 1 holds a few vectors with long links, so the search makes big jumps first. Step 2: it drops to layer 0, which holds every vector, and continues from the same vector. Step 3: the greedy walk scores every neighbour of the current node and moves to the closest one; the counter counts these distance computations, not only the hops. Step 4: no neighbour is closer, so the search returns the top-3, while exact search scores all 40. Recall@k is the share of the exact top-k (from brute force) that the ANN index also returns. The graph is illustrative: a real index has millions of nodes and 16 to 64 links per node. Analogy: HNSW is a motorway to the right district, then local streets to the right house. A likely question: "How do you know the approximate index is good enough?" Measure recall@k against an exact flat index on a query sample.

import faiss, numpy as np
rng = np.random.default_rng(7)
N, D, K = 100_000, 256, 10
centers = rng.standard_normal((1_000, D)).astype(np.float32)
noise = lambda n, s: s * rng.standard_normal((n, D)).astype(np.float32)
xb = centers[rng.integers(0, 1_000, N)] + noise(N, 0.3)   # clustered
xq = xb[rng.choice(N, 500, replace=False)] + noise(500, 0.1)
faiss.normalize_L2(xb); faiss.normalize_L2(xq)     # cosine == IP

flat = faiss.IndexFlatIP(D); flat.add(xb)          # exact baseline
_, gt = flat.search(xq, K)
hnsw = faiss.IndexHNSWFlat(D, 32, faiss.METRIC_INNER_PRODUCT)  # M=32
hnsw.hnsw.efConstruction = 80                      # default 40
hnsw.add(xb)
for ef in (16, 64, 128, 256):
    p = faiss.SearchParametersHNSW(efSearch=ef)    # per query
    _, I = hnsw.search(xq, K, params=p)
    r = np.mean([len(set(a) & set(g)) / K for a, g in zip(I, gt)])
    print(f"efSearch={ef:<4} recall@10={r:.3f}")

# eval_gate.py (fixed) -- block a PR when faithfulness OR judge coverage drops
import asyncio, json, math, os, sys
from openai import AsyncOpenAI
from ragas.llms import llm_factory
from ragas.metrics.collections import Faithfulness

MIN_ROWS, MAX_NAN_RATE = 50, 0.05
client = AsyncOpenAI(api_key=os.environ["GEMINI_API_KEY"],
                     base_url="https://generativelanguage.googleapis.com/v1beta/openai/")
faith = Faithfulness(llm=llm_factory("gemini-3.8-flash", provider="openai",
                                     client=client, max_tokens=4096))
base = json.load(open("baseline.json"))                    # {"faithfulness": 0.91}
rows = [json.loads(line) for line in open("runs/candidate.jsonl", encoding="utf-8")]
assert len(rows) >= MIN_ROWS, f"only {len(rows)} rows: too few for a reliable gate"

async def main():
    results = await asyncio.gather(*(faith.ascore(user_input=r["question"], response=r["response"],
                                     retrieved_contexts=r["retrieved_contexts"]) for r in rows))
    vals = [x.value for x in results if not math.isnan(x.value)]
    nan_rate = 1 - len(vals) / len(results)
    score = sum(vals) / len(results)                        # release gate: a NaN row counts as 0
    print(f"faithfulness={score:.3f} base={base['faithfulness']:.3f} coverage={1 - nan_rate:.0%}")
    blocked = score < base["faithfulness"] - 0.03 or nan_rate > MAX_NAN_RATE
    sys.exit(1 if blocked else 0)

asyncio.run(main())
