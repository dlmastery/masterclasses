import asyncio
from google.adk.runners import InMemoryRunner
from refund_agent.agent import root_agent

APP = "refund_agent"   # match the folder name

async def main() -> None:
    runner = InMemoryRunner(agent=root_agent, app_name=APP)
    await runner.run_debug(
        "Is order A-1001 refundable? Changed my mind.",
        verbose=True)
    # ... run_async loop and isolation: next slides
    await runner.close()

One line gives in-memory session, artifact and memory services.

run_debug() creates a session and prints each event. It is "for debugging and experimentation only".

Close the runner. It is also an async context manager.

InMemoryRunner bundles an in-memory session service, artifact service and memory service in one line. Its app_name must equal the folder name, or ADK warns "App name mismatch detected" and later sessions are not found. Step 2: run_debug gets or creates the session debug_session_id for user debug_user_id, wraps your string as a user message, prints every event and returns the list of events; its own docstring says it is for debugging and experimentation only. Step 3: await runner.close() closes plugins; you can also use async with. Analogy: run_debug is the test bench with the cover off; run_async, on the next slide, is the engine in the car. Likely question: "Why does my output show [Calling tool: ...] lines?" That is verbose=True, which prints tool calls and results.
