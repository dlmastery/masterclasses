ADK 2.0 building blocks

After this chapter you can build, run and inspect a first ADK 2.0 app. You can also explain what the App, the Runner, the session, the state and the plugins do.

Repo google/adk-python README
This chapter gives students the parts list of ADK 2.0. Press once: three kinds of node come in. An Agent calls a model, a Function is plain Python, and a Workflow is a whole graph. Press again: all three sit on one BaseNode rail, because in 2.0 every one of them is a node with the same contract. Analogy: LEGO bricks of different shapes that all use the same studs. Likely question: "Is a Workflow an agent?" Answer: yes, the ADK Go 2.0 announcement says "A graph is an agent", so you can nest one Workflow inside another.
