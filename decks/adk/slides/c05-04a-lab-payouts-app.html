def kyc_lookup(node_input: str) -> dict:
  open("side_effects.log", "a").write(f"kyc_lookup {node_input}\n")
  return {"payee": node_input, "risk": "medium"}
def analyst_review(node_input: dict):   # hand-off pause
  yield RequestInput(message=f"Approve payout to {node_input['payee']} "
                             f"(risk {node_input['risk']})? yes/no")

Lab 5B is the Acme payout desk, and it needs no API key because there is no LLM node. Install google-adk 2.13.0 and run every command from labs/adk/lab5b-payouts-durable. Walk the four focus steps. kyc_lookup appends one line to side_effects.log; that line is our proof later that a finished node is replayed, not run again. analyst_review is a plain function that yields a RequestInput, so ADK wraps it as a function node with the default hand-off pattern: the analyst's reply becomes its output, and that output is the node_input of pay. The edges chain the three nodes. Last, the App turns on ResumabilityConfig and the Runner keeps the session in payouts.db with SqliteSessionService, so a second process can read it. Think of side_effects.log as the stamp on a parcel: if a parcel has two stamps, somebody sent it twice. A likely question: "Why a file and not a print?" A print goes away with the process; the file survives the restart and lets you count real executions.
