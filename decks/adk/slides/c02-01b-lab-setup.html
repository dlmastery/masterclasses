This is the run-it-Monday slide for Lab 2. Create one virtual environment, install google-adk 2.13.0 (Python 3.11 or newer), and export two variables: GOOGLE_GENAI_USE_ENTERPRISE=0 selects an AI Studio key, 1 selects Agent Platform, the former Vertex AI. Walk the folder tree in three clicks. First, claims/ holds plain Python scripts; they run outside adk web, so they do not read a .env file and you must export the variables. Second, agents/claims_api/ is the App folder; its __init__.py says "from . import agent", and adk run, adk web and adk api_server load it and do read its .env. Third, rest_calls.sh holds the curl calls for step 3; PowerShell breaks the single-quoted JSON, so use Git Bash or WSL on Windows. Analogy: this folder is the workbench; every later slide picks up one tool from it. A likely question: "Can I use Python 3.10?" No: google-adk 2.13.0 requires 3.11, even though the quickstart page still says 3.10.
