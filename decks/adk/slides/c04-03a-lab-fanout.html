This is step 1 of the Acme back-office lab: one claim, three independent checks, one decision. Make a folder claim_checks with an __init__.py that says "from . import agent" and the agent.py from labs/adk/c04-claim-checks; the file has no model call, so it runs offline with no API key and no .env. Walk the four focus steps: each check is async and sleeps 0.3, 0.5 or 0.2 seconds to stand in for a policy database, a fraud model and an estimator; the tuple inside the edges chain is what makes the fan-out, and every branch gets the same dict from parse_claim; the JoinNode is the barrier that fires once, after all three; max_concurrency=3 is only an optional cap on graph-scheduled nodes ("None or <= 0 means unlimited"), not what creates the branches. Think of the JoinNode as the claims supervisor who signs only when all three reports are on the desk. A likely question: "Can a branch be an LLM agent?"
