ADK injects one delegation tool per sub-agent, named after it. Do not set mode on the root agent.

chat (default, the 1.x behaviour): the sub-agent takes the user thread. It returns only by a manual transfer_to_agent. This is a handoff (OpenAI Agents SDK: handoffs=).

task: the sub-agent may ask the user a clarifying question, then returns automatically through finish_task. A task agent must be a leaf. Codelab level L3b shows the pause and the resume.

single_turn: no user turns, automatic return, can run in parallel. Each parallel sub-agent runs in its own session branch and cannot see its peers' events. This is agent-as-tool (Agent.as_tool(), ADK AgentTool).

The collaboration docs say task mode is disabled in graph workflows in Python 2.0.0. The codelab notes that a static task-mode node works on 2.5.0, and 2.5 and 2.12 add task-mode resume. Test on your version.

from google.adk import Agent

weather_agent = Agent(
    name="weather_checker", mode="single_turn",
    tools=[get_weather, user_info, geocode_address])
flight_agent = Agent(
    name="flight_booker", mode="task",
    input_schema=FlightInput, output_schema=FlightResult,
    tools=[search_flights, book_flight])
root = Agent(name="travel_planner",
             sub_agents=[weather_agent, flight_agent])

Collaborative workflows keep the 1.x idea of a coordinator with sub-agents, but every sub-agent now declares how it talks to the user. Step 1, chat: the default. The coordinator transfers control, and the user then talks to the sub-agent directly; control comes back only by another transfer. Step 2, task: the flight booker asks one clarifying question, for example a date, and then returns a typed FlightResult through finish_task. Step 3, single_turn: the weather checker never talks to the user, so the coordinator can call two copies in parallel. Step 4 is the summary table and the version caveat. Analogy: chat is passing the phone to a colleague; task is asking a colleague to call the customer once and report back; single_turn is sending a colleague an email and waiting for the answer. Interview question: "Handoff or agent-as-tool?" Ask who owns the user-facing thread. Use a handoff when routing itself is the job; use agent-as-tool when the coordinator must keep control and context.
