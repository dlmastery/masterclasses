Every dependent LLM step and every handoff costs reliability

Success = pn. At 95% per step, 16 dependent steps leave 44%.

  • Do not chain dependent LLM steps that a function can do.
  • Pass policy facts as typed state. Free-text handoffs lost 56-85%.
  • Keep delegation trees flat. Each tier keeps about 0.57 of the findings.
arXiv 2609.01660 arXiv 2609.17464
The third rule is about the steps between agents. Each dependent LLM step is a coin that lands right with probability p, and you need every coin in a row to land right, so success is p to the power n. Even at 95% per step, 16 dependent steps leave 44%; at 99% you keep 85%. arXiv 2609.01660, How Fast Do Agents Rot, found agent success decays geometrically with step count and every model nears zero within 16 dependent steps. So do not chain dependent LLM steps that a function can do: each deterministic node removes one factor p. Second, pass policy facts as typed state with output_schema and output_key: free-text handoffs lost the fact in 56 to 85% of runs with a small model in Governance at the Boundary. Third, keep delegation trees flat: Decomposition Buys Integrity, arXiv 2609.17464, measured that each delegation tier keeps about 0.57 of the findings, and two tiers only overtake a flat tree at 403 findings for equal spend; MS-Eval, 2610.22869, adds that narrow domain subagents work best and that for closed models delegation raised cost and lowered performance. A likely question: "Does a bigger model fix the decay?" Per-step reliability rises with scale but stays below 1, so the number of dependent steps still sets the ceiling.
