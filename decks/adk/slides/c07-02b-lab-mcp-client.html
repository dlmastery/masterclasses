labs/adk/lab7-acme-refunds/consumer/agent.py
from google.adk.agents import LlmAgent
from google.adk.tools.mcp_tool import (
    McpToolset, StreamableHTTPConnectionParams)

root_agent = LlmAgent(
    name="cs_frontline", model="gemini-3.5-flash",
    instruction="For any refund question call the refund_agent tool.",
    tools=[McpToolset(
        connection_params=StreamableHTTPConnectionParams(
            url="http://127.0.0.1:8090/mcp",
            sse_read_timeout=120.0),   # the whole run is one call
        tool_filter=["refund_agent"])],  # tool name = agent name
)

The client connects to the server's /mcp URL.

The remote agent run is one call_tool. Raise the read timeout.

The filter keeps one tool. Its name is the agent's name.

Now the other side of step 1: an Acme front-line agent consumes the refund agent as an MCP tool. Run adk run consumer in terminal 3 while terminal 1 keeps the MCP server on port 8090. McpToolset connects with StreamableHTTPConnectionParams to the /mcp URL. The whole remote agent run, with its own model calls and its lookup_order call, happens inside one call_tool, so raise sse_read_timeout to 120 seconds or the client gives up first. tool_filter keeps only the refund_agent tool; the tool name is the agent's name. The consumer's model sends one request string, and the reply text comes back as the tool result. Think of a vending machine again: the consumer presses one button and waits for the product. A likely question: "Can Claude Desktop or another MCP host call it?" Yes, any MCP host that speaks streamable HTTP can; the consumer agent is just one example.
