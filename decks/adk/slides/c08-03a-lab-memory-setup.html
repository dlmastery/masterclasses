run it Monday · labs/adk/c08-memory-bank/ · GCP + billing
$ pip install "google-adk[gcp]==2.13.0" \
    "google-cloud-agentplatform>=2.2,<3"
$ gcloud services enable aiplatform.googleapis.com
$ gcloud auth application-default login
$ export GOOGLE_CLOUD_PROJECT=my-proj
$ export GOOGLE_CLOUD_LOCATION=us-central1
$ export AGENT_ENGINE_ID=$(python create_bank.py)
labs/adk/c08-memory-bank/create_bank.py
import os
import agentplatform

client = agentplatform.Client(
    project=os.environ["GOOGLE_CLOUD_PROJECT"],
    location=os.environ["GOOGLE_CLOUD_LOCATION"])
runtime = client.runtimes.create()   # billed resource
print(runtime.api_resource.name.split("/")[-1])
Memory Bank is the one part of this chapter that needs Google Cloud: it lives inside an Agent Runtime in your project, which is a billed resource. Run the five setup commands once: pin google-adk with the gcp extra and google-cloud-agentplatform 2.2 or later, enable the API, log in with application default credentials, and set the project and a regional location. Press once: agentplatform.Client takes the project and location. Press again: client.runtimes.create() makes an empty Agent Runtime; it is the same call that adk deploy agent_engine uses. Press again: print the last part of the resource name, and the shell exports it as AGENT_ENGINE_ID. If you see "The installed Agent Platform SDK exposes Client.agent_engines rather than Client.runtimes", an old SDK is installed: upgrade google-cloud-agentplatform. Think of the runtime as a filing cabinet you rent: create it once, and return it when you finish. A likely question: "Can I test without the cloud?" adk web without a memory URI uses InMemoryMemoryService, but it forgets everything on restart, as a gotcha slide shows. Delete the runtime in the console when you finish.
