Lab 3.4 is the last step of the Acme support desk: the triage router as reviewable YAML. To keep the YAML short, Triage has one label and three routes, with no how_to branch and no priority rule. The folder labs/adk/c03-triage-yaml holds three YAML files and agent.py. Press through and watch each YAML reference fly to the node it creates. Step 1: START and .agent.intake; a leading dot resolves relative to the YAML folder's package, so it is triage_yaml.agent.intake, wrapped as a function node. Step 2: classify.yaml is a separate agent file, so legal can review the prompt diff alone. Step 3: .agent.route_ticket, then the second edge names route_ticket as a bare word, which means a node defined by an earlier edge. Step 4: the three route keys. Every Triage.label value has its own key, including other, so no label can go unmatched. The Python constant DEFAULT_ROUTE is the string "__DEFAULT__", but no official YAML sample uses that key yet, so this lab maps each label explicitly. Analogy: the YAML is the wiring diagram on the wall and agent.py is the parts bin. Next: the prompt file and the Python file.
