Gotcha Context cache

cached=None on every turn: a timestamp moved the prefix

Symptomcached=None on turns 2 and 3 too. CauseA timestamp or {state} sits in static_instruction, or the prefix is under 4,096 tokens. FixKeep the prefix byte-stable. Put dynamic text in instruction.
handbook_app.py · fixed
agent = Agent(name="handbook_agent",
    model="gemini-3.5-flash",
    static_instruction=types.Content(   # byte-stable
        role="user", parts=[types.Part(text=HANDBOOK)]),
    instruction="Customer: {customer_name}. Now: {now}.")
# {now} comes from session state, set before each turn
The first Acme failure looks like "the cache does nothing": cached=None on every turn, not only on turn 1. Press once: the gotcha card. Press again: the animation shows why: a timestamp inside static_instruction makes the prefix different on every turn, so the cache key changes, A, B, C, and every request misses; when the chip moves into instruction, which ADK sends as user content after the prefix, the prefix stays A, so turns 2 and 3 hit. Turn 1 still misses, because caching starts on turn 2, so a single-turn eval never shows a hit. Press again: the fixed code keeps the handbook alone in static_instruction and moves {now} into instruction. Think of the cache like a photocopy master: write the date on the master and you need a new master every time. The other cause is size: the prefix must reach 4,096 tokens on Gemini 3 and 2,048 on Gemini 2.5. A likely question: "Where does {now} come from?" Write it into session state before each turn, the same way {customer_name} is set when the session is created.
