import pathlib, sys
from google.adk.tools.mcp_tool import McpToolset, StdioConnectionParams
from mcp import StdioServerParameters
SERVER = pathlib.Path(__file__).parent / "claims_server.py"
claims_tools = McpToolset(
    connection_params=StdioConnectionParams(
        server_params=StdioServerParameters(
            command=sys.executable, args=[str(SERVER)]),  # same venv
        timeout=10.0),                          # default 5.0 s
    tool_filter=["get_claim", "approve_claim"],  # no purge_claim
    tool_name_prefix="claims",                  # claims_get_claim
)

This is step 2 of the Acme claims desk: the agent connects to the claims MCP server from step 1 and gets only the tools it needs. Step 1: use StdioConnectionParams so you can set the timeout to 10 seconds; its default is 5.0 seconds, and a bare StdioServerParameters has no timeout at all. sys.executable starts the server in the agent's own virtual environment, so mcp is importable; a bare "python" on Windows often finds a different interpreter. Step 2: tool_filter matches the server's original names, so purge_claim stops at the bar and never reaches the model. Step 3: tool_name_prefix renames the rest, and the model calls claims_get_claim and claims_approve_claim; two servers can no longer collide on a name. Step 4: the model's list holds 2 of the 3 server tools. Think of a hotel key card: it opens two doors, and each door has a name plate. A likely question: "Does the filter use the prefixed name?" No, the filter runs first on the server's names, and ADK adds the prefix afterwards.
