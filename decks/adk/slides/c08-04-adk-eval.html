Codelab Evaluating Agents with ADK Docs adk.dev: evaluation criteria
Begin with the why: an agent takes a path, so we grade the path and the answer. Steps 1 to 3 run the same actual trajectory A, X, B, C through the three match types. EXACT fails because of one harmless extra lookup. IN_ORDER passes because the expected calls still come in order. ANY_ORDER passes even after the calls shuffle. Tell students: EXACT only for strict, regulated flows; the over-strict trajectory is the most common eval mistake. Step 4 opens an evalset file, and each part lights with the criterion that reads it. Step 5 is the codelab: its config sets trajectory 0.8 and ROUGE 0.5, and the CLI line runs it; the last line runs only two cases. Step 6 shows two gate fixes from the CHANGELOG and two ways to test your verifiers. Analogy: a driving test grades the route and the parking, not only that the car arrived. Likely question: "Why is my green CI meaningless?" Before 2.10 a run with zero cases passed; before 2.13 the CLI exit code did not show failure.
