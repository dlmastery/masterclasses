Gotcha Compaction

Compaction triggers come in pairs: half a pair is a ValueError

SymptomValueError: token_threshold and event_retention_size must be set together. CauseOnly one half of a trigger pair is set. FixSet both fields. Import from google.adk.apps.app.
support_app.py · fixed · google-adk==2.13.0
from google.adk.apps.app import App, EventsCompactionConfig

app = App(name="acme_support", root_agent=agent,
    events_compaction_config=EventsCompactionConfig(
        token_threshold=20_000,      # pair 1, half 1
        event_retention_size=6))     # pair 1, half 2
The second Acme failure: compaction never runs, because the App does not even build. EventsCompactionConfig has two trigger pairs: token_threshold with event_retention_size, and compaction_interval with overlap_size. Press once: the error text when you set only token_threshold. Press again: the fixed code sets both halves of pair 1; the badge turns OK. Press again: if you set both pairs, the token pair wins for that turn. EventsCompactionConfig is exported from google.adk.apps.app; importing it from the package google.adk.apps raises ImportError, because that package exports only App and ResumabilityConfig. Think of a pair like the two keys of a bank vault: one key alone does not open it. A likely question: "What summarises the events?" With no summarizer, ADK builds an LlmEventSummarizer on the root agent's model; a later slide shows why that default needs care.
