Interview drill: explain the ADK 2.0 runtime without hand-waving

What is the difference between a plugin and a callback? What does a non-None return from before_model_callback do?
A callback acts on one agent. A plugin is a named BasePlugin class on the App. It runs first, for every agent, model and tool call. A returned LlmResponse skips the LLM call, the later plugins and the agent callbacks. Use this for caches and guardrails.
Which state prefix do you use for a user's cart and for scratch data? When is a write persisted?
Use user:cart: all sessions of that user in the app share it. Use temp:x for scratch: ADK never persists it. A write is committed only after the Runner processes the yielded event that carries its state_delta. Before that, local code can see a dirty read.
What breaks when you upgrade from ADK 1.x to 2.0?
Events get node_info and output. Rigid DB tables and strict validators fail, so upgrade all readers first and use adk migrate session. Overrides of _run_async_impl are ignored. session.events.append breaks determinism: yield the event. A broad except stops retries, and catching BaseException traps NodeInterruptedError.
Where do you register plugins in ADK 2.x Python? How do you add one to a YAML-only agent?
Put them on App(plugins=[...]), then build Runner(app=app). Runner(plugins=) is deprecated, and both together raise ValueError. AgentConfig has no plugins key, so pass adk web --extra_plugins=…. These plugins run after the App's own plugins.

Ask each question to the room before you reveal the answer. Good answers name the mechanism: who runs first, what a return value short-circuits, and when the Runner commits a write. For the upgrade question, push for the order of work: readers and schemas first, writers last, because ADK 1.28+ can read 2.0 sessions but older 1.x versions cannot. Analogy for the commit rule: a database transaction, where the event is the commit record. A common follow-up: "Why did my retry never fire?" Usually a broad except block swallowed the exception, so RetryConfig never saw it.
