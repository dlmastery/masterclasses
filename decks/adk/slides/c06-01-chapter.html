Tools, MCP, A2A and multimodal

Tools are the agent's hands. Protocols and modalities widen its reach.

"MCP standardizes how an agent connects to tools… A2A standardizes how independent agents discover each other, delegate tasks, and share results."
Docs a2a-protocol.org: Key concepts

This chapter is about everything the agent touches outside its own model call. Press four times: each press connects one plug to the agent. First a plain Python function, then an MCP server, then a remote agent over A2A, and last a microphone and camera over a bidirectional stream. Analogy: the agent is a laptop; a function tool is a built-in key, MCP is a USB port for any device, A2A is a phone call to a colleague who has a laptop of their own, and Live is a video call. Read the quote out loud, because it is the one-line difference between MCP and A2A that interviewers ask for. Likely student question: "Is A2A only MCP for agents?" No. An MCP tool is a typed function that you can see. An A2A peer is an opaque agent with its own model, memory and policy.
