Gotcha Memory

A hand-built Runner has no memory service until you pass one

SymptomValueError: Cannot add session to memory: memory service is not available. CauseThe Runner was built without memory_service. FixPass the Memory Bank service to the Runner.
support_app.py · fixed · google-adk==2.13.0
memory = VertexAiMemoryBankService(
    project=os.environ["GOOGLE_CLOUD_PROJECT"],
    location=os.environ["GOOGLE_CLOUD_LOCATION"],
    agent_engine_id=os.environ["AGENT_ENGINE_ID"])
runner = Runner(app=app, session_service=InMemorySessionService(),
                memory_service=memory)   # no service: ValueError
The third Acme failure: the day-one callback crashes. Press once: add_session_to_memory raises "Cannot add session to memory: memory service is not available", because a Runner that you build by hand has no memory service; the socket in the picture is empty. Press again: pass memory_service=VertexAiMemoryBankService(...) to the Runner, and the plug slides in. Press again: the same rule holds for artifacts: a hand-built Runner has no artifact service either, and save_artifact raises "Artifact service is not initialized." Think of it like a phone with no SIM card: the phone works, but it cannot make the call you asked for. A likely question: "Why does adk web not crash?" adk web supplies an in-memory memory service by default, which hides the problem until a restart, as the next slide shows.
