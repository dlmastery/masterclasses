ADK docs Skills (Experimental)
A skill is a folder of instructions, scripts and resources that the agent finds and loads only when it needs them (Anthropic, 2025-10-16; open standard 2025-12-18). Step 1: only the name and description of each skill sit in the context, at tens of tokens per skill; in ADK, load_skill_from_dir reads the folder and SkillToolset (since 1.25, still Experimental) exposes it. Step 2: the user asks for an Instagram caption, so the model calls load_skill and the SKILL.md body enters the context. Step 3: the body points to references and scripts; the script runs in the code executor (the Next 26 codelab passes code_executor to SkillToolset), and only its short output comes back, never the script source. Step 4: the same idea applied to tool definitions cut about 77K tokens to about 8.7K in Anthropic's Tool Search. The standard is spreading: Antigravity replaced its legacy workflows with SKILL.md skills (workflows stopped working on 2026-10-19), and uvx google-agents-cli setup installs ADK skills into coding agents. Analogy: a skill is a manual on a shelf; the agent reads the spine labels all day and opens a manual only for the job at hand. Likely question: "How is a skill different from a tool?" A tool is one callable function; a skill is a package of know-how that can tell the agent which tools and scripts to use.
