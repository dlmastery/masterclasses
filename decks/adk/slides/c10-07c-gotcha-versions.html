The third default is the requirements file. The before block is what many tutorials still show: a lower bound on google-adk and the latest OpenTelemetry. Press once: issue 6156 came from an unpinned google-adk that resolved to a different version in the cloud than on the laptop, and the deployed agent failed with "'LlmAgent' object has no attribute 'mode'". Press again: an old Agent Platform SDK gives "The installed Agent Platform SDK exposes Client.agent_engines rather than Client.runtimes"; google-adk[gcp] wants google-cloud-agentplatform 2.2 or newer. Press again: pinning opentelemetry-sdk 1.45.1, the latest on PyPI, breaks the install, because ADK 2.13.0 requires 1.39 to 1.44. Press again: the after file pins the exact ADK version and the two ranges ADK itself declares; use the same file locally and in the deploy. Analogy: a recipe that says "some flour" gives a different cake in every kitchen. Likely question: "How often should I move the pin?" ADK shipped 13 minor releases in 5 months; move it on purpose, behind the canary from this chapter.
