What adk deploy agent_engine does

  • 1 Copies the agent. It honours .gitignore, .gcloudignore and .ae_ignore.
  • 2 Reads .agent_engine_config.json. {"identity_type": "AGENT_IDENTITY"} there gives the agent its own identity.
  • 3 Writes requirements.txt with version floors.
  • 4 Generates a Dockerfile: api_server on port 8080 with --a2a.
  • 5 Calls client.runtimes.create(), then update().

Flags: --trigger_sources pubsub,eventarc, --session_service_uri, --artifact_service_uri, --service_account. SDK: AdkApp(agent=…) + client.agent_engines.create(…), or agentplatform.Client().runtimes.create(…) (SDK 2.0.1, 2026-09-18).

Agent Starter Pack is in maintenance mode: “Active development has moved to agents-cli, the next evolution of Agent Starter Pack.” uvx google-agents-cli setup also installs ADK skills into Antigravity CLI, Claude Code and Codex.
AdkApp keeps artifacts in memory by default. A GE app in us accepts only us-* runtimes; eu only europe-*. The agents.create quota (Standard 1, Plus 10 per user per day) returns 429 in CI. A replaced agent gets a new Agent Identity principal: grant the roles again. Source deploys over 8 MB fail.

Follow the package on the belt. Step 1: in Antigravity, /grill-me asks clarifying questions, /plan writes implementation_plan.md, you comment on it, and the agent codes with the ADK skills that agents-cli setup installed; Agent Starter Pack now gets critical fixes only. Step 2: a Stop hook runs agents-cli eval run; on failure it prints decision "continue", so the coding agent cannot stop until the evals pass. Step 3: deploy; the package becomes a reasoningEngines resource, and the panel shows what adk deploy agent_engine really does, down to the Dockerfile with api_server on port 8080. Step 4: publish gemini registers the resource in the Gemini Enterprise Agent Gallery; read the pitfalls, because the location rule and the 429 quota break many CI pipelines. Step 5: where to host. Analogy: a factory line with a quality gate; a red light holds the box until it passes inspection. Likely question: "Why not just call adk deploy from CI?" You can, but agents-cli also sets up Terraform, CI/CD and publishing, and both paths end in the same reasoningEngines resource.
