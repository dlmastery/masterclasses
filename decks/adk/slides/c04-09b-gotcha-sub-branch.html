Parallel workers need use_sub_branch=True, or they read each other

SymptomGarbled events. The hotel auditor's context holds the dinner auditor's output. Causeuse_sub_branch was left False. Before 2.12, a shared-event-list bug did the same (#7488). Fixuse_sub_branch=True on every gathered call, and google-adk>=2.12.

raw = await asyncio.gather(*[
    ctx.run_node(auditor, node_input=l,
                 use_sub_branch=True,   # one branch per worker
                 run_id=f"line-{i}")    # not run_id="1"
    for i, l in enumerate(lines)])
yield Event(output=raw)                 # not: return raw

Three auditors run at the same time, one per expense line.

One shared branch: every worker sees every event.

One branch per worker: each sees only its own events.

A custom run_id needs a letter. "1" collides with auto ids.

A generator node must yield its output. return does not work.

Repo adk-python #7488 Docs adk.dev/graphs/dynamic
The second bug: set use_sub_branch=True on every gathered ctx.run_node call so that each auditor sees only its own events. The docs call it "critical for parallel isolation". Without it the three auditors share one branch, so the hotel auditor's context can hold the dinner auditor's output, and the events look garbled. Before 2.12 a shared-event-list bug (issue 7488) leaked one worker's output into another even with the flag, so upgrade as well. The top half of the animation is the shared branch: three workers' events interleave in one list. The bottom half is one branch per worker. Two smaller rules sit in the same lines of code: a custom run_id must contain a non-numeric character, so use f"line-{i}" and not "1", because numeric ids collide with the ids ADK generates; and in a generator node, return value is a SyntaxError in an async generator and is silently discarded in a sync one, so always yield Event(output=...). Analogy: three adjusters sharing one notepad will copy each other's numbers. A likely question: "Does a static fan-out tuple need this?" No, static branches are already separate; it is for runs you start yourself.
