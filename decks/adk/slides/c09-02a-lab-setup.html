Lab 9 is one folder in the repo, labs/adk/lab9-refund-eval, and the README there has every command on this slide. Install google-adk with the eval extra, pinned to 2.13.0: plain google-adk does not ship the eval module and adk eval tells you to install the extra. Set GOOGLE_GENAI_USE_ENTERPRISE to FALSE and use an AI Studio key; only safety_v1 and the multi_turn metrics call a Vertex-only service and need a Google Cloud project, and this lab does not use them. Export PYTHONPATH as the lab folder, because ADK imports our custom metrics, refund_policy and completion_bit, by module name with importlib. Then start adk web and chat with the agent. Analogy: this is the mise en place before cooking; every later step assumes these four lines. A likely question: "Why pin 2.13.0?" Because adk eval only exits 1 on a failed case since 2.13.0, and the whole gate depends on that exit code.
