Code mode goes one step further than tool search: the model writes a short script that batches tool calls, so intermediate results never pass through the context. Step 1: in Uber's post, one wide-table query fell from 1,431,594 tokens to 900; the bars use a log scale, because the drop is more than three orders of magnitude. Step 2: a small case gains much less: one SQL example went from 903 to 402 tokens. Uber has 25+ pre-built code-mode skills. The same post reports grounding through a context graph with 24M nodes: a grounded query took 38 seconds and was correct, the ungrounded one took 20 minutes and was wrong. Step 3: the MCPacific paper mapped 1.33 million MCP tool specs to 58,915 capabilities and found that a capability hierarchy beats a flat list by up to 12 points when many tools compete. Step 4: for Acme, past about 50 tools, give each MCP server its own AgentTool subagent, which is a two-level hierarchy. The 50 is a rule of thumb, not a limit, so measure. Think of a large shop: you find a screwdriver faster through the aisle signs than by reading every shelf. A likely question: "Does ADK have code mode?" ADK has code executors; the slide shows Uber's numbers, not an ADK feature.
