Routing and parallel fan-out pay off when the split is cheap to decide

budget_router.py · sketch from documented primitives

import os
from google.adk import Agent, Event, Workflow
from google.adk.workflow import DEFAULT_ROUTE
FAST_MODEL = os.environ["FAST_MODEL"]  # cheap model id
classifier = Agent(name="complexity", model=FAST_MODEL,
    instruction="Reply 'SIMPLE' or 'COMPLEX' only.")
def pick(node_input: str):             # 0 LLM calls
    return Event(route=node_input.strip())
root_agent = Workflow(name="budget_router", edges=[
    ("START", classifier, pick),
    (pick, {"SIMPLE": flash_agent,
            "COMPLEX": pro_agent,
            DEFAULT_ROUTE: pro_agent}),  # unknown label
])

Router failure modes (Gulli ch. 16)

  • A weak router sends hard queries to the cheap model.
  • Teams forget the cost of the router call itself.
  • Tone differs between the two models.
  • Evals pass on the big model and silently regress on the small one. Run the full suite per model.

Parallel failure modes

  • Cost multiplies with N branches. Rate limits hit sooner.
  • The merge cannot reconcile conflicting outputs.
  • Branches race on shared state. Give each branch its own key.

Two cheap splits. First the router: a fast model classifies, a plain function turns the label into a route, and only the matching edge fires. DEFAULT_ROUTE catches any label the model invents, and the safe side here is the strong model. Press on to see the code-first variant: when data decides, a function routes with zero LLM calls. Then parallel voting: five candidates answer the same prompt, a JoinNode collects the ballots, and the majority wins (self-consistency). The other parallel variant is sectioning, where each branch does a different subtask. Analogy: a hospital triage nurse is cheap and fast, and only the hard cases go to the specialist. Interview question: "When is a deterministic router better than an LLM router?" When the next step depends on data (a field, a threshold, a status code), on an irreversible action, or on an audit trail.
