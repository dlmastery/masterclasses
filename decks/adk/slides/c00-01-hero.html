This course is hands-on, and the first picture is the whole idea. The graph is on screen from the start: a Workflow named acme_desk with seven nodes. Press once: the legend. Amber nodes are plain Python functions; you write def intake, and ADK wraps it as a FunctionNode for you, so you never type FunctionNode. Coral nodes are Agent calls; Agent is a type alias of LlmAgent. Press again: classify, the only model call on this path, returns a Ticket object whose route field is "refund"; pick, plain code, sends that value out as the route, so the model produces a value and code picks the edge. Last press: one refund ticket runs START, intake, classify, pick, refund, audit; answer is skipped because pick routed refund. ReAct tool loops are not gone: an LlmAgent with tools still works, Lab 1 uses one, and a Workflow puts it inside a graph. Analogy: the graph is the rail track and the model is a signal operator who reads the ticket; the track decides where the train can go. Likely question: "Is answer a model call too?" Yes, but only on the question path. Next: the same graph in Python, one node at a time.
