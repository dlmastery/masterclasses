Step four: record the golden cases. In adk web, chat once about each order: A-2040 should escalate, A-1001 should be refunded 79 dollars. Then open the Eval tab and click Add current session: ADK freezes the user turn, the tool calls and the final answer as one eval case in an .evalset.json file inside the agent folder. Read the file before you commit it: you are saying "this is the right behaviour", so a recorded mistake becomes a golden mistake. Analogy: a flight recorder; you record one good flight, and every new build must fly the same route. A likely question: "Can I write the file by hand?" Yes, and the next slide shows its four parts; recording is just faster and gets the keys right.
