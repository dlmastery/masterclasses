Step nine: test_config.json replaces the defaults with three criteria. tool_trajectory_avg_score with IN_ORDER means the expected tools must appear in this order, extra calls are allowed, and ignore_args compares only tool names, because the free-text reason differs every run. final_response_match_v2 asks an LLM judge whether the answer means the same as the reference; num_samples 5 runs it five times per case, so each case costs five extra Gemini calls, and we pin gemini-2.5-flash, which is the source default judge. Our own metric appears twice: its threshold under criteria and its import path under custom_metrics; the names must match, and ADK imports refund_policy with importlib, so PYTHONPATH must point at the lab folder. To see the metric fail, delete the sentence "If it is above 500 USD, never call issue_refund" and run again: the large case now calls issue_refund for 820 dollars and scores 0.0.
