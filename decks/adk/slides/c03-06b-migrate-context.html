This is the trap in the port, from google/adk-python issue 5780. Inside a Workflow, single_turn agent nodes default to include_contents='none'; the LlmAgent field default is still 'default', but the workflow changes it. Step 1: the synthesizer gets only its system instruction plus a placeholder user turn, "Handle the requests as specified in the System Instruction.", and it answers "Understood. Provide request". The ticket text and the intake finding never reach it. Step 2: set include_contents="default" on the node that needs the history, and the user text and the intake finding come back into the request. Step 3: catch this in CI with a golden test: a scripted BaseLlm that records llm_request.contents, and an assertion that the second request still holds the original user text. Analogy: the second clerk got a sticky note that says "do your job" instead of the customer's letter. A likely question: "Should every node get default?" No: only the nodes that need the conversation; the others stay cheaper with none.
