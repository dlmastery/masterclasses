# no root_agent: the loader uses root_agent.yaml
from typing import Literal
from google.adk import Event
from pydantic import BaseModel

class Triage(BaseModel):
  label: Literal["billing", "outage", "other"]

def intake(node_input: str):
  yield Event(state={"ticket": node_input})

def route_ticket(node_input: Triage):
  yield Event(route=node_input.label)

Step 1: the instruction is plain text in its own file, so legal or a PM can review a prompt change as a one-file diff, without reading Python. Step 2: output_schema uses name: triage_yaml.agent.Triage, a fully qualified Python name resolved against sys.path. That is also the security point for the next slide: name: references import Python objects. Right, agent.py has no root_agent; the loader falls through to root_agent.yaml. Step 3: route_ticket yields one route string, because this Triage has one label. billing.yaml has the same shape as classify.yaml, with the billing prompt, and page_oncall and human_queue yield a message each; the full files are in labs/adk/c03-triage-yaml. Analogy: the YAML is the menu the owner signs off, the Python is the kitchen. A likely question: "Can I put the Literal in YAML?" No; keep schemas in Python where they are typed and tested.
