Anthropic Engineering Effective context engineering for AI agents (2025-09-29)
This chapter is about what the model sees on each call, and what the agent keeps between calls. Press once: the green stack is the session, the full event log and the ground truth. Press again: a funnel compiles that stack into one small working context for one model call. Analogy: the session is the source code, and the working context is the compiled binary for a single run; you never ship the whole repository to the CPU. Then read the Anthropic line: the target is the smallest high-signal set of tokens, not the biggest window. Likely student question: "Gemini has a 1M-token window, so why compile at all?" Because quality, cost and latency all get worse as the input grows; the next slide shows the evidence.
