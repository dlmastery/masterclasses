Start with the board: these renames confuse everyone, so get them right before an interview. Step 1 flips the labels: Agentspace became part of Gemini Enterprise on 2025-10-09, and at Cloud Next on 2026-04-22 Vertex AI became the Gemini Enterprise Agent Platform and Agent Engine became Agent Runtime; NotebookLM Enterprise is now Gemini Notebook Enterprise (2026-07-16). The grey chips do not change: the REST resource is still reasoningEngines, the CLI is still adk deploy agent_engine, and the env vars still say AGENT_ENGINE. Step 2 builds the stack from the bottom; the key point is that Gemini Enterprise and Agent Platform are two products: you build and host on the platform, then publish into the app. Step 3 sends a query down the stack and the answer back up, and it names the I/O 2026 four-rung framing, which comes from a secondary source. Analogy: the platform is the factory and the power grid; Gemini Enterprise is the shop where employees pick up the product. Likely question: "Is Agent Runtime a different service from Agent Engine?" No, it is the same managed runtime with a new name and new features such as 7-day operations.
