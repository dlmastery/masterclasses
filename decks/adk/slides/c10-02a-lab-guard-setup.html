This is the "run it Monday" slide for Lab 10, the Acme HR assistant; the full files and README are in labs/adk/c10-acme-hr. Press once: pin google-adk 2.13.0 with the gcp and otel extras; gcp brings google-cloud-modelarmor, and unlike Labs 1 to 7 this lab needs a Cloud project with billing. Press again: GOOGLE_GENAI_USE_ENTERPRISE=TRUE plus project and location means Gemini calls go through the Cloud project, not an AI Studio key. Press again: create the Model Armor template named hr-guard in the Console first; the gcloud command for it is not verified, so we do not show one. The plugin wants the full resource name, and a bare 'hr-guard' raises "Template names must be full resource names"; templates in two locations raise a second ValueError. Press again: adk web from the parent folder; the loader takes app before root_agent, which matters on the next slide. Analogy: this is the mise en place before the cook starts. Likely question: "Can I do this lab with only an API key?" Step 1 needs Model Armor, which lives in a Cloud project, so no.
