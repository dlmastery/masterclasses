class CountInvocationPlugin(BasePlugin):
  def __init__(self) -> None:
    super().__init__(name="count_invocation")
    self.agent_count = 0
    self.llm_request_count = 0
  async def before_agent_callback(
      self, *, agent, callback_context) -> None:
    self.agent_count += 1
  async def before_model_callback(
      self, *, callback_context, llm_request) -> None:
    self.llm_request_count += 1   # Observe: return None

app = App(name="test_app_with_plugin",
          root_agent=root_agent,
          plugins=[CountInvocationPlugin()])
runner = InMemoryRunner(app=app)

A plugin is a BasePlugin subclass with a unique name. You register it once on App(plugins=[...]) and its hooks apply "globally to every agent, tool, and LLM call". Step one: the playhead walks the 14 hooks in lifecycle order, and the error hooks branch below in red. Step two: the PluginManager runs plugins in list order and the first non-None return wins, so a cache plugin can answer with a stored LlmResponse and skip the later plugins, the agent callback and the model call. A plugin that raises becomes a RuntimeError, and two plugins with the same name raise ValueError. Analogy: plugins are airport security that every passenger passes; a callback is the check at one gate. Likely question: "How do I add a plugin to a YAML-only agent?" AgentConfig has no plugins key, so use adk web --extra_plugins=google.adk.plugins.LoggingPlugin; Runner(plugins=) is deprecated, and passing it together with app raises ValueError.
