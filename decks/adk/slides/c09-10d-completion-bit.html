from google.adk.evaluation.eval_case import get_all_tool_calls
from google.adk.evaluation.evaluator import (
    EvalStatus, EvaluationResult)

DONE = {"escalate_to_human", "issue_refund"}   # terminal tools

def completion_bit(eval_metric, actual_invocations,
                   expected_invocations, conversation_scenario):
    done = any(call.name in DONE for inv in actual_invocations
               for call in get_all_tool_calls(inv.intermediate_data))
    status = EvalStatus.PASSED if done else EvalStatus.FAILED
    return EvaluationResult(overall_score=1.0 if done else 0.0,
                            overall_eval_status=status)

The Monday change from GAUGE: a judge-free completion bit for the simulated set. The rule is simple: the chat is done only if the agent called a terminal tool, escalate_to_human or issue_refund; nothing a judge says can change that. The function reads the tool calls with get_all_tool_calls, sets the score and the status, and is registered like refund_policy_score, with the threshold under criteria and the import path under custom_metrics in sim_config.json. Completion is not correctness: a refund of 820 dollars is "complete", so keep refund_policy_score and the rubric next to it. Analogy: the parcel tracking says "delivered", whatever the customer email says. A likely question: "Why not check the final text for a ticket id?" You can, but tool calls are structured data, while text can mention a ticket that was never opened.
