A router emits a route label, and only the matching edge fires

A node yields Event(route=v). The value v is a str, int or bool. A routing dict maps v to the next node.

The router emits "BUG". Only the edge with the key "BUG" fires. The other branches do not run.

A list route fans out: Event(route=["BUG", "LOGISTICS"]) starts every matching branch.

No match and no default: the branch ends silently. ADK writes only a log warning. Other branches continue.

DEFAULT_ROUTE (the literal "__DEFAULT__") fires when a route is emitted and no key matches. Since 2.10 it can fan out.

  • (a) Function router: rules in code, e.g. codelab L2b "HOT" if temp >= 70 else …
  • (b) LLM + schema: output_schema with Literal[...], a function routes on the field.
  • (c) ClassifierNode (2.13, labs): calibrated score, threshold gate.
Pitfall: an LLM router with free-text output and no DEFAULT_ROUTE can invent a label, for example "REFUND". The request then disappears with no error. Constrain the label with a Literal schema and add a default edge.

from google.adk import Event, Workflow
from google.adk.workflow import DEFAULT_ROUTE

def router(node_input: str):
    routes = [r.strip() for r in node_input.split(",")]
    return Event(route=routes)      # a list fans out

root_agent = Workflow(name="routing_workflow", edges=[
    ("START", process_message, router),
    (router, {"BUG": response_1_bug,
              "CUSTOMER_SUPPORT": response_2_support,
              "LOGISTICS": response_3_logistics,
              DEFAULT_ROUTE: fallback}),   # catch-all
])

from google.adk.labs.classifiers import (
    Binary, Choice, ClassifierNode, LlmClassifier)

classifier = LlmClassifier(model="gemini-3.5-flash")
triage = ClassifierNode(name="triage", classifier=classifier,
    question=Choice(
        instructions="Which team should handle this support ticket?",
        criteria={"billing": "Invoices, refunds, or subscription charges",
                  "technical": "Bugs, errors, outages, or API problems",
                  "general": "Product questions and anything else"}),
    answer_key="triage_answer")
is_urgent = ClassifierNode(name="is_urgent", classifier=classifier,
    question=Binary(instructions="Is this an outage, or does it "
                    "block the customer's production use?"),
    threshold=0.7, answer_key="urgency_answer")

edges = [("START", process_input, triage),

Routing is the core of graph engineering: code decides which edge fires, and the model only produces a label. Step 1: one label, one branch. Step 2: a list label starts two branches at once; this is the multi-label example from adk.dev. Step 3 is the failure students meet first: the model writes "REFUND", no key matches, and the request stops with only a log warning. Step 4 adds DEFAULT_ROUTE as the safety net. Step 5 shows the strongest grade: ClassifierNode from 2.13, a labs API, where a Binary question with threshold=0.7 makes a confidence-gated edge. The bar in the animation is illustrative, not a measured score. Analogy: a mail sorter. A barcode reader (function) is cheap and exact; a human reading handwriting (LLM) needs a fixed list of bins and a "return to sender" bin. Interview question: "How do you stop a router from hallucinating a branch?" Answer: Literal output schema, function routing on the typed field, DEFAULT_ROUTE, or a calibrated classifier with a threshold.
