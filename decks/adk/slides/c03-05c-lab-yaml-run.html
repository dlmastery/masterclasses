Run the YAML graph from labs/adk/c03-triage-yaml, the parent folder of triage_yaml. Step 1: the double-charge ticket gets the billing label and billing answers, the same as the Python router. The output is illustrative. Step 2: run the same thing from inside the folder and you get ModuleNotFoundError: No module named 'triage_yaml', because the dotted references and output_schema name resolve against sys.path, and the CLI adds the parent folder. The fix is to run from the parent, as the loop_config README says. Step 3: swap the two edges in root_agent.yaml and the loader stops with "ValueError: Unknown node 'route_ticket'. A node has to be defined by an earlier edge before another edge can name it." Either reorder the edges or use the full .agent.route_ticket reference. Step 4 is the rule with no error message: name: references import arbitrary Python objects, so a YAML file is code. Never template it from user input, and load it only from your own repo.
