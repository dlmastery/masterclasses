An agent card is a promise, and ADK does not check the promise for you. to_a2a writes protocol, host and port into the card, and the default port is 8000. uvicorn binds the socket on whatever port you pass it, here 8001. So the client loads the card, follows its URL to port 8000 where nothing listens, and every send fails with httpx ConnectError: All connection attempts failed. The fix is one argument: pass the port you really serve on, port=8001, as the lab's a2a_server.py does. Then check it: curl the well-known card path and read the url field before any client calls it. Analogy: the card is a business card, and a wrong phone number on it sends every caller to an empty office. A likely question: "Can I skip to_a2a's card and write my own?" Yes, pass a hand-written agent_card=, but the same rule holds: the URL must match how you serve it. The next slide shows the same bug when you deploy.
