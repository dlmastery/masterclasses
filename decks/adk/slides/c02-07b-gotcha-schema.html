Second structured-output mistake. Step 0: ADK raises an error whose full text ends with "Move your schema to LlmAgent(output_schema=...)". Click 1: the cause is an old google-genai habit of putting response_schema into GenerateContentConfig; ADK manages the schema itself, so it rejects it there. Click 2: the schema belongs on the agent as output_schema, and output_key stores the validated result in state. Click 3, a likely question: "Why does my trace show an extra set_model_response call when I add tools?" On an AI Studio key ADK cannot combine a schema and tools natively, so it adds a set_model_response tool and asks the model to answer through it. With GOOGLE_GENAI_USE_ENTERPRISE=1, the Agent Platform backend formerly called Vertex AI, the call goes away. On AI Studio it still works; there is nothing to fix. A related error: Agent(temperature=0) also fails; put temperature in generate_content_config instead.
