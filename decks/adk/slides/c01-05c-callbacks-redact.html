def redact_pii(tool: BaseTool, args: dict, tool_context: ToolContext,
               tool_response: dict) -> Optional[dict]:
    if tool.name == "lookup_order" and "order" in tool_response:
        order = {k: EMAIL.sub("[email redacted]", v)
                 if isinstance(v, str) else v
                 for k, v in tool_response["order"].items()}
        return {**tool_response, "order": order}
    return None                     # None = keep the tool result

def meter_tokens(callback_context: Context,
                 llm_response: LlmResponse) -> Optional[LlmResponse]:
    if llm_response.usage_metadata:
        used = callback_context.state.get("tokens_used", 0)
        callback_context.state["tokens_used"] = used + (
            llm_response.usage_metadata.total_token_count or 0)
    return None                     # None = keep the response

The fourth hook, block_card_numbers, stops card numbers before the model. It is in the lab file.

Step 1: after_tool_callback sees the tool's response; a non-None return value replaces it, so the model never sees the customer's email, only "[email redacted]". Return None for every other tool to keep the original result. Step 2: after_model_callback runs after each model call; it adds usage_metadata.total_token_count to tokens_used in session state. A state write inside a callback goes into the event's state_delta, so it is persisted like any other state change. The number is illustrative. Step 3: the fourth hook, before_model_callback=block_card_numbers, checks the last user turn for a card number and returns a canned LlmResponse, so the model is never called; the code is in labs/adk/lab1-refund-guardrails. Pitfall: before_model only sees the request; injected text can also arrive inside a tool result, which is one more reason for after_tool checks. Analogy: redaction is the black marker on the copy, the meter is the electricity meter on the wall. Likely question: "Why not redact in the tool?" You can, but a callback applies one rule to every tool and every agent you attach it to.
