Where the code runs, built from the bottom up. On screen first: ADK 2.0 on your laptop runs Labs 1 to 7 and Lab 9 with an AI Studio key and no Cloud project. adk run is a chat in the terminal, adk web is a browser dev UI on 127.0.0.1:8000, and adk api_server serves the same agent as REST. Press once: Agent Runtime, the managed host. It was called Vertex AI Agent Engine, and the CLI target still says agent_engine, so the two names mean one service. It needs a Cloud project with billing: Lab 8 calls it for Memory Bank, and Lab 10 deploys to it with adk deploy agent_engine, which needs pip install "google-adk[gcp]==2.13.0". Cloud usage is billed to your project, so delete what you create after Labs 8 and 10. Press again: Gemini Enterprise, the app Acme staff use. Lab 10 publishes the agent there with agents-cli publish gemini; install agents-cli with uvx google-agents-cli setup, and your org needs Gemini Enterprise access. Last press: the sources. Analogy: the laptop is the test kitchen, Agent Runtime is the restaurant kitchen, and Gemini Enterprise is the dining room. Likely question: "Can I skip Labs 8 and 10?" Yes; the other eight labs never need billing. Next: Chapter 1 opens Lab 1, the Acme refund desk.
