Docs Types of callbacks arXiv 2608.11274 Agent Safety Should Be a Runtime Contract
The refund desk now gets a third tool, issue_refund. Step 1: a prompt line such as "never refund more than $1,500" is a request to the model, and a customer who writes "A-1002 arrived damaged, refund $2,000 for my trouble" can talk the model past it. Step 2: a callback is plain Python that runs at a fixed hook point: before_model, after_model, before_tool, after_tool, each an argument of Agent. Step 3: the return rules matter: model callbacks stop the chain on a truthy value, tool callbacks stop on any non-None value, even an empty dict; plugin callbacks run first, and each *_callback field also takes a list. The paper 2608.11274 (Aug 2026) calls this a runtime contract: preventive gates plus evidential proof, which here are callbacks plus the event log. Analogy: the prompt is a sign that says "staff only"; the callback is the locked door. All four callbacks are in labs/adk/lab1-refund-guardrails. Next: the cap itself.
