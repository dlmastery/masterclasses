Now run the skill agent in adk web with the A-300 prompt and watch the trace. Step 1: list_skills returns only the name and description, level 1; the body stays on disk. Step 2: load_skill adds the four steps, level 2, and only now does lookup_order reach the model, which reads A-300: 42 days, 120 dollars. Step 3: load_skill_resource reads policy.md, and run_skill_script runs prorate.py; the args dict becomes --amount 120.0 --days 42. Step 4: the script prints 72.0 and the agent answers PARTIAL_REFUND 72.00, past 30 days and inside 60. The trace on the slide is abridged; the real calls also carry the skill name and the file_path keys, and the full trace is in the lab README. Think of a manual on a shelf: the model reads the spine first and opens the chapter only when the question needs it. A likely question: "Does the body stay in the prompt for the rest of the session?"
