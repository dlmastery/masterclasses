Step eleven: the GitHub Actions workflow is short because CI needs only the exit code. Pin google-adk with the eval extra to the same 2.13.0 the lab uses, put the API key in a repository secret, run from the lab folder, and call ci/eval_gate.sh. The script runs adk eval, and since 2.13.0 a failed case gives exit 1, so the job fails and branch protection blocks the merge; when every case passes, the job exits 0. The script also adds three checks that adk eval does not do for you: it fails on a missing config file, on a wrong case count and on a known-bad case that passes; the gotcha slides explain why. Analogy: a bouncer who reads one thing, the wristband colour. A likely question: "Where does the copy of this file go?" Copy ci/eval.yml to .github/workflows/eval.yml at the repository root.
