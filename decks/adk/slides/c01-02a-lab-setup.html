Scaffold the Acme refund desk with one adk create command

cd labs/adk/lab1-refund-toolsfull code + README in the repo
terminal · Python 3.11+
$ python -m venv .venv
$ source .venv/bin/activate     # Windows: .venv\Scripts\activate
$ pip install "google-adk==2.13.0"
$ adk create refund_agent --model gemini-3.5-flash \
      --api_key $GOOGLE_API_KEY

Pin the version. Every slide in this chapter uses google-adk 2.13.0, which needs Python 3.11 or newer.

adk create writes a package folder. The folder name is the app name, so use underscores, not hyphens.

Use GOOGLE_GENAI_USE_ENTERPRISE. The old GOOGLE_GENAI_USE_VERTEXAI still works but raises a DeprecationWarning.

This is the run-it-Monday slide for Lab 1. Step 1: create a virtual environment and pin google-adk 2.13.0; the 2.13.0 wheel needs Python 3.11 or newer, even though the quickstart page still says 3.10. Step 2: adk create writes a package folder with __init__.py, agent.py and .env; ADK imports this folder as a Python package, so the name must be a valid identifier. Step 3: the .env file selects the backend; GOOGLE_GENAI_USE_ENTERPRISE=0 means an AI Studio key, 1 means Agent Platform with a project and location. The old GOOGLE_GENAI_USE_VERTEXAI still works but prints "DeprecationWarning: GOOGLE_GENAI_USE_VERTEXAI is deprecated, please use GOOGLE_GENAI_USE_ENTERPRISE instead". Analogy: the folder is the shop front, and the loader only finds shops whose sign it can read. Likely question: "Can I skip adk create?" Yes: copy labs/adk/lab1-refund-tools, which has the same layout plus the runner scripts. Next: the first tool.
