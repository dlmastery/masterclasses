ROLE = re.compile(r"\[?(user|model|system)\]?:", re.I)   # anywhere
def escape_roles(text: str) -> str:
    return ROLE.sub(lambda m: "| " + m.group(0), text)
def escaped(ev):          # deep copy; session untouched

INNER = LlmEventSummarizer(llm=Gemini(model="gemini-3.5-flash"))
class EscapingSummarizer(BaseEventsSummarizer):
    async def maybe_summarize_events(self, *, events):
        return await INNER.maybe_summarize_events(
            events=[escaped(ev) for ev in events])
compaction = EventsCompactionConfig(token_threshold=60_000,

Press once: a regex finds role labels such as "[User]:" anywhere in a line, and escape_roles puts a bar in front of each one. Press again: escaped() works on a deep copy of each event, text parts and tool responses alike, so the session itself never changes. Press again: EscapingSummarizer wraps the default LlmEventSummarizer and hands it only escaped copies, so in the summary the forged label reads as quoted tool data, not as a user turn. Press again: plug it into EventsCompactionConfig with a full trigger pair; event_retention_size=8 keeps the latest raw tool outputs, as the source-judge paper suggests. Escaping is a partial defence: keep approvals in typed session state that only a real user event can write, and never let a summary grant a permission. Think of escaping like putting quotation marks around a quote, so nobody mistakes it for your own words. A likely question: "Does this slow compaction down?" It adds one regex pass over the events being compacted, which is small next to the summarizer's model call. A third paper, CliffCompaction (arXiv 2609.26779), adds that truncating or dropping, instead of rephrasing, cut cost by up to 50 percent on Terminal-Bench.
