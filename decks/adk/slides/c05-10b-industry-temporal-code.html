This is the payout agent from this chapter, written for Temporal. Install the pinned versions, temporalio 1.34.0 with the google-adk extra and google-adk 2.13.0, and start a local dev server; the Worker needs GOOGLE_API_KEY. First click: the same GoogleAdkPlugin instance goes to the Client and to the Worker, as the Temporal docs show. Second click: activity_as_tool wraps charge_gateway, your own Activity that calls the gateway, so each tool call is a separate, retryable Activity with a 60-second timeout. Third click: TemporalModel wraps the model, so each model call becomes an invoke_model Activity. Fourth click, the lesson: replay re-sends charge_gateway with the same inputs, so neither Temporal nor ResumabilityConfig makes the ACME-GmbH payout idempotent for you; the gateway still needs the payout- key. The integration package is moving: on sdk-python main the module re-exports temporalio.google_adk from the new temporalio-google-adk 0.0.1 package, but 1.34.0 keeps the contrib path on this slide. The docs page is marked pre-release. A likely question: "Do I need Temporal if ADK has ResumabilityConfig?" ResumabilityConfig checkpoints your ADK workflow in one session store; Temporal adds per-call retries and a history that any worker can replay.
