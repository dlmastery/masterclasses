Run it with adk web from the parent folder, pick pricing_analyst and ask for the average comprehensive premium on a 2024 Civic. The output is illustrative and the prices are placeholders, not real premiums. Walk the trace: the root calls price_search through its AgentTool and gets back a short list of prices with a url for each; then it calls price_math, which writes and runs Python in Gemini's sandbox, so the mean, min, max and spread are computed, not guessed; then the root writes the answer and cites the sources. Since 2.13 the google_search grounding is recorded on the LLM spans, so you can audit which urls backed an answer; Google's terms also require that you show the search suggestions in a production UI. The paper on the right is the reason to recompute: When Tools Silently Lie, arXiv 2609.37153, shows that plausible but wrong tool evidence lowers data-agent task success by 26 to 39 points, and agents sometimes adopt the wrong answer even after they check it. A likely question: "Is the sandbox enough?" It computes correctly on the numbers it gets, so also check that the prices came from the urls cited.
