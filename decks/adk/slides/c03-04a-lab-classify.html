from typing import Literal
from google.adk import Agent, Event, Workflow
from google.adk.workflow import DEFAULT_ROUTE
from pydantic import BaseModel, Field

class Triage(BaseModel):
  labels: list[Literal["billing", "outage", "how_to", "other"]] = Field(
      description="All labels that apply to the ticket.")
  priority: Literal["p1", "p2", "p3"]

def intake(node_input: str):
  yield Event(state={"ticket": node_input})

classify = Agent(name="classify", model="gemini-3.5-flash",
    instruction="Classify this support ticket. Ticket: {ticket}",
    output_schema=Triage, output_key="triage")

Lab 3.3 is the Acme support desk triage. A second package, ticket_triage, adds routing; the full file is labs/adk/c03-ticket-triage/ticket_triage/agent.py. Step 1: the Triage schema. Labels and priority are closed Literal sets, so the model can only pick from them; it cannot invent "Billing" with a capital B. labels is a list because one ticket can be both an outage and a billing problem. Step 2: intake is a function node that yields an Event with state, so {ticket} is available to every prompt later in the graph. Step 3: classify is an Agent with output_schema=Triage: its reply is validated JSON, saved in state under triage, and passed on the edge to the next node. For this double-charge ticket the illustrative answer is labels billing, priority p1; the next slide shows how code adds the outage route. Analogy: the nurse may only write one of four ward names on the chart. A likely question: "Why import DEFAULT_ROUTE from google.adk.workflow?"
