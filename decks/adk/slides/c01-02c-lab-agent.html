Step 1: Literal becomes an enum in the schema, so the model can only choose changed_mind, damaged or wrong_item; it cannot invent "broken". Step 2: reason has a default, so it is optional; order_id has none, so it is mandatory, and if the model omits it ADK returns an error dict instead of raising. Step 3: the agent is one constructor call; plain functions go straight into tools and ADK wraps each one in a FunctionTool. The name refund_agent must be a Python identifier and must not be "user".
