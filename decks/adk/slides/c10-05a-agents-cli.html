Agent Starter Pack still installs, but its README says it is in maintenance mode with critical fixes only, so new projects start with agents-cli, PyPI google-agents-cli 1.11.0; its sub-commands come from its docs. Press once: setup installs the CLI and puts the ADK skills into the coding agent, here Antigravity. Press again: scaffold enhance wraps the existing hr_agent folder with app/agent_engine_app.py, Cloud Build, deployment files and tests, and prints "Success! Your agent project is ready." Press again: the key idea is the loop: a Stop hook runs agents-cli eval run and answers decision continue with the reason, so the coding agent cannot stop until the evals pass. Press again: deploy reads the target from pyproject.toml, and infra cicd adds a staging and a production pipeline in Cloud Build. Analogy: the Stop hook is a quality inspector who sends the box back to the bench. Likely question: "Must I stop using adk deploy?" No: adk deploy still works on its own; agents-cli adds the scaffold, the eval gate and CI around the same agent folder. Full script: labs/adk/c10-acme-hr/agents_cli.sh.
