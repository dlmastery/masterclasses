from google.adk.agents import LlmAgent
from google.adk.agents.remote_a2a_agent import (
    AGENT_CARD_WELL_KNOWN_PATH, RemoteA2aAgent)

refund_remote = RemoteA2aAgent(
    name="refund_agent",      # local name: the LLM transfers by it
    agent_card=f"http://localhost:8001{AGENT_CARD_WELL_KNOWN_PATH}",
    description="Remote refund-eligibility agent (Payments team).",
    timeout=60.0,             # default 600.0 seconds
)
root_agent = LlmAgent(
    name="support_triage", model="gemini-3.5-flash",
    instruction=("Classify the ticket. Refund or return questions: "
                 "transfer to refund_agent. Else answer yourself."),
    sub_agents=[refund_remote],
)

agent_card takes a URL, a file path or an AgentCard.

In sub_agents: triage transfers to it by its local name.

The A2A message carries the user's text, so it names A-100.

Step 3 of the Acme refund team: support triage, owned by the support team, delegates refund tickets to the refund agent that the Payments team serves on port 8001. Run adk web from the lab folder in terminal 3, pick triage in the dropdown, and keep uvicorn from step 2 running; the MCP server from step 1 is not needed. RemoteA2aAgent fetches the agent card from the well-known path; agent_card can also be an AgentCard object or a file path, and we lower the timeout from the 600 second default to 60. The remote agent sits in sub_agents like any local agent, and the LLM transfers to it by the local name you give it. There is no message argument on a transfer: RemoteA2aAgent builds the outgoing A2A message from the conversation, and the user's turn already names A-100. Session state does not cross: if triage saved the order id in state, the remote agent would never see it; the gotcha slides cover this, and context_builder controls what is sent. Think of a phone call to another department: they cannot read your notes, so you say the order number out loud. A likely question: "Will I see an error when state is dropped?" Not an error: since 2.12.0 ADK logs a warning that it cannot forward a state-only event across A2A.
