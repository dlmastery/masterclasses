Two changes. Use both.

Import DEFAULT_ROUTE from google.adk.workflow.

A Literal set: the model can only emit "billing".

An unmatched route now reaches a human, not a log line.

The fix has two halves, and you want both. Step 1: import DEFAULT_ROUTE from google.adk.workflow; the top-level google.adk package does not export it. Its value is the string "__DEFAULT__". Step 2: classify into a Literal set, so the model can only emit legal labels; the token is now 'billing' and takes the billing edge. Step 3: add the DEFAULT_ROUTE edge to human_queue: any route that matches no key, for example the label other, now reaches a person instead of ending in a log line. In the figure the dashed violet wire is that default edge. DEFAULT runs only when no other key matches, and it cannot be combined with other routes in one list: that raises "GraphValidationError: DEFAULT_ROUTE cannot be combined with other routes in a list". Analogy: the Literal set is a form with tick boxes instead of a free-text field; DEFAULT is the "return to sender" stamp. A likely question: "If I have Literal, why DEFAULT?" Because other is a legal label with no branch, and because schemas change faster than edge maps. Next: two errors that do fail loudly.
