Step fourteen scores the simulated chats. Simulated cases have no golden turns, so we use only reference-free metrics. sim_config.json has three of them: hallucinations_v1 checks that the answers are grounded in the tool results, per_turn_user_simulator_quality_v1 checks that the simulator followed its plan, and the rubric metric on this slide checks our two rules. A rubric is a property the answer must have; the judge scores each rubric five times. The type field picks the simulator; older configs without it are treated as llm_backed with a warning, and we cap the chat at 8 turns instead of the default 20. In the NOVICE chat the agent gave the ticket but promised the 820 dollar refund, so no_overlimit_promise scores 0.0, the rubric metric scores 0.5 and the case fails. The output is illustrative. A likely question: "Do these need Google Cloud?" No: these three metrics run on the AI Studio key; only safety_v1 and the multi_turn metrics need a Cloud project.
