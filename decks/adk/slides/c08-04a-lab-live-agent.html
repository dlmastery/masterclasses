def get_balance(account_id: str) -> dict:
    """Returns balance and due date for an Acme account."""
    return {"status": "success", "account_id": account_id,
            "balance_usd": 84.20, "due": "2026-11-05"}

agent = Agent(name="voice_billing", tools=[get_balance],
    model="gemini-live-2.5-flash-native-audio",
    instruction="Acme billing. Be brief. No new-plan prices.")

cfg = RunConfig(
    response_modalities=["AUDIO"],
    output_audio_transcription=types.AudioTranscriptionConfig(),
    session_resumption=types.SessionResumptionConfig())

One plain tool. The Live model calls it mid-call.

Step three of Lab 8 moves the Acme billing desk to voice with the Live API on Agent Platform, so the .env sets GOOGLE_GENAI_USE_ENTERPRISE=TRUE and a regional location; global does not serve the Live model. With an AI Studio key instead, set it to FALSE, add GOOGLE_API_KEY, and use the preview model gemini-3.1-flash-live-preview. Press once: get_balance is a plain function tool; the instruction forbids quoting new-plan prices. Press again: the agent uses gemini-live-2.5-flash-native-audio, which is DEFAULT_LIVE_MODEL in 2.13; native-audio models answer in audio only. Press again: RunConfig asks for audio out, turns on output_audio_transcription so you also get text, and adds session_resumption so ADK reconnects when the Live connection hits its duration limit. Think of the transcript as the subtitles on a phone call. A likely question: "Does StreamingMode.BIDI turn on live mode?" No; its own docstring says to use runner.run_live, which is the next slide.
