This is the run of Lab 3.2. The plain adk run shows only two lines for four nodes. Step 1: adk run prints message events only, so check_policy, which only returns a value, shows no text. Step 2: the audit line is signed refund_flow, not audit_log, because function nodes sign their events with the enclosing Workflow's name; an LLM agent node signs with its own name. When you search traces for a function node, filter on event.node_info.path, not on author. Step 3: run A-1002 with --jsonl and every event appears as one JSON line, check_policy included; @1 means the first run of that node. Step 4: A-1002 was delivered 41 days ago, the policy is 30 days, so eligible is false and the instruction makes the reply offer store credit. All output here is illustrative: built from the CLI print code and sample goldens, not executed. A likely question: "Where do I see state changes?" In adk web, or in the state_delta field of each --jsonl event.
