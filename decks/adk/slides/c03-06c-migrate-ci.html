The last step of the port is a CI gate. Step 1: run pytest with -W error::DeprecationWarning, so the deprecation warning becomes an exception and the test fails; the lab has a one-line test that imports the agent, in v1 and in v2. That finds every SequentialAgent, ParallelAgent and LoopAgent in the code base. Step 2: pick the mode by what the node must do. single_turn is a one-shot worker, and what an agent node resolves to inside a graph. task asks the user for missing slots and then exits with a typed result through finish_task. chat is free conversation. Step 3: a chat agent after any node other than START fails validation, with the GraphValidationError on the slide. Put the chat agent at the root instead, with task-mode sub-agents. Also run the graph through the Runner; never call workflow.run(ctx=...) yourself, because that skips the Runner event-queue consumer that saves tool-call events. Analogy: the warning is a smoke detector; the -W flag connects it to the fire alarm. A likely question: "Does the old code still work?" Yes, today; but it can go in a future release, and 2.x ships every one to two weeks.
