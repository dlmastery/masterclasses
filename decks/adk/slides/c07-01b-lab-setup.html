Codelab Getting Started with MCP, ADK and A2A
Before step 1, set up one folder that the whole lab grows in: labs/adk/lab7-acme-refunds, with a README that has the same commands. Install the pinned versions with the mcp and a2a extras, and export the Gemini variables in every terminal, because plain python and uvicorn do not read an agent folder's .env file the way adk web does. The ADK_SUPPRESS_EXPERIMENTAL_FEATURE_WARNINGS variable silences the warning from to_mcp_server, which is experimental. Walk the three terminals: terminal 1 runs the MCP server only for step 1; terminal 3 runs the MCP consumer with adk run in step 1; terminal 2 runs the A2A server on 8001 for steps 2 and 3; terminal 3 then runs adk web on 8000 for steps 3 to 5. Each agent package for adk web needs an __init__.py with "from . import agent"; refund_service needs only an empty one. Think of the folder as one kitchen with three serving hatches. A likely question: "Which processes must run together?" Only in step 3: uvicorn on 8001 and adk web on 8000.
