Post Uber: Running a Software Factory Efficiently
Uber published its cost program for agentic coding on 2026-08-27. One line item is the MCP tool schema: about 50K to 70K tokens for 100+ tools, paid on every request before the model reads a word of the task. Step 1: the schemas pile up on each request. Step 2: their fixes are a gateway that resolves tools through a CLI, and on-demand tool search, so the model sees only the tools the task needs. Step 3: for Acme, the cheap version of the same idea is tool_filter on every toolset, and a metric for schema tokens per request, so a new server cannot quietly double your bill. Think of a mechanic who carries the whole workshop to every job instead of the two tools the job needs. L'Oreal also connects ADK agents to its data through MCP, but published no cost number. A likely question: "Is there a tool count limit?" No hard limit, so measure tokens and selection accuracy as you add tools; the next slide shows what code mode and grouping add.
