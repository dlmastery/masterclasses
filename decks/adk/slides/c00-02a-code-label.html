from typing import Literal
from google.adk import Agent, Event, Workflow
from pydantic import BaseModel

class Ticket(BaseModel):
  route: Literal["refund", "question"]
  order_id: str = ""

def intake(node_input: str):
  yield Event(state={"ticket": node_input})

classify = Agent(
    name="classify", output_schema=Ticket,
    instruction="Label refund or question; copy order id: {ticket}")

Press once: Ticket is a Pydantic model whose route field is a Literal with two values, and output_schema=Ticket on classify makes the reply validated JSON, so the model cannot invent a third route. It gets the user's text as node_input and yields an Event with state=, which writes the ticket key into session.state, the dict that every node of this run shares. Press again: classify is the only model call; ADK replaces {ticket} in the instruction with session.state["ticket"] before the call, and a missing key raises a KeyError. There is no model= argument, so the agent uses the 2.13.0 default, gemini-3.5-flash; set model= to pin another id. Analogy: classify fills in a form with two boxes.
