Interview drill: defend when an agent is worth its cost

Workflow or agent for a refund process?
A workflow spine. The path is data-determined, it has irreversible side effects and it needs an audit trail. Use an LLM node only for the unstructured complaint. Google: “If you can clearly map the workflow, use determinism.” Its illustrative refund run went from 5,152 to 2,265 tokens.
A 20-step agent is 95% reliable per step. What is the end-to-end success, and what do you change?
About 36% (0.9520). Put cheap verifiers after the risky steps, hard-code the data-determined edges and remove steps. Each removed or verified step raises the product.
Why did the single growing ReAct prompt fail on long tasks?
Context rot: Chroma (2025-07-14) found that all 18 tested models degrade as input grows. Attention is an n² budget, and tool output piles up in the window. Modern harnesses move state into files, memory and subagents, and each call gets a compiled view.
What is harness engineering, and who named it?
Mitchell Hashimoto, 2026-02-05: each agent mistake triggers an engineered fix in the environment, so the mistake does not repeat. Böckeler splits the controls into guides (feedforward) and sensors (feedback), each computational or inferential. In ADK, each failure becomes an eval case and a CI gate.

Read each question aloud and give students ten seconds before you reveal the answer. Question 1 tests the decision rule: money, irreversibility and audit push you to deterministic edges, and the LLM handles only the open-ended part. Question 2 tests compounding error: candidates who say "95%" fail; the right answer is about 36%, and the fix is verifiers and fewer steps, not a bigger model. Question 3 tests whether the candidate knows why ReAct-style transcripts were replaced: context rot and the attention budget. Question 4 tests vocabulary from 2026: harness engineering, guides and sensors. Analogy for question 2: a chain of 20 links that each hold 95% of the time breaks most days. Likely follow-up: "Why not just use a model with a 1M-token window?" A bigger window raises the ceiling but does not stop the degradation, the cost or the latency.
