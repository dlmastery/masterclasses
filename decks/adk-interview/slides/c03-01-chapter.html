Code in this chapter: pip install google-adk==2.13.0 · Python 3.11+ · GOOGLE_API_KEY (or GOOGLE_GENAI_USE_ENTERPRISE=1 + GOOGLE_CLOUD_PROJECT)
This chapter answers one question: what does the model see on each call, and what does that cost? Click 1: call 1 sends the stable prefix (static_instruction and tool schemas) plus the first message, and ADK creates no cache on the first call, so it is a miss. Click 2: from call 2 the same prefix is read from the cache, and only the history grows. Click 3: by call 5 the history is the expensive part. Click 4: EventsCompactionConfig folds calls 1 to 4 into one summary, and call 6 sends prefix plus summary plus the recent history. Analogy: a lawyer keeps the same contract template on the desk and adds one page of notes per meeting; at some point the notes become a one-page memo. Likely question: "Why not compact on every call?" Because a summary can invent facts, which is the compaction slide. The code in this chapter uses google-adk 2.13.0 and an AI Studio key; Memory Bank is the managed Vertex AI memory backend, so it needs a Google Cloud project, while InMemoryMemoryService needs nothing.
