import asyncio
from google.adk import Agent
from google.adk.runners import InMemoryRunner
from google.genai import types
hr_agent = Agent(
    name="hr_policy_agent", model="gemini-3.5-flash",
    instruction=("You are the HR assistant for {app:company_name}. "
                 "Reply in {user:language}. Quote policy text exactly."),
    output_key="last_hr_answer",
)
async def main() -> None:
    runner = InMemoryRunner(agent=hr_agent, app_name="hr_app")
    svc = runner.session_service
    s1 = await svc.create_session(app_name="hr_app", user_id="emp-17",
                                  state={"app:company_name": "Acme Corp"})
    s1 = await svc.get_session(app_name="hr_app", user_id="emp-17", session_id=s1.id)
    s1.state["user:language"] = "German"
    msg = types.UserContent(parts=[types.Part(text="How much parental leave do I get?")])
    async for ev in runner.run_async(user_id="emp-17", session_id=s1.id, new_message=msg):
        if ev.is_final_response():
            print(ev.content.parts[0].text)
asyncio.run(main())

SymptomThe first turn crashes before the model call, one line after line 17 set the language. HintLine 17 sets the key. Which object did it change? Causeget_session() returns a copy. Only events write stored state. FixSend the key as state_delta on line 19 (left).

Show the script and the KeyError, then give the room one minute. The template on line 8 is rendered from the state that the session service stores, not from the Python object in main. In google-adk 2.13.0, get_session() on the in-memory service returns a deep copy, so line 17 changes only that copy and the key never reaches storage. The fix is to write state through an event: state_delta on run_async, or seed it in create_session(state=...), or make it optional with {user:language?}. Inside the agent, tools write through tool_context.state and callbacks through callback_context.state; both go through events too. Analogy: you corrected a photocopy of the form and then handed the clerk the original. Likely follow-up: "Why a copy at all?" So that only events change persisted state, which keeps the event log the single source of truth. This is the same hr_app and emp-17 from the state Q&A slide, so link the answer back to Q1 there.
