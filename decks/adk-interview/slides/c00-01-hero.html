This deck drills ADK 2.0 interview questions in five topic areas. On every question, say the mechanism, the failure mode, one number and the fix, in that order, like a bug report. Press through run A: intake stores the ticket, the classify LLM labels it "outage", the route_ticket function emits that label as the route, and the "outage" edge pages on-call. Then run B: the label "other" has no edge, so DEFAULT_ROUTE sends the ticket to human_queue instead of ending the branch with only a log warning. Lab 0, two slides on, builds this exact graph in code, so the names here are the names you will see there. Analogy: the LLM is the triage nurse who writes the label, and the edge map is the hospital protocol that picks the ward. A likely student question is "why is route_ticket not an LLM?": the route is a rule, so a function costs no LLM call and never misroutes on a typo.
