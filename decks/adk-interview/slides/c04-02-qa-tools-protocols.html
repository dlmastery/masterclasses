Read each question, pause, and let the students answer before you reveal the model answer. Q1 is the interface: the docstring is the tool description, so treat it like an API contract. The 92-100% figure comes from a two-tool test in 2610.14334: all five models picked the first-listed tool, so position bias is real and the descriptions must be distinct; Vercel cut 17 tools to 2 and got 3.5x faster. Q2 is trust: A2A connects to an agent that you do not control, session state does not cross, and the agent card at /.well-known/agent-card.json advertises skills and auth schemes but does not enforce them, so authenticate every request (RemoteA2aAgent takes auth_scheme and auth_credential). Analogy: MCP is a vending machine with labelled buttons; A2A is a phone call to a colleague in another department. Q3 is failure: after a restart the tool returns an error dict, not an exception, so nothing crashes and nothing alerts; google-adk 2.10.0 fixed the reuse of the dead session. Alert on the error string, fail startup when get_tools() is empty, and write errors that name the next tool call: recovery rose from 45% to 84% (2609.35381). Likely follow-ups: 91.8% of 414 internet-facing MCP servers lacked OAuth (2608.00150); the legacy MCP handshake costs 3 round trips and 230 ms, against 1 round trip and 61 ms for A2A (2610.30151).
