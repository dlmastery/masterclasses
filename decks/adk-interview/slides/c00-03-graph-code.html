ticket_triage/agent.py · part 1 of 2
from typing import Literal
from google.adk import Agent, Event, Workflow
from google.adk.workflow import DEFAULT_ROUTE
from pydantic import BaseModel

class Triage(BaseModel):
  labels: list[Literal["billing", "outage", "other"]]
  priority: Literal["p1", "p2", "p3"]

def intake(node_input: str):
  yield Event(state={"ticket": node_input})

classify = Agent(name="classify", model="gemini-3.5-flash",
    instruction="Classify this support ticket. Ticket: {ticket}",
    output_schema=Triage, output_key="triage")

Literal labels: a reply such as "Billing" fails validation, so it cannot misroute.
intake writes state["ticket"]. {ticket} in any instruction reads it.
output_schema=Triage makes the reply validated JSON. output_key also stores it in state.

Run every command from the parent folder: adk run loads root_agent from ticket_triage/agent.py, and a Workflow is a valid root_agent. adk run with a quoted query sends one message and exits; without the query it opens an interactive session. Step 1: the labels are a Literal list, so a typo like "Billing" fails validation instead of misrouting. Step 2: intake yields Event(state=...), and the {ticket} placeholder in an instruction reads that state key. Step 3: output_schema validates the reply, output_key stores it in state, and the Triage object becomes the next node's node_input. gemini-3.5-flash is also LlmAgent.DEFAULT_MODEL in 2.13.0, but pin it anyway. Analogy: the LLM is the triage nurse who writes a label from a fixed list. A likely student question is "why a list of labels?": one ticket can be both billing and outage, and part 2 shows what a list route does.
