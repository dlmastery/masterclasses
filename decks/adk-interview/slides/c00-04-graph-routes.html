Lab 0: a function picks the route, DEFAULT_ROUTE catches the rest

ticket_triage/agent.py · part 2 of 2 (Triage, intake, classify are in part 1)
def route_ticket(node_input: Triage):
  yield Event(output=node_input.model_dump(),
              route=list(node_input.labels))

billing = Agent(name="billing", model="gemini-3.5-flash",
    instruction="Draft a billing reply for: {ticket}")

def page_oncall(node_input: dict):
  yield Event(message=f"PAGED on-call (priority={node_input['priority']}).")

def human_queue():
  yield Event(message="Routed to the human L1 queue.")

root_agent = Workflow(name="ticket_triage", edges=[
    ("START", intake, classify, route_ticket),
    (route_ticket, {"billing": billing, "outage": page_oncall,
                    DEFAULT_ROUTE: human_queue}),
])

route_ticket is a function node: 0 LLM calls. With a list route, every label that has an edge runs its branch.
node_input is the previous node's output: model_dump() gives page_oncall a dict. A node may omit it.
If no emitted label has an edge, DEFAULT_ROUTE sends the ticket to human_queue.

Part 2 finishes the graph. Step 1: route_ticket is plain code, and one Event carries both the payload and the route. A list route runs every branch whose label has an edge, so ["billing", "outage"] runs billing and page_oncall. Step 2: node_input is the previous node's output; a pydantic model goes in, model_dump() sends a dict out, and a function node may omit node_input, as human_queue does. The billing Agent reads {ticket} from state instead. Step 3: DEFAULT_ROUTE fires only when no emitted label matches an edge. Step 4: without it, run B ends with only that log warning and no error. Likely student question: "what about labels ["billing", "other"]?" Billing matches, so DEFAULT_ROUTE does not fire and "other" is dropped without a trace; if that matters, give "other" its own edge to human_queue. Analogy: the edge map is the hospital protocol that picks the ward.
