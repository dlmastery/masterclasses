# lab1_docling_claims.py
import json, sys
from pathlib import Path
from docling.chunking import HybridChunker
from docling.datamodel.base_models import InputFormat
from docling.datamodel.pipeline_options import PdfPipelineOptions, TableFormerMode
from docling.document_converter import DocumentConverter, PdfFormatOption
from docling_core.transforms.chunker.tokenizer.huggingface import HuggingFaceTokenizer
from transformers import AutoTokenizer

# Your claims policy PDF; falls back to the public Docling tech report so the lab always runs.
SOURCE = sys.argv[1] if len(sys.argv) > 1 else "https://arxiv.org/pdf/2408.09869"
EMBED_MODEL_ID = "Qwen/Qwen3-Embedding-0.6B"   # chunk with the SAME tokenizer you embed with
MAX_TOKENS = 512

opts = PdfPipelineOptions()
opts.do_ocr = False                      # born-digital PDF: skip OCR (default is True)
opts.do_table_structure = True           # default True; shown for clarity
opts.table_structure_options.mode = TableFormerMode.ACCURATE
converter = DocumentConverter(
    format_options={InputFormat.PDF: PdfFormatOption(pipeline_options=opts)})

result = converter.convert(SOURCE, max_num_pages=60)
doc = result.document
print(f"status={result.status.value} pages={len(doc.pages)} tables={len(doc.tables)}")
out = Path("out"); out.mkdir(exist_ok=True)
(out / "claims_policy.md").write_text(doc.export_to_markdown(), encoding="utf-8")

do_ocr = False reads the text layer. The default is True. Keep OCR on for scans.

ACCURATE is already the default. FAST gives lower table quality for more speed.

Set limits (also max_file_size, page_range) so a 2,000-page upload cannot block a worker.

Save doc.save_as_json(...) to object storage before you chunk. The parse never repeats.

This is the run-it-Monday slide for Lab 2: make a Python 3.12 venv and pin docling 2.142.1, which is now a meta-package for docling-slim[standard] with PDF parsing, the layout and table models, RapidOCR and docling-core chunking. No env vars are needed; on an air-gapped machine run docling-tools models download first. Walk the four focus bands: turn OCR off for born-digital PDFs because the default is on, keep TableFormer in ACCURATE mode, cap the input with max_num_pages, then print status, pages and tables and export Markdown. Analogy: the DoclingDocument JSON is the negative of a photo; save it once and you can print new chunk sizes from it without a re-shoot. The last click is the error you will meet first in production: an encrypted PDF raises ConversionError, so call convert with raises_on_error=False and route non-success results to a dead-letter queue. Likely question: "Why does the import list include HybridChunker if we do not chunk yet?" It is the same script; the next slide adds the chunking half.
