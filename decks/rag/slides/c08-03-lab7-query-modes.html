# part 1 (step 1): imports, MODEL, WORKING_DIR, DOCS, llm_model_func, embedding_func
async def main():
    os.makedirs(WORKING_DIR, exist_ok=True)
    rag = LightRAG(working_dir=WORKING_DIR, llm_model_func=llm_model_func,
                   llm_model_name=MODEL, embedding_func=embedding_func)
    await rag.initialize_storages()                       # REQUIRED (no auto-init)
    try:
        await rag.ainsert(list(DOCS.values()), file_paths=list(DOCS.keys()))
        q = "Which Elm St hail claims must the SIU review together, and who handled them?"
        for mode in ("naive", "local", "global", "mix"):
            ans = await rag.aquery(q, param=QueryParam(mode=mode, include_references=True))
            print(f"--- {mode} ---\n{ans}\n")
    finally:
        await rag.finalize_storages()

if __name__ == "__main__":
    asyncio.run(main())

The first run extracts entities with the LLM. Later runs reuse ./claims_kg and the LLM cache.

initialize_storages() is required: auto_manage_storages_states defaults to False and is deprecated. Close in finally.

file_paths become the citation targets. ainsert always chunks with the fixed-token strategy.

naive reads vector chunks only. It finds one claim and misses the rule that links both.

local follows entity edges: same street, same date, same adjuster. Vector chunks alone miss this cross-document link.

global ranks relations. Modes: local, global, hybrid, naive, mix, bypass.

mix (the default) joins graph and chunks. Prefer it, and cite chunk file paths, not entity summaries.

This is step 2 of the Harbor Mutual lab: we index the three claim files and ask one cross-document question in four modes. First, initialize_storages is required, because automatic storage management defaults to False and is deprecated, and finalize_storages runs in the finally block. Second, ainsert takes the file paths, and those paths become the citation targets that come back as References. Then watch the spotlight: naive reads one vector chunk and misses the guideline, local follows entity edges and sees that both claims share Elm St, the date and Maria Lopez, global ranks the relations, and mix, the default, joins the graph with the original chunks. Analogy: naive reads one folder, the graph is the investigator's pin board with strings between folders, and mix reads the pin board and then the folders it points to. Likely question: "Which mode do I ship?" Start with mix, measure it against naive on your own labelled questions, and cite the chunk file paths in the answer.
