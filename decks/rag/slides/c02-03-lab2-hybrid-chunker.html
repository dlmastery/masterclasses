# continues part 1: json, doc, out, EMBED_MODEL_ID, MAX_TOKENS are defined there
tokenizer = HuggingFaceTokenizer(
    tokenizer=AutoTokenizer.from_pretrained(EMBED_MODEL_ID), max_tokens=MAX_TOKENS)
chunker = HybridChunker(tokenizer=tokenizer, merge_peers=True, repeat_table_header=True)

n = 0
with open(out / "claims_chunks.jsonl", "w", encoding="utf-8") as f:
    for i, chunk in enumerate(chunker.chunk(dl_doc=doc)):
        embed_text = chunker.contextualize(chunk=chunk)        # headings + text
        pages = sorted({p.page_no for item in chunk.meta.doc_items for p in item.prov})
        rec = {
            "chunk_id": f"{doc.origin.filename}#{i}",
            "text": embed_text,
            "raw_text": chunk.text,
            "headings": chunk.meta.headings or [],
            "pages": pages,
            "labels": sorted({item.label.value for item in chunk.meta.doc_items}),
            "tokens": tokenizer.count_tokens(embed_text),
        }
        f.write(json.dumps(rec, ensure_ascii=False) + "\n")
        n += 1
print(f"wrote {n} chunks -> out/claims_chunks.jsonl")

This is the second half of lab1_docling_claims.py: the parsed DoclingDocument from step 1 becomes JSONL chunks in out/claims_chunks.jsonl. Line 2 is the line people forget: if you do not wrap your embedder's tokenizer in HuggingFaceTokenizer, HybridChunker counts MiniLM tokens, so the 512 limit is measured in the wrong unit for Qwen3. Think of it as cutting fabric with a ruler from a different country: the cut looks right but does not fit. Embed the contextualized text, which carries the heading path, and keep raw_text for display; the page numbers from the provenance items let the answer cite page 4, section 3.2. Without a PDF argument the script parses the public Docling report (arXiv 2408.09869), so students can run it anywhere. A likely question is why not embed raw_text: because a table fragment without its heading path does not say which policy or section it belongs to.
