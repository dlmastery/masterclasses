lab6/deep_research_cell.py · after: the agent writes this cell
# OpenSaC runs the cell; only printed output becomes an observation
from opensac import sdk

queries = ["EU PFAS restriction textiles", "PFAS ban outdoor jackets EU"]
pool = sdk.search(queries, limit=10)         # rankings fused locally, one limit
if pool:
    best = sdk.rerank(queries[0], pool[:100], top_n=min(3, len(pool)))
    doc = sdk.content.fetch(best[0].url)     # the page stays in Python
    print(best[0].url, doc.text[:800])       # a bounded extract for the model

arXiv 2610.25779 OpenSaC: Search as Code Repo liuqi6777/OpenSaC
This build adds search as code to the compliance desk's deep-research mode, with OpenSaC from arXiv 2610.25779. OpenSaC searches the public web through providers such as serper and jina, so the desk uses it for public questions, here the EU rules on PFAS in textiles behind a chemical-safety failure; the internal supplier archive stays in Lab 6's store and the rank_first index. It is not on PyPI yet: clone the repo, run pip install . with Python 3.12 or newer, and set the search key, the rerank model and the LLM model next to the provider URLs, as the README lists. Before: a ReAct loop spends one model turn per search or fetch, and all twenty results and both pages land in the context. After: the agent writes one cell; sdk.search sends both reformulations and fuses the rankings locally under one limit (the README does not name the method; the separate fuse helper uses weighted reciprocal rank fusion), rerank and fetch run in the sandbox, and only the URL and an 800-character extract of doc.text become the observation. In the paper's leakage-audited run, with Codex 0.147.0, gpt-5.6-luna at xhigh reasoning and a 30-minute budget, BrowseComp went from 82.25% to 85.21%, mean tokens per task fell from 4,102.9k to 2,552.1k, 37.8% fewer, and cost fell 36.4%. Wide list-gathering tasks lose a little: WideSearch row F1 went from 60.62 to 59.78, 0.84 points down, so measure it on your own tasks. Analogy: you send an intern to the library with a written plan and ask for one page of notes, not a phone call after every shelf. Likely question: "What breaks first?" The SDK has no automatic retries, so a provider timeout kills the cell unless you wrap the calls. Meta's RPL paper (arXiv 2610.24854) trains the same primitives-in-a-sandbox idea with RL: +11.5% EM at 4B. Next: what happens when you train the search policy with RL.
