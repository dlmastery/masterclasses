import asyncio, os, re
from typing import Literal
from pydantic import BaseModel, Field
from google.adk import Agent, Event, Workflow
from google.adk.runners import InMemoryRunner

MODEL = os.getenv("MODEL", "gemini-3.8-flash")
HR_DOCS = {
    "PTO-2026": "Full-time staff accrue 1.75 PTO days per month. "
                "At most 5 unused PTO days carry over into the next year.",
    "PARENTAL-2026": "Birth and adoptive parents get 16 weeks of paid leave after 90 days of employment.",
    "REMOTE-2026": "Staff may work remotely up to 3 days per week with manager approval. "
                   "Working abroad over 30 days needs HR approval.",
}

class Route(BaseModel):
    category: Literal["hr_policy", "it_support", "out_of_scope"]

class Verdict(BaseModel):
    supported: bool = Field(description="True only if EVERY claim in the draft is stated in the evidence")
    unsupported_claims: list[str] = Field(description="Claims of the draft not found in the evidence")

def take_question(node_input: str):
    return Event(state={"question": node_input})

router = Agent(name="router", model=MODEL, output_schema=Route, output_key="route",
               instruction="Classify this employee message: {question}")

def route_on_category(node_input: Route):
    yield Event(route=node_input.category)

def retrieve_hr(question: str, k: int = 2):
    words = set(re.findall(r"[a-z]+", question.lower()))
    ranked = sorted(HR_DOCS.items(), key=lambda kv: -len(words & set(re.findall(r"[a-z]+", kv[1].lower()))))
    return Event(state={"evidence": "\n".join(f"[{d}] {t}" for d, t in ranked[:k])})

The code is step 1 of lab5_helpdesk.py, the one file that the whole lab grows, adapted from the ADK Workflow Routing sample, and every node here is either a plain function or an Agent. Walk the four bands: the imports and the three HR policy documents; take_question writes the question into session state with Event(state=...); the router agent returns JSON that ADK validates against Route and stores as a dict under route, and route_on_category gets a Route object back through its type hint and picks the edge with Event(route=...); retrieve_hr gets question from state only because its parameter has that name. Analogy: state is a shared whiteboard, and each function reads the boxes whose labels match its parameter names. Likely question: "What if I rename the parameter to query?" Then ADK finds no state key with that name and raises WorkflowDataError, which is the gotcha later in this chapter. Next, step 2 wires these nodes into a graph.
