This is the "run it Monday" slide for the whole course. Click 1: make one folder and one Python 3.12 virtual environment. Click 2: install the three Lab 1 packages; every later lab's first slide gives its own pinned install line for the same folder. kb.py holds the Northwind Outfitters corpus (18 chunks) and 15 labelled questions; evalkit.py scores any retriever; you copy both from the Lab 1 slides. Click 3: the first run scores a "retriever" that ignores the question; this floor output was executed on Python 3.12. Clicks 4 to 6: Labs 1 and 2 need no API key, so start there. From Lab 3 you need a Gemini API key, Lab 4 adds Cohere, the chapter 5 build-ups add Anthropic, and Lab 10 needs a Google Cloud project. Likely question: "Can I do everything offline?" Labs 1 and 2 yes; later labs call hosted models.
