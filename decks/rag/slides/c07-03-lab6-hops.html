from typing import Literal
def hop(s: State):
    reg = [dict(r) for r in s["register"]]                       # new list: never mutate s
    i = next(n for n, r in enumerate(reg) if r["a"] is None)      # first open requirement
    q = reg[i]["q"]
    for n, r in enumerate(reg[:i], 1):                            # rows resolve in order,
        q = q.replace(f"#{n}", r["a"])                             # so each #n has an answer
    docs = store.similarity_search(q, k=2 + 2 * reg[i]["tries"])  # widen k on retry
    ctx = "\n".join(f"[{d.metadata['id']}] {d.page_content}" for d in docs)
    res = llm.with_structured_output(Hop).invoke(f"Passages:\n{ctx}\nSub-question: {q}")
    reg[i].update(q=q, tries=reg[i]["tries"] + 1)
    if res.answer != "UNKNOWN" and res.source_id:
        reg[i].update(a=res.answer, src=res.source_id)
    return {"register": reg, "hops": s["hops"] + 1}
# hop again while a row is open and hops < 2 x rows; at the cap, answer() refuses
def next_step(s: State) -> Literal["hop", "answer"]:
    still_open = any(r["a"] is None for r in s["register"])
    return "hop" if still_open and s["hops"] < 2 * len(s["register"]) else "answer"

This slide runs the hop loop of Lab 6, one hop per click, and the second hop misses on purpose so you see the retry. First, hop() builds a new list from the register so it never mutates the input state in place; it returns the new list, and LangGraph's default reducer replaces the register key with it, while keys that a node does not return keep their values. next() then picks the first open row. Second, the hop-1 answer, Kestrel Textiles, replaces #1; rows resolve in order, so every #n already has an answer when it is substituted, and with at most 4 sub-questions there is no #10 to confuse with #1. In this run the k=2 search returns AUD-1 and SUP-5, the model says UNKNOWN, and tries goes to 1. Third, the retry widens k to 2 + 2 × 1 = 4, SUP-4 is now in the passages, and the row resolves with tries 2. Fourth, row 3 resolves and next_step returns answer after 4 hops; the cap is 2 × 3 = 6, and at the cap the answer node refuses, which is the next slide. The output is illustrative: your run may hit SUP-4 at k=2. Analogy: a relay race where each runner must hand over a signed baton. Likely question: "Why not let the model rephrase on a miss?" Widening k is cheaper and deterministic. arXiv 2608.20627 shows why we log the register at every hop: post-hoc coverage diagnosis finds hop-1 faults 91 percent of the time but none at hops 2 and 3, so later-hop faults are invisible after the fact.
