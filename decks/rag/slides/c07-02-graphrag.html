GraphRAG extracts an entity graph, clusters it with Leiden and summarizes every community

  1. Compose TextUnits. Default 1200 tokens (paper: 600, overlap 100).
  2. Extract. An LLM finds entities and relationships per chunk. FastGraphRAG uses NLP.
  3. Summarize. An LLM merges each entity description over all mentions.
  4. Cluster. Hierarchical Leiden makes levels C0 (few, big) to C3 (many, small). No LLM.
  5. Report. An LLM writes a report per community per level. Then embed. Output: parquet.
terminal · getting started

$ python -m pip install graphrag  # 3.3.0 (8 Oct 2026)
$ graphrag init                   # .env, settings.yaml, input/
$ curl https://www.gutenberg.org/cache/epub/24022/pg24022.txt \
    -o ./input/book.txt           # GRAPHRAG_API_KEY in .env
$ graphrag index                  # --method standard | fast
$ graphrag query "What are the top themes in this story?"
$ graphrag query --method local \
    "Who is Scrooge and what are his main relationships?"
$ graphrag query --method drift \
    "How does Scrooge change, and why?"
Cost is set by corpus size, not query count. Each chunk, entity and report is an LLM call: about 1000x vector indexing. The repo is "largely in maintenance mode".

Walk the index pipeline one phase at a time and watch the LLM-call counter. Chunks first; then an LLM reads every chunk and pulls out entities and relationships; then an LLM merges the descriptions of each entity. Leiden is plain graph maths with no LLM: it finds dense groups, then groups of groups, so you get levels from C0 at the top to C3 at the bottom. Then the expensive part: one LLM report for every community at every level. Analogy: a newsroom that writes a briefing for every desk, every department and the whole paper before anyone asks a question. Global search map-reduces over those briefings; local search starts from entities; DRIFT mixes the two. Likely question: "Why is it so expensive?" Because every LLM phase scales with the corpus, which is about 1000x vector indexing, and the project is now in maintenance mode.
