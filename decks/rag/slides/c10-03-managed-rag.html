file_search.py · Gemini API, Interactions API

import time
from google import genai                       # google-genai 2.33.0
client = genai.Client()
store = client.file_search_stores.create(config={
    "display_name": "my-store",
    "embedding_model": "models/gemini-embedding-2"})   # images need -2

op = client.file_search_stores.upload_to_file_search_store(
    file="sample.txt", file_search_store_name=store.name,
    config={"display_name": "display-file-name"})
while not op.done:                     # service parses, chunks, embeds
    time.sleep(5); op = client.operations.get(op)

interaction = client.interactions.create(
    model="gemini-3.8-flash", input="Can you tell me about ...",
    tools=[{"type": "file_search", "file_search_store_names": [store.name]}])
for step in interaction.steps:
    if step.type == "model_output":
        for b in step.content:
            if b.type == "text":
                print(b.text, [a.file_name for a in (b.annotations or [])
                               if a.type == "file_citation"])
Step 1 builds the Google ladder from the bottom: BigQuery VECTOR_SEARCH, where you write one SQL statement and own every choice, up to Gemini File Search, where Google parses, chunks, embeds, stores and cites. The shading shows who manages the pipeline; the shares are illustrative. Step 2 compares the five managed services across clouds. Point at File Search pricing: storage and query embeddings are free, and you pay embedding rates only at indexing time. Point at Azure: agentic retrieval plans subqueries with an LLM and costs about $4.32 for 2,000 retrievals in the docs example. The rename callout matters in practice: in April 2026 Vertex AI became Gemini Enterprise Agent Platform, so old tutorials use old names and the old vertexai.rag SDK. Steps 3 to 6 walk the File Search code: create a store, upload and poll, call the file_search tool, then read the file_citation annotations. Analogy: managed RAG is a hotel; DIY RAG is your own house. The hotel is ready tonight, but you cannot move the walls. Likely question: "When would you leave File Search?" When you need custom chunking, hybrid weights, a specific reranker or ACL logic it does not expose.
