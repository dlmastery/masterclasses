import sys, time

def wait_indexed(client, op):                 # File Search: never query before indexing ends
    while not op.done:
        time.sleep(5)
        op = client.operations.get(op)
    return op

def cited_span(block, a) -> str:              # FileCitation offsets are BYTES
    raw = block.text.encode("utf-8")
    return raw[(a.start_index or 0):(a.end_index or 0)].decode("utf-8", "ignore")

EXPECTED_FILES = 14
def check_import(imp) -> None:                # partial failures do not raise
    done = imp.imported_rag_files_count + imp.skipped_rag_files_count
    if imp.failed_rag_files_count or done != EXPECTED_FILES:
        sys.exit(f"import incomplete, see {imp.partial_failures_gcs_path}")

def best_first(ctx) -> list:                  # score is a distance: lower is better
    return sorted(ctx.contexts.contexts, key=lambda c: c.score)

Managed RAG removes the index work, but each of these three failures is silent, so the guards must live in your code. File Search indexes asynchronously: a query sent before the operation is done gets no grounding and no error, citation offsets are bytes so a Python string slice drifts on the euro sign or an umlaut, and the store is Developer API only, so an enterprise client raises the ValueError shown. RAG Engine returns success when 13 of 14 handbook PDFs import, and a Drive import without folder permission imports nothing at all, so count every file you expect and keep a result sink. Its context score is a distance, so lower is better and a descending sort puts the worst chunk on top. Analogy: a courier who leaves the parcel at the wrong door still marks it delivered. Likely question: "Why not just retry the import?" Retry is fine, but only the count tells you that you need one, and the quota allows only 3 concurrent imports per region.
