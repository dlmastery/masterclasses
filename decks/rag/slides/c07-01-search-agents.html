Chapter 7 is Lab 6: an Acme Outfitters compliance analyst asks who must approve a return of the jacket made by the supplier that failed the March 2026 audit, and no single passage answers that. The animation shows the whole lab: the planner splits the question into three linked sub-questions, each hop fills one register row with an answer and a source id (AUD-1, SUP-4, RET-2), and the gate under the register stays closed until all three rows are filled. The register is simply a table with one row per sub-question: the question, the answer, the source id and the retry count. The lede is the failure attribution finding of this quarter (arXiv 2608.20627): a hop-1 retrieval error shows up as a wrong answer at hop 3, so we log every hop. Analogy: a detective's case board, where every pinned fact has its evidence tag and nobody names the suspect while a card is still blank. After the lab, we scale the desk with 2026 papers on rank-first discovery (arXiv 2607.26497), search as code (OpenSaC, arXiv 2610.25779), RL-trained search agents, and PayPal's SCOUT MCP gateway (arXiv 2608.23992). The register idea comes from arXiv 2610.21184, Beyond Retrieval Failure. Likely question: "Why not let one ReAct agent search freely?" Because free search drifts away from the open sub-question; the register keeps every search tied to one named requirement. Next: the first Lab 6 slide sets up the store and the planner.
