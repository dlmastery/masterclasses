Monday checklist: ten rules for shipping RAG in October 2026

  • Run a 100-300 query labelled set and evalkit floor in CI.
  • Parse once, pinned; chunk with the embedder's tokenizer.
  • Content-hash chunk IDs. One index per model + dim.
  • Hybrid + rerank, checked per corpus. Pin RRF k.
  • Score-gate rewrites and loops; budgets in code.
  • Cite raw chunks or byte spans. Summaries score 0.12.
  • Gate releases on recall, canaries, calibrated judge.
  • Filter by groups in the query; nightly injection tests.
  • Budget each stage. Cache only non-personal, policy-scoped answers.
  • Chunk or embedder change = new corpus. Delete test stores.
  • Federate live MCP calls. Up to 45 s vs seconds.
  • Ship a part untested in the full stack. +47% → +17%.
