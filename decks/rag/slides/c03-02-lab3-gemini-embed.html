import time
import numpy as np
from google import genai
from google.genai import errors, types
client = genai.Client()                       # GEMINI_API_KEY / GOOGLE_API_KEY
MODEL, DIM, BATCH = "gemini-embedding-001", 768, 100
TICKETS = [
    ("TKT-1042", "Login loop after Okta SSO", "Clear the stale session cookie; re-sync the SAML clock skew."),
    ("TKT-1077", "Claim PDF upload fails", "Files over 20 MB are rejected; compress or split the PDF."),
    ("TKT-1103", "Refund not received", "Refunds post 5-7 business days after approval to the original card."),
    ("TKT-1150", "Duplicate premium charge", "Void the second authorization in Billing > Transactions."),
]
def embed(texts: list[str], task_type: str) -> np.ndarray:
    vecs = []
    for i in range(0, len(texts), BATCH):
        cfg = types.EmbedContentConfig(task_type=task_type, output_dimensionality=DIM)
        for attempt in range(5):
            try:
                resp = client.models.embed_content(model=MODEL, contents=texts[i:i + BATCH], config=cfg)
                break
            except errors.APIError as err:
                if err.code in (429, 500, 503) and attempt < 4:
                    time.sleep(2 ** attempt)
                    continue
                raise
        vecs.extend(emb.values for emb in resp.embeddings)
    v = np.asarray(vecs, dtype=np.float32)
    return v / np.linalg.norm(v, axis=1, keepdims=True)   # REQUIRED for 001 below 3072 dims
D = embed([f"{title}\n{body}" for _, title, body in TICKETS], "RETRIEVAL_DOCUMENT")
q = embed(["customer says money from cancelled policy never arrived"], "RETRIEVAL_QUERY")
scores = (D @ q.T).ravel()
for idx in np.argsort(-scores):
    print(f"{scores[idx]:.3f}  {TICKETS[idx][0]}  {TICKETS[idx][1]}")
print("shape:", D.shape, "norm[0]:", round(float(np.linalg.norm(D[0])), 4))

Retry only 429, 500 and 503. Sleep 1, 2, 4, 8 s, then raise.

Unit rows make D @ q.T the cosine. Store MODEL and DIM with the index.

This is the run-it-Monday slide for Lab 3: pin google-genai 2.33.0, export GEMINI_API_KEY, and run lab4_gemini_tickets.py inside northwind_index. If both GOOGLE_API_KEY and GEMINI_API_KEY are set, the client warns and uses GOOGLE_API_KEY, so remove the one you do not mean. Walk the four bands: asymmetric task types (gemini-embedding-001 only, and title applies to the whole request), retry on 429/500/503 with 1, 2, 4, 8 second sleeps and then raise, the normalisation the Embeddings guide requires below 3072 dimensions, and the dot product that is only a cosine because rows are unit length. Analogy: a vector without its norm is a compass needle of random length; you can still read the direction only after you make every needle the same length. Likely question: "How do I embed 100k tickets cheaply?" Use the Batch API, which the guide prices at 50% of the default, and pin MODEL and DIM in config so a query from another model is refused. Hand-off: the tickets may go to Google, but the claims policy may not, so step 2 embeds the Lab 2 claims chunks on our own machines.
