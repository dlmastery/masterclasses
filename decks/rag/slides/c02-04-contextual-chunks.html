Prompt caching stores the document once. Every chunk call reads it from the cache. “All these benefits stack.”

situate.py · adapted from the blog prompt

import anthropic
client = anthropic.Anthropic()
def situate(doc: str, chunk: str) -> str:
    msg = client.messages.create(
        model="claude-haiku-4-5",  # illustrative; blog used Claude 3 Haiku
        max_tokens=150,
        system=[{"type": "text", "text": f"<document>\n{doc}\n</document>",
                 "cache_control": {"type": "ephemeral"}}],  # cached once
        messages=[{"role": "user", "content":
            f"Here is the chunk we want to situate within the whole document\n"
            f"<chunk>\n{chunk}\n</chunk>\n"
            "Please give a short succinct context to situate this chunk within "
            "the overall document for the purposes of improving search "
            "retrieval of the chunk. Answer only with the succinct context "
            "and nothing else."}])
    return msg.content[0].text + "\n\n" + chunk  # index for dense AND BM25
Start with the problem chunk: alone, it does not say which company or which quarter, so neither the embedder nor BM25 can match a query that names them. Step 1, late chunking: run the long-context embedder over the whole document first, then mean-pool each chunk's token span; the token "Its" now carries attention from "Berlin", so the cosine rises from 0.708 to 0.825. Step 2, Contextual Retrieval: an LLM writes a short context note for each chunk, and you index note plus chunk in both the dense and the BM25 index. Step 3: the gains stack, from 5.7% to 1.9% failures with reranking. Steps 4 and 5: the cache_control block is the reason this is cheap, about $1.02 per million document tokens, because the document is written to the cache once and read for every chunk. Analogy: late chunking reads the whole book before it summarizes a page; Contextual Retrieval writes a header on each index card. Likely question: "Which fix do I choose?" Answer: late chunking needs an open long-context embedder with token outputs; Contextual Retrieval works with any embedder and also fixes BM25, but costs one LLM call per chunk.
