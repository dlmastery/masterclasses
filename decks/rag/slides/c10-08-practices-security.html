Best practices

Security rules: token groups, filters on every path, nightly tests

Do · identity and filters

  • Take groups from the verified OIDC token. Never from the prompt.
  • One ACL filter on dense, BM25, reranker input and cache.
  • One namespace per tenant when a contract requires isolation. Rovo: one per customer.
  • CI: leak test per user × golden query, plus a hidden-text canary PDF.

Do · content and infra

  • Layer defenses: least-privilege tools, datamarking, a detector, egress allowlist.
  • Store valid_to; hide unvetted new docs after a deadline. 34 → 7 (2610.05826)
  • Sign GraphRAG summaries after the build. 88–94% ASR from 0.016% edits
  • Upgrade pgvector to 0.8.7. CVE-2026-3172; no backports.

Don't

  • Do not post-filter top-k. Maria gets [].
  • "No verbatim leakage" is not no leakage. 3 queries recover 48.3%.

harbor_claims/secure.py · chromadb 1.5.9 · psycopg 3.3.6 · pgvector 0.8.7
import os
import chromadb
import psycopg
from harbor_claims.guards import acl_where, norm_groups   # the gotcha fixes

col = chromadb.PersistentClient(path="./claimskb").get_collection("claims_kb")
def groups_from_token(claims: dict) -> list[str]:
    """claims: the verified OIDC ID-token payload, never model output."""
    return norm_groups(claims.get("groups", []))

def secure_search(claims: dict, query: str, k: int = 5):
    where = acl_where(groups_from_token(claims))
    res = col.query(query_texts=[query], n_results=k, where=where)   # filter in the ANN search
    return list(zip(res["ids"][0], res["distances"][0]))

# pgvector: upgrade, then verify (only the latest release is supported)
conn = psycopg.connect(os.environ["PG_DSN"], autocommit=True)
conn.execute("ALTER EXTENSION vector UPDATE")
ver = conn.execute("SELECT extversion FROM pg_extension WHERE extname = 'vector'").fetchone()[0]
assert ver == "0.8.7", f"pgvector {ver}: install 0.8.7, then ALTER EXTENSION"
