Chapter 6 is Lab 5: we build the Northwind People and IT helpdesk as an ADK 2.13.0 Workflow graph, step by step. The animation shows the whole lab in one loop: a message enters the router, and an HR question runs retrieve_hr, grader, answerer and a separate verifier; when the first retrieval is weak, a routed back-edge rewrites the query and the attempt badge goes from 1/3 to 2/3; an IT question goes to it_triage, which searches the known-issues KB first; a pizza order gets a polite refusal. The point of the lede is cost: every agent step adds latency and tokens, so we add a route or a retry only where it changes the answer. Analogy: a hospital triage desk sends each patient to one ward, and a second doctor signs off before discharge. Likely question: "Why not one big agent with all the tools?" Because a graph keeps the budget, the order of tools and the verifier in code, where you can test them; the Dropbox case later in this chapter shows the other side of that trade-off.
