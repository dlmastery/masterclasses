# lab5_cross_encoder.py -- hybrid top-20 -> cross-encoder -> top-10
import time
from sentence_transformers import CrossEncoder
from kb import TEXT
from evalkit import evaluate
from lab3_hybrid import hybrid_search

reranker = CrossEncoder("cross-encoder/ms-marco-MiniLM-L6-v2", max_length=512)

def rerank_search(query: str, candidates: int = 20, keep: int = 10) -> list[str]:
    cand_ids = hybrid_search(query)[:candidates]
    hits = reranker.rank(query, [TEXT[i] for i in cand_ids], top_k=keep, batch_size=32)
    return [cand_ids[h["corpus_id"]] for h in hits]   # corpus_id = position in cand_ids

if __name__ == "__main__":
    q = "zipper broke on my pack after 3 years"
    docs = [TEXT[i] for i in hybrid_search(q)[:5]]
    for h in reranker.rank(q, docs, return_documents=True):
        print(f'{h["score"]:7.2f}  {h["text"][:60]}')
    evaluate("hybrid", hybrid_search)
    t0 = time.perf_counter()
    evaluate("hybrid + MiniLM-L6 CE", rerank_search)
    ms = (time.perf_counter() - t0) / 15 * 1000
    print(f"rerank latency per query: {ms:.0f} ms (CPU)")

One forward pass per (query, chunk) pair. Pairs over 512 tokens are cut: rerank child chunks.

rank() scores all pairs and returns sorted dicts. corpus_id is the position in your list.

Map positions back with cand_ids[...]. Gold chunk c09 climbs from rank 3 to rank 1.

score is a raw logit (Identity activation). Never threshold at 0.5.

Reranking only reorders. Anthropic's Contextual Retrieval setup retrieved 150 and kept 20.

Step 3 of Lab 4 adds the second stage: the hybrid list goes into a cross-encoder that reads the query and each chunk together and writes one score per pair. Walk the bands: max_length=512 truncates long pairs, rank() returns sorted dicts whose corpus_id is a position, cand_ids maps it back to business ids, and the score is a raw logit for this model, so a 0.5 threshold would keep only one chunk. On the board, the scan writes a logit on each of the 18 candidates (the knowledge base only has 18 chunks), then the cards re-sort and the gold chunk c09 for q14 climbs from rank 3 to rank 1; the logits for the five printed pairs match the output pane, the others are illustrative. Analogy: hybrid search is a fast first interview that builds a shortlist; the cross-encoder is the slow second interview that reads each candidate in full against the job. Likely question: "Why not rerank the whole corpus?" Cost grows linearly with candidates, and reranking cannot add a chunk that first-stage retrieval missed, so retrieve wide and rerank narrow, as Anthropic did with 150 retrieved and 20 kept; measure the latency on your own CPU, because the research has no measured figure. Hand-off: step 4 sends the same 20 candidates to hosted rerankers, Cohere Rerank v5 and Voyage rerank-3, and uses Cohere's relevant spans to shrink the context.
