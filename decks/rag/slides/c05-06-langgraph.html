agentic_rag.py · langgraph 1.2.16 · langchain 1.4.7

@tool
def retrieve_blog_posts(query: str) -> str:
    """Search and return information about Lilian Weng blog posts."""
    return "\n\n".join(d.page_content for d in _get_retriever().invoke(query))
class GradeDocuments(BaseModel):
    binary_score: str = Field(description="'yes' if relevant, 'no' if not")
def grade_documents(state) -> Literal["generate_answer", "rewrite_question"]:
    q, ctx = state["messages"][0].content, state["messages"][-1].content
    msg = GRADE_PROMPT.format(question=q, context=ctx)
    r = response_model.with_structured_output(GradeDocuments).invoke(
        [{"role": "user", "content": msg}])
    return "generate_answer" if r.binary_score == "yes" else "rewrite_question"
wf = StateGraph(MessagesState)
wf.add_node(generate_query_or_respond)
wf.add_node("retrieve", ToolNode([retrieve_blog_posts]))
wf.add_node(rewrite_question); wf.add_node(generate_answer)
wf.add_edge(START, "generate_query_or_respond")
wf.add_conditional_edges("generate_query_or_respond",
    lambda s: "tools" if s["messages"][-1].tool_calls else END,
    {"tools": "retrieve", END: END})
wf.add_conditional_edges("retrieve", grade_documents)   # CRAG-style gate
wf.add_edge("rewrite_question", "generate_query_or_respond")  # loop
wf.add_edge("generate_answer", END); graph = wf.compile()
This is the LangGraph docs example "Build a custom RAG agent", trimmed. Step one: the retriever is a plain function with the @tool decorator, so the LLM in generate_query_or_respond can choose to call it or to answer at once; that is the router. Step two: the grader uses with_structured_output and a Pydantic model, so it can only say yes or no, and grade_documents returns the name of the next node. Step three: the conditional edges make the graph a CRAG-style gate after retrieval. Step four: the rewrite edge goes back to generate, which closes the corrective loop; watch the token take the second pass. Analogy: a quality gate on a factory line that sends a bad part back to rework. Likely question: "What stops this loop?" Nothing in this sample; in production add an iteration counter to the state and route to a "not found" answer when it hits the cap.
