harbor_kg/case_memory.py · sentence-transformers 6.2.0
# AFTER: raw turns + dense retrieval + cross-encoder rerank
from sentence_transformers import CrossEncoder, SentenceTransformer

emb = SentenceTransformer("Qwen/Qwen3-Embedding-0.6B")
rr = CrossEncoder("cross-encoder/ms-marco-MiniLM-L6-v2")
turns: list[str] = []                 # "speaker: text [date]", never rewritten

def remember(turn: str) -> None:
    turns.append(turn)

def recall(q: str, k_dense: int = 50, k_final: int = 10) -> list[str]:
    E = emb.encode_document(turns, normalize_embeddings=True)
    qv = emb.encode_query(q, normalize_embeddings=True)
    top = emb.similarity(qv, E)[0].argsort(descending=True)[:k_dense].tolist()
    cand = [turns[i] for i in top]
    return [cand[h["corpus_id"]] for h in rr.rank(q, cand, top_k=k_final)]

This build gives the Harbor Mutual adjuster assistant a long-term memory of past case discussions, and it starts from the Mem0 quickstart, where an LLM extracts facts from each turn and decides ADD, UPDATE, DELETE or NOOP. The after version is about 15 lines: keep every turn word for word with speaker and date, retrieve with the Qwen3 embedder, and rerank with a cross-encoder, the same calls as Labs 3 and 4. The October paper "Naive RAG Is Stronger Than We Thought" found that this Raw-RAG baseline was first in 6 of 7 benchmark settings, scored 93.70 on LoCoMo against 62.92 for Mem0, ingested and searched 10 MEME episodes in 305.91 seconds against 4,142.95, and lost 19.62 points when it switched to atomic facts. Analogy: a court keeps the full transcript, not a clerk's summary, because you cannot know today which detail matters next year. The counterpoint is MemPABench: for how a user wants to be helped, retrieval memory did not beat no memory, so put preferences in an explicit profile file. Likely question: "What about conflicting or outdated turns?" The paper notes that strong readers resolve state changes from dated raw turns; a weak reader may still need explicit updates, and the next slide shows Uber's time-decay weight.
