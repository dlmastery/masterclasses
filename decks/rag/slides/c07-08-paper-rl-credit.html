lab6/grounded_share.py · answer-in-retrieved, a cheap proxy for ToolHit
import json
from lab6_multihop_register import app, store
GOLD = {"Who must approve a return of the jacket made by the supplier "
        "that failed the March 2026 audit?": "Priya Natarajan"}   # add your labelled questions
with open("lab6_runs.jsonl", "w") as f:                          # 1) log one line per run
    for q, gold in GOLD.items():
        out = app.invoke({"question": q}, {"recursion_limit": 20})
        seen = [d.page_content for r in out["register"]           # re-run each final hop search
                for d in store.similarity_search(r["q"], k=2 + 2 * (r["tries"] - 1))]
        em = int(gold.lower() in out["answer"].lower())           # lenient exact match
        f.write(json.dumps({"em": em, "gold": gold, "retrieved": seen}) + "\n")
runs = [json.loads(line) for line in open("lab6_runs.jsonl")]   # 2) score the log
correct = [r for r in runs if r["em"]]
hit = [r for r in correct if any(r["gold"].lower() in p.lower() for p in r["retrieved"])]
print(f"EM {len(correct) / len(runs):.2f} · answer-in-retrieved {len(hit) / max(len(correct), 1):.2f}")

The main paper is GCA, Grounded Credit Assignment (arXiv 2610.23148). Define the terms first: EM is exact-match accuracy; GRPO is a reinforcement-learning method that trains the LLM from rewards on whole answers; grounded share is the share of correct answers that the retrieved text supports. Search-R1, an older RL-trained search agent, raises EM on all seven QA sets, yet on Bamboogle its grounded share falls from 84.0% to 42.9% against the base model: the agent learns to answer from memory. GCA adds a small extra reward, ToolHit, which fires when a tool response contains the gold answer; it adds 5.7 EM over Search-R1 at Qwen2.5-3B, and the supported share goes from 76.9% to 93.4%. The two bar pairs are different comparisons, so do not chain them into one story of 42.9 to 93.4. You can use the metric today without RL: the script logs one line per Lab 6 run with a lenient exact match, the gold answer and the passages from each final hop search, then measures answer-in-retrieved, a cheap proxy for ToolHit, not a full check that the evidence supports the answer. Two more papers, as one line each: EG-GRPO (2610.25269) rewards the step that first cites each evidence item, best at weight 0.5, GAIA 34.8 to 45.9 at 4B; BRIDGE (2609.36505) adapts the retriever to agent-issued queries before RL on the policy, +9.6 EM on multi-hop at 3B and +3.4 at 7B. Analogy: a student who guesses right on an open-book exam still fails the audit if no page in the book supports the answer. Likely question: "Do I need RL for any of this?" No; the metric and a retriever fine-tune on agent-issued queries both work with a prompted agent. Next: the desk now calls many MCP servers, so tools need retrieval too.
