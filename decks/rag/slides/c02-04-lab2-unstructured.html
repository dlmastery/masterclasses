# lab2_unstructured_hr.py
from collections import Counter
from pathlib import Path
from unstructured.chunking.title import chunk_by_title
from unstructured.partition.html import partition_html

HR_HTML = Path("data/hr_handbook.html").read_text(encoding="utf-8")
elements = partition_html(text=HR_HTML)
print("element types:", dict(Counter(e.category for e in elements)))

# Character budget: hard max 800, soft max 600, merge sections under 150 chars.
by_chars = chunk_by_title(elements, max_characters=800, new_after_n_chars=600,
                          combine_text_under_n_chars=150)
# Token budget (tiktoken encoding name), mutually exclusive with max_characters.
by_tokens = chunk_by_title(elements, max_tokens=120, tokenizer="cl100k_base")

for name, chunks in [("chars", by_chars), ("tokens", by_tokens)]:
    print(f"\n== {name}: {len(chunks)} chunks")
    for c in chunks:
        origs = c.metadata.orig_elements or []
        print(f"[{c.category}] {len(c.text):>4} chars from {len(origs)} elements",
              f"| {c.text[:70]!r}")
        if c.metadata.text_as_html:
            print("   table html kept:", c.metadata.text_as_html[:60], "...")

Step 3 of Lab 2 moves from the claims PDF to the Northwind Mutual HR handbook, data/hr_handbook.html, in the same Python 3.12 venv. Unstructured works in two passes: partition turns each HTML tag into a typed element, and chunk_by_title groups elements into chunks that never cross a heading. Walk the right side: first the raw tags, then the typed chips, then the four chunk boxes, with the table alone in its own amber chunk. A chunk is like a folder per section of the handbook: the Title is the folder label, and a table always gets its own folder. Point out the two exact ValueErrors, because both come from mixing budgets: either raise max_characters with combine_text_under_n_chars, or use max_tokens alone. For citations, orig_elements keeps the source elements, and text_as_html keeps the table rows, so index the HTML or a Markdown rendering for table chunks. A likely question is why the soft max is 600: at about 75 percent of the hard max, sections close at a natural boundary instead of a hard cut mid-sentence. Note that cl100k_base is not the Qwen3 tokenizer from step 2, so keep the token budget below the embedder limit. Next: the refund policy is Markdown, and step 4 shows what a naive window does to it.
