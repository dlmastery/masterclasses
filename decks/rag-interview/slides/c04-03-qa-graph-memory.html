def remember(db, user, key, value, now):        # "I moved to Berlin"
    db.execute("UPDATE memory SET valid_to=? WHERE user=? AND key=?"
               " AND valid_to IS NULL", (now, user, key))   # close Paris
    db.execute("INSERT INTO memory VALUES (?,?,?,?,NULL)",
               (user, key, value, now))                     # open Berlin

Is Complex Agentic Memory Always Needed? Naive RAG Is Stronger Than We Thought

Raw-RAG won 6 of 7 settings, by +0.13 to +5.53 points. Atomic-fact extraction cost -19.62; removing the reranker cost -3.92.

Ask each question and let the candidate answer before you reveal the model answer; the answered question dims when you move on. Q1 tests cost judgement: a strong candidate prices the graph and uses it to locate passages, then answers and cites from the source text, which is what LightRAG aquery_data in mix mode gives you (it returns entities, relations, chunks and references with no LLM answer). gemini_llm and gemini_emb are thin wrappers around lightrag.llm.gemini, and LightRAG reads GEMINI_API_KEY, not GOOGLE_API_KEY. Extra numbers if asked: LLM-free traversal gave over 100x lower latency and over 99% lower cost than GraphRAG Global and DRIFT (LiteRAG, 2609.10239); and an attacker who edits 0.016% of GraphRAG's auxiliary structures (community summaries and scores) reached 88-94% attack success (2610.02373), so sign or verify summaries after the index build. Q2 checks user scoping and temporal invalidation, not overwrite: close the Paris row with valid_to, keep it, and "where did I live last year?" still answers Paris. Analogy: valid_from and valid_to are like the stamps in a passport; you do not erase the old address, you close it. Keeping stale facts live is harmful: stale documents flipped 30% (Llama) and 37% (Qwen) of correct answers (2609.31342). Q3 tests whether the candidate builds the strong simple baseline first. The bars show one of the 7 settings, LoCoMo (a long chat-memory QA benchmark) with a GPT-4.1-mini reader. ReFind: agent-controlled BM25 over raw chat beat structured memory, 58.2 vs 53.2 on MemoryAgentBench. Analogy for Q1: a graph is a map of the library, but you still read the book before you quote it. Likely follow-up: "How do you evaluate memory?" Add knowledge-update and stale-fact questions to the golden set and score them on their own.
