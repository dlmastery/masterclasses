Judge vs human agreement (Cohen's κ)

κ = agreement beyond chance (0 = chance, 1 = perfect). admit rate = share of unsupported claims that the judge marks "supported".

lab3_judge_calibrate.py · scikit-learn==1.9.1
from sklearn.metrics import cohen_kappa_score
# CTX, GOLD = [(answer, human_label)], judge(): in the lab file
model = "gemini-3.5-flash-lite"
human = [h for _, h in GOLD]
pred = [judge(CTX, a, model)[0].verdict for a, _ in GOLD]
kappa = cohen_kappa_score(human, pred)
bad = [p for p, h in zip(pred, human) if h != "supported"]
admit = sum(p == "supported" for p in bad) / len(bad)
print(f"kappa={kappa:.2f} admit={admit:.0%}")
# kappa=0.71 admit=33%   (illustrative)

eval_gate.py · canary check · standard library only
# canary: {"question": "Can I return a gift card?", "canary": true}
ABSTAIN = ("i don't know", "not in the knowledge base")
canary = [g for g in gold.values() if g["canary"]]  # golden.jsonl
def abstained(r):                                   # runs/candidate.jsonl
    return any(m in r["response"].lower() for m in ABSTAIN)
rate = sum(abstained(run[g["id"]]) for g in canary) / len(canary)

Ask each question and let the candidate answer before you reveal the step. For question 1, a strong answer separates support from usefulness and adds a retrieval metric that needs no judge, then names the all-constraint number: 80% per constraint in EnterpriseRAG, but only 26.8% of answers meet all of them. A follow-up point: an answer that copies the context verbatim scores high faithfulness but can be useless (arXiv 2610.18442). For question 2, use this analogy: you calibrate a new thermometer against a reference before you trust it, and the reference here is adjudicated human labels with a human-vs-human ceiling of 0.69, so 0.69 is the ceiling, not a target to beat. The trap is to compare judges on accuracy only; the unsupported-admit rate shows which judge lets bad claims through. Extra numbers if asked: a cheap judge scored AUROC 0.603 against 0.783 for gpt-4o on RAGBench (AGO, 2610.01218), DoorDash found more than half of audited human labels wrong, and running the judge at temperature 0 cut answer disagreement from 14.3% to 3.4% (2610.05034). For question 3, the number to remember is 16.7% vs 98.1% canary violations at the same 97 to 98% accuracy, so a canary set with zero tolerance belongs in the CI gate. Likely follow-up: "How many human labels do you need?" Keep at least 100 labelled claims per domain and re-calibrate after any judge model or prompt change.
