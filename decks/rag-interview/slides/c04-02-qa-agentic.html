Ask each question, give the room 20 seconds, then reveal the answer; the answered question dims when you move on. Q1 tests whether the candidate starts with the cheapest control: a constrained enum router with structured output, measured on routing accuracy, and a clear price for agentic latency. Airbnb's skill agent (a SKILL.md plus one hybrid search tool, run in a loop) took about 90 s, against 8-9 s for their production assistant (arXiv 2610.14428); simple score or uncertainty triggers often match learned routers (arXiv 2607.24010). Q2 is the most common production failure: a strong answer puts a counter and a fallback route in code, with both exits (publish when every sentence is supported, fallback when tries reaches 2), and also sets recursion_limit, because LangGraph 1.2.17 reads LANGGRAPH_DEFAULT_RECURSION_LIMIT with a default of "10007" in _internal/_config.py. Early stopping cut about 11% of iterations at about 98% quality (arXiv 2609.16453). Q3 checks the difference between a wrapper (CRAG: a grader, then rewrite plus web search when no passage is kept) and a trained behaviour (Self-RAG emits tokens for retrieve, is-relevant, is-supported, is-useful); analogy: you can add a smoke detector to any house, but you cannot rewire a rented flat. Likely follow-up: "What do you measure first?" Routing accuracy and retrieval recall, before answer quality, and the abstention rate after each loop you add.
