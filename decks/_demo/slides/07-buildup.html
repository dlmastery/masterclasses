Gotcha Retrieval scoring

Normalise before you fuse, or one retriever silently wins

fuse.py
score = bm25_score + cosine_score   # 0..40 + 0..1
ranked = sorted(docs, key=score, reverse=True)
fuse.py
def rrf(rankings, k=60):
    s = {}
    for r in rankings:
        for i, d in enumerate(r):
            s[d] = s.get(d, 0) + 1 / (k + i + 1)
    return sorted(s, key=s.get, reverse=True)

Best practices

  • Fuse ranks (RRF, k=60) when score scales differ.
  • Measure recall@k on a labelled set before and after.
  • Do not add raw BM25 and cosine scores.
  • Do not tune k on the test set.
