import numpy as np, krippendorff as kd
from sklearn.metrics import cohen_kappa_score

# Q1: 1 = outage. (A,B) pairs: 90x(0,0) 2x(1,1) 6x(1,0) 2x(0,1)
a = np.array([0]*90 + [1]*2 + [1]*6 + [0]*2)
b = np.array([0]*90 + [1]*2 + [0]*6 + [1]*2)
p_o = (a == b).mean()                               # 0.92
p_e = a.mean()*b.mean() + (1-a.mean())*(1-b.mean()) # 0.886
cohen_kappa_score(a, b)                             # 0.30

# Q2: 0=billing 1=login 2=shipping (no order)
codes = [[0, 2, 1, 2, 0, 1],                        # rater A
         [2, 2, 1, 0, 0, 1]]                        # rater B
kd.alpha(reliability_data=codes)                    # 0.083
kd.alpha(reliability_data=codes, level_of_measurement="nominal")

# Q3: two judges must agree; humans are the anchor
judge_a = judge_b = ...     # text -> (label, confidence)
texts, human = ...          # ~200 human-labelled tickets
def gate(text, t=0.86):
    (la, ca), (lb, cb) = judge_a(text), judge_b(text)
    return la if la == lb and min(ca, cb) >= t else "REVIEW"
pairs = [(h, gate(x)) for x, h in zip(texts, human)]
cohen_kappa_score(*zip(*[p for p in pairs if p[1] != "REVIEW"]))
Ask each question, wait for an answer, then reveal the model answer; the code focus moves to the matching lines. Question 1 tests chance correction: p_o is the observed agreement, and p_e is the agreement two raters get by chance from their own label rates. Here rater A says outage on 8% of tickets and rater B on 4%, so p_e is 0.886 and kappa is only 0.30. Question 2 is a silent default: the krippendorff library treats category codes as numbers on an interval scale unless you pass the level, so a billing-versus-shipping disagreement counts four times a billing-versus-login one. The toy uses three of the four ticket classes and gives 0.083 against 0.542 on the same six tickets. Question 3: keep a judge label only when two judges agree above a confidence threshold, and re-measure kappa against a human anchor set on every judge upgrade, because newer judge backbones do not always keep correct judgements (arXiv 2610.09820). In a merchant-matching paper (arXiv 2609.33878), two agreeing local judges with separate thresholds for match and no-match kept 81.7% of items at 96.88% purity. The anchor size of about 200 is a rule of thumb, not a published number. Which kappa is good enough? Compare with the human-human kappa, which is the ceiling; a common CI gate fails a judge below 0.6. Analogy: kappa is a test score after you subtract what a student gets by guessing.
