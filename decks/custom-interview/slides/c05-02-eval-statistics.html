import numpy as np
from scipy import stats
rng = np.random.default_rng(0)
d = rng.normal(0, 1.5, 400)            # shared item difficulty
p1 = 1 / (1 + np.exp(-(1.3 - d)))      # v1 pass probability
p2 = 1 / (1 + np.exp(-(1.6 - d)))      # v2 pass probability
a = (rng.random(400) < p1).astype(float)  # v1: 0/1, shape (400,)
b = (rng.random(400) < p2).astype(float)  # v2: row i = same case
eval_stats.py · power
def diff_of_means(x, y, axis=-1):
    return np.mean(x, axis=axis) - np.mean(y, axis=axis)
r = stats.bootstrap((b, a), diff_of_means, paired=True,
                    n_resamples=9999, method="percentile", rng=rng)
mde = 2.8 * r.standard_error   # 2.8 = 1.96 (α 0.05) + 0.84 (power 0.8)
print(f"MDE {100 * mde:.1f} pts")        # MDE 7.0 pts
n_need = 400 * (100 * mde / 2) ** 2      # n for a 2-pt MDE
print(f"n for 2 pts: {n_need:,.0f}")     # n for 2 pts: 4,941

The first code block makes the lab data: two 0/1 arrays of shape (400,), where row i is the same refund case for both models. Q1 tests a power analysis before you build the set. The minimum detectable effect is about 2.8 times the standard error of the delta, where 2.8 = 1.96 (z for alpha 0.05, two-sided) + 0.84 (z for power 0.8). At 400 paired cases that is 7.0 points; MDE scales with 1 over the square root of n, so a 2-point MDE needs 400 × (7.0 / 2)² ≈ 4,900 paired cases, or about 7,200 unpaired (MDE 8.5). Q2 tests per-item thinking: discordant cases are the cases where exactly one model is right; the 299 concordant cases cancel out. Exact McNemar on 40 vs 61 gives p = 0.046. On SWE-bench Verified, the same test separates none of 29 adjacent leaderboard pairs. Q3 uses a second scenario, the Lab 3 claims eval: a 16-item Spanish health slice passes 56% under an 84% headline. Bootstrap intervals under-cover below 100 items, so use Wilson; when items share a conversation, resample whole conversations (cluster bootstrap), which is out of scope here. Analogy: two thermometers that disagree by less than their own error tell you nothing about the room.
