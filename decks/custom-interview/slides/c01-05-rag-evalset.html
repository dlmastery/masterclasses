import json, os
from openai import OpenAI
client = OpenAI()                         # reads OPENAI_API_KEY
JUDGE = os.environ["JUDGE_MODEL"]
def ask(prompt: str) -> str:
    r = client.chat.completions.create(model=JUDGE, temperature=0,
        messages=[{"role": "user", "content": prompt}])
    return r.choices[0].message.content
rows = [json.loads(l) for l in open("claims_testset.jsonl")]  # ragas
kept = []
for r in rows:
    closed_book = ask(r["user_input"])    # no retrieval
    same = ask(f"Reference: {r['reference']}\n"
               f"Candidate: {closed_book}\nSame facts? YES or NO.")
    if not same.strip().upper().startswith("YES"):
        kept.append(r)
print(f"generated={len(rows)} kept={len(kept)}")  # generated=40 kept=34

Ask Q1 and wait. The model answer has two parts: generate, then verify. Click 1: ragas TestsetGenerator turns the claims documents into question, reference answer and reference context rows. A synthetic set is only a draft. WinSyn (arXiv 2609.12171) builds grounded synthetic enterprise email QA, and frontier agents still stay below 80% on it, so synthetic does not mean easy. Click 2: walk the loop. Ask the judge model the question with no retrieval. Click 3: if the closed-book answer already states the same specific facts as the reference, the item tests the model's memory, not your retrieval, so drop it. Dropping 6 of 40 is normal. Then a human checks a 5 to 10% sample, you freeze the file by hash, and you report per product line. The full generator setup is ragas Lab 2 in the main deck. Click 4, Q2: when the index holds pages the assistant wrote, arXiv 2608.22118 found that answers collapse onto that self-authored content in 79.6% of 1,528 simulations, and one such page can be enough. Tag the author at ingest and filter or down-rank model-written chunks at retrieval, as in the three-line filter. Analogy: an exam you can pass from memory does not test the open book. Likely follow-up: "Filter or down-rank?" Filter for policy answers that must cite a clause; down-rank where model-written FAQs are reviewed and useful.
