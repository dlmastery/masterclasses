Pick thresholds from costs at production prevalence

A missed refund fraud costs $120, a false hold $15. Which threshold?
Calibrate the probabilities first. Then the Bayes threshold is t* = C_FP / (C_FP + C_FN) = 15 / 135 = 0.111. In the refund-fraud lab, a move from 0.5 to the cost-tuned threshold cut cost by 31%: $10.72 → $7.38 per case.

Refund-fraud eval set: 10% fraud; production: 2%. Does it matter?
Yes. FPR and FNR do not depend on prevalence, but cost does. The eval-tuned threshold cost 66% more in production: $3.10 vs $1.86 per case. Re-derive the threshold at production prevalence, and re-derive it when costs change.

IT tickets: when should the router defer to a human?
When the expected cost of acting is higher than the review cost. With costs (correct 0, triage 1, wrong 5), route only if P(correct) > 0.80. Freeze the threshold on calibration data, then test once: cost 0.763 → 0.472 (−38.1%), wrong routes 15.3% → 3.5%.

thresholds.py
from sklearn.metrics import confusion_matrix_at_thresholds
C_FP, C_FN, PI_PROD = 15.0, 120.0, 0.02  # $ hold, $ miss
t_bayes = C_FP / (C_FP + C_FN)  # 0.111 if p is calibrated
def best_t(y, p, pi):  # $ per case at prevalence pi
    tns, fps, fns, tps, thr = confusion_matrix_at_thresholds(y, p)
    fpr, fnr = fps / fps[-1], fns / tps[-1]
    ec = pi * fnr * C_FN + (1 - pi) * fpr * C_FP
    return thr[ec.argmin()], ec.min()  # 0.152 eval, 0.340 prod
C_OK, C_TRIAGE, C_WRONG = 0.0, 1.0, 5.0  # ticket router costs
t_break_even = (C_WRONG - C_TRIAGE) / (C_WRONG - C_OK)  # 0.80
This slide tests decision thinking, not modelling. Q1: the candidate should say "calibrate first", then derive the threshold from the cost matrix; 0.5 is only right when both errors cost the same and the classes are balanced. Analogy: a smoke alarm is set very sensitive because a missed fire costs far more than a false alarm. Q2 is the trap most candidates miss: an enriched eval set changes the cost curve, so the threshold you tuned there is wrong in production; in the lab the best threshold moved from 0.152 to 0.340. Q3 extends the same idea to deferral: route when (1 − p) × 5 is below the review cost of 1, select the threshold on a calibration split, freeze it, and report the test once. Likely follow-up: "Your LLM gives one confidence value for every ticket. Now what?" Then the correctness AUROC is 0.500, no threshold can help, and you must report always-route and always-defer baselines. Hand-off: the whiteboard puts paired statistics, a calibrated judge and a gate threshold into one weekly release gate for an HR-policy assistant.
