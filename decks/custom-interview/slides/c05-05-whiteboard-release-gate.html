Read the prompt and let the candidate draw before you reveal anything. The strong answer has four parts: a golden set from real traces plus a human anchor set labelled by two or more experts, an LLM judge calibrated on that anchor with kappa, TPR and TNR against the human-human ceiling, a paired comparison against the current model with per-slice Wilson intervals, and a quality card per model and eval hash that a CI job turns into a pass or exit 1. The card values are the captured HR-policy judge run: kappa 0.58 against 0.81 between humans, TNR 0.593, and a corrected pass rate of 0.727 with CI 0.628 to 0.798, so the CI-low rule passes but the kappa rule fails and the deploy is blocked. Analogy: the judge is a scale in a shop, and the anchor set is the reference weight you check it against before every weekly sale. Likely follow-up: "Can we reuse last release's judge calibration?" No: reusing an old version's calibration raised comparison error from 3.8 to 19.5 points (arXiv 2609.34198), so re-measure kappa on the new model's own answers every release. Hand-off: the paired step of this gate is where most teams slip, and the debug drill shows how.
