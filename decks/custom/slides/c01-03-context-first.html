Databricks measured Genie Code on 401 internal data tasks with a 20-minute budget and an independent judge; the numbers are vendor-reported. First click: accuracy, 76.6% for Genie Code against 72.1% for the best general coding agent. Second click: cost, $0.55 against $1.09 per task. Genie Code also used 8.3 tool calls per task, the fewest of any agent tested, and Databricks says "accuracy and cost did not trade off". The gain came from context: semantic search over the catalog and a persistent memory of tables, with the model weights unchanged. Compare it to a new support hire: give them the policy binder before you send them on a training course. The counter-case is NextNet on Google Cloud: its failure was behaviour and cost, so tuning Gemini Flash won with +80% accuracy, −90% cost and −60% latency, partly because the prompt template shrank from 2,000 to 200 tokens. A likely question is "so when do I tune?": tune when the failure is behaviour, format, cost or latency. For Acme, the missing refund facts are a context fix: a search tool over the policy documents plus session memory. Next: a new paper shows why facts trained into weights backfire.
