On corrected ImageNet labels, ResNet-18 outperforms ResNet-50 if the share of originally mislabeled test examples rises by 6%. The model ranking flips.

  1. Get out-of-sample probabilities with K-fold cross_val_predict.
  2. Per class j, set the threshold tj = mean self-confidence of the examples labeled j.
  3. Count x (labeled i) into cell (i, j) if p̂(j|x) ≥ tj. This is the confident joint.
  4. Off-diagonal cells hold likely errors. Rank them by self-confidence.
  5. Prune or relabel them, then retrain.

from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_predict
from cleanlab.filter import find_label_issues
from cleanlab.classification import CleanLearning
from cleanlab import Datalab
model = LogisticRegression(max_iter=1000)
# 1) out-of-sample probabilities (critical!)
pred_probs = cross_val_predict(model, X, labels, cv=5,
                               method="predict_proba")
# 2) ranked indices of likely label errors
issues = find_label_issues(
    labels=labels, pred_probs=pred_probs,
    filter_by="both", return_indices_ranked_by="self_confidence")
# 3) finds the issues, then trains on the cleaned data
cl = CleanLearning(model).fit(X, labels)   # cl.get_label_issues()
# 4) Datalab: label issues, outliers, near-duplicates, non-IID
lab = Datalab({"X": X, "y": labels}, label_name="y")
lab.find_issues(pred_probs=pred_probs, features=X)
lab.report()
Out-of-sample. In-sample probabilities memorize the noise, so a wrong label looks correct to the model.
The pred_probs columns must be in the order of the class labels. A wrong column order makes every label look wrong.

Training dynamics: a data map

Record p(true label | x) at the end of each epoch. Confidence = the mean over epochs. Variability = the standard deviation.

easy-to-learnhigh confidence, low variabilitylargest region; helps optimization

Use both signals. cleanlab gives a ranked list from one set of probabilities. The data map adds the history over epochs.

First the motivation: even famous test sets have label errors, at least 3.3% on average and about 6% in ImageNet validation. Step 1 builds the confident joint cell by cell. Rows are the given labels, columns are the labels the model is confident about. The counts here are for illustration, but the missile to projectile cell copies a real finding: about 645 ImageNet missile images carry the parent label "projectile". Step 2 sends the off-diagonal cells to a ranked review list. Steps 3 to 5 walk the cleanlab code; stress that the probabilities must be out-of-sample. Step 6 adds training dynamics: examples that stay at low confidence every epoch are often mislabeled. Analogy: a teacher who marks the same answer wrong every time, while all other students agree, should check the answer key. Likely question: "Why not just remove all low-confidence examples?" Answer: hard but correct examples also have low confidence; the per-class threshold and the off-diagonal count separate noise from difficulty.
