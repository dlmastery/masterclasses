Start every project with an eval set of at least 20 gold cases and a business metric. Then try prompt and context engineering; if the eval passes, ship. If it fails, read the failures and classify each one as knowledge or behavior. Knowledge goes right and up: long context for a small stable KB, RAG for a large or fresh corpus, agentic RAG for multi-hop questions. Behavior goes right and down, and the data you have picks the method: gold outputs mean SFT, pairs mean DPO, a grader means RFT or GRPO. Analogy: a doctor runs the test before choosing the drug. The table then gives the cost of each rung. Note that Anthropic offers no public fine-tuning API; its customization path is context engineering, prompt caching, Skills and tools. Likely question: "How do I pick the accuracy bar?" Use the OpenAI break-even example: with these costs, the system must beat 81.5 percent to make money.
