Measure agreement before you scale labeling, and accept an LLM only when it agrees like a human

Cohen's κ: two raters, corrected for chance

κ = (po − pe) / (1 − pe)
po
5/7 = 0.714
pe
15/49 = 0.306
κ = (0.714 − 0.306) / (1 − 0.306) = 0.588

po is the observed agreement. pe comes from the label shares of each rater. The quadratic-weighted κ on the same data is 0.800, because it gives partial credit on ordinal scales. Kappa paradox: with skewed classes pe is high, so κ is low while raw agreement is high. Report both.

Krippendorff's α = 1 − Do / De

Observed over expected disagreement. It accepts any number of raters, missing ratings (grey cells), and nominal to ratio levels. Use it for crowd and LLM + human panels. Fleiss' κ needs a fixed number of raters per item.

Loop: guidelines → pilot 50–200 items with 3+ raters → α per label → adjudicate → revise → repeat until α ≥ 0.8 → scale with 5–10% overlap items. Low agreement can be signal on subjective tasks: keep soft or per-annotator labels.

agreement.py · sklearn 1.9.x, statsmodels, krippendorff 0.9.0

import numpy as np, krippendorff
from sklearn.metrics import cohen_kappa_score
from statsmodels.stats.inter_rater import aggregate_raters, fleiss_kappa

a = [0, 1, 1, 2, 0, 2, 1]
b = [0, 1, 2, 2, 0, 2, 0]
cohen_kappa_score(a, b)                       # nominal: 0.588
cohen_kappa_score(a, b, weights="quadratic")  # ordinal: 0.800

ratings = np.array([[0, 0, 1], [1, 1, 1], [2, 2, 1], [0, 0, 0]])
table, _ = aggregate_raters(ratings)   # items x raters -> counts
fleiss_kappa(table, method="fleiss")

# Krippendorff: raters x items, np.nan = missing rating
rel = np.array([[0, 1, 2, np.nan], [0, 1, 2, 0], [1, 1, np.nan, 0]])
krippendorff.alpha(reliability_data=rel, level_of_measurement="nominal")

Hybrid LLM + human labeling recipe

  1. Humans label a gold set of 200–500 items with high agreement.
  2. The LLM labels the same items. Compare LLM–human α with human–human α. Accept the LLM only if the two are close.
  3. Reduce known biases: swap the answer order, use a fixed label set, set temperature 0, use several judges and vote.
  4. Send low-confidence and disagreeing items to humans.
  5. Run cleanlab on the merged labels. Re-audit 2–5% of the LLM labels each week.

Argilla 2.8.0 and Label Studio 1.23.2 show LLM pre-annotations as suggestions. A human accepts or corrects each one.

“LLMs should be carefully validated against human judgments before being used as evaluators.”
Paper JUDGE-BENCH (ACL 2025): 11 LLMs, 20 datasets Paper ChatGPT Outperforms Crowd-Workers Paper Judging LLM-as-a-Judge
Start with the formula. Step 1 uses the same two raters as the code: they agree on 5 of 7 items, and chance alone gives 0.306, so kappa is 0.588, which is "moderate". Step 2 shows why Krippendorff's alpha is the default for real panels: raters skip items, and alpha accepts the missing cells. Steps 3 to 5 walk the code: sklearn for Cohen, statsmodels for Fleiss, and the krippendorff package with np.nan for missing ratings. Step 6 is the LLM-era recipe: validate the LLM on a human gold set, then route by confidence and audit the merged labels. The numbers: ChatGPT beat MTurk on 4 of 5 tasks at under 0.3 cents, but JUDGE-BENCH found that reliability varies a lot by task. Analogy: a new lab instrument must match the reference instrument on known samples before you use it on unknown samples. Likely question: "Raw agreement is 95%, why is kappa 0.4?" Answer: the classes are skewed, so chance agreement is already high.
