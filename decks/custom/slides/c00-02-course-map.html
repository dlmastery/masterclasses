Use this map to show the order of the course. First we decide which lever to use: prompt and context, RAG, SFT, DPO or RL. Then we open each mechanism and look at how it works inside. Step 2 shows that all three mechanisms read from the same data, and the strip under the map shows the seven data stages and the chapter for each stage. Step 3 adds evaluation and the full lifecycle. Step 4 closes the loop: drift in production sends us back to dataset design. Analogy: a build system, where the data is the source code and the model is the compiled binary. Likely question: "Why is evaluation near the end if we need it first?" Answer: we build an eval set on day one in chapter 1, and chapter 8 teaches how to design it with statistics. Every chapter ends with an interview slide.
