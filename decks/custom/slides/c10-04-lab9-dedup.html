import re
from datasketch import MinHash, MinHashLSH
NUM_PERM = 128
def shingles(text, k=5):
    t = re.sub(r"\s+", " ", re.sub(r"[^a-z0-9 ]", "", text.lower())).strip()
    return {t[i:i + k] for i in range(max(1, len(t) - k + 1))}
def signature(text):
    m = MinHash(num_perm=NUM_PERM)          # 2.0.0 default scheme = "affine32"
    m.update_batch(s.encode("utf8") for s in shingles(text))
    return m
train = {
    "tr-001": "Employees accrue 1.5 days of paid time off per month of service.",
    "tr-002": "Employees accrue 1.5 days of paid time-off per month of service!",
    "tr-003": "Parental leave is 16 weeks at full pay for all new parents.",
    "tr-004": "Remote work requires manager approval and a signed equipment form.",
    "tr-005": "Expense reports must be filed within 30 days of the purchase date.",
    "tr-006": "Expense reports must be submitted within 30 days of the purchase date.",
}
test = {                                    # texts from the frozen eval set (step 2)
    "te-001": "Parental leave is 16 weeks at full pay for all new parents",
    "te-002": "Badges must be worn visibly at all times inside the office.",
}
lsh = MinHashLSH(threshold=0.7, num_perm=NUM_PERM)        # 1) dedup inside train
sigs, kept, dropped = {}, [], []
for key, text in train.items():
    sigs[key] = signature(text)
    matches = lsh.query(sigs[key])
    if matches:
        dropped.append((key, matches[0], round(sigs[key].jaccard(sigs[matches[0]]), 2)))
    else:
        lsh.insert(key, sigs[key])
        kept.append(key)
print("kept:", kept)
print("dropped (dup, of, est. Jaccard):", dropped)
test_lsh = MinHashLSH(threshold=0.7, num_perm=NUM_PERM)   # 2) index the TEST set
for key, text in test.items():
    test_lsh.insert(key, signature(text))
leaked = {k: test_lsh.query(sigs[k]) for k in kept if test_lsh.query(sigs[k])}
print("train docs leaking into test:", leaked)
print("final train set:", [k for k in kept if k not in leaked])

Step 2 froze the HR eval set; this is the test side. Before we fine-tune the HR assistant, we remove near-duplicates inside the training text and any training item that copies the eval set. Step 1: the shingles are character 5-grams on lowercased text without punctuation, so "filed" versus "submitted" still shares most shingles; step 2: MinHash turns each shingle set into 128 numbers, and two texts share a number with probability equal to their Jaccard similarity. Step 3: LSH with threshold 0.7 cuts the signature into 14 bands of 9 rows, and tr-002 and tr-006 hit the buckets of tr-001 and tr-005 with estimated Jaccard 0.82 and 0.77; step 4: we index only the test set and query train, and tr-003 is the same sentence as te-001, so it leaves the training data. Analogy: a fingerprint check at the exam door, with the answer sheet locked in a separate room. Likely question: "Why not delete the newer duplicate?" Query-then-insert keeps whichever comes first, so sort by policy version first: two versions that differ only in 16 versus 12 weeks are near-duplicates with different facts. The gotcha card is the upgrade trap: datasketch 2.0.0 changed the default MinHash scheme, so an index pickled with 1.x must be rebuilt. Train and test are now clean, so step 4 checks the last instrument: the LLM judge that scores the answers.
