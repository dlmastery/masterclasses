Split by entity and by time, or the test set leaks the answer

Entity

Several scans per patient. A random split puts one patient in both folds.

Time

Train on the past, test on the future. Each training set is a superset of the one before. A gap stops boundary bleed.

Preprocessing

A scaler, imputer, SMOTE or vocabulary fit on all rows sees the test set. Fit each step inside the fold.

from sklearn.model_selection import GroupKFold, StratifiedGroupKFold
from sklearn.model_selection import TimeSeriesSplit, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
pipe = make_pipeline(StandardScaler(),                # fit per fold
                     LogisticRegression(max_iter=1000))
# entity: no patient_id in both train and test
cross_val_score(pipe, X, y, groups=patient_id,
                cv=GroupKFold(n_splits=5))
cross_val_score(pipe, X, y, groups=patient_id,      # + class balance
                cv=StratifiedGroupKFold(n_splits=5))
# temporal: rows sorted by time; the gap stops boundary bleed
tscv = TimeSeriesSplit(n_splits=5, gap=7)
cross_val_score(pipe, X_sorted, y_sorted, cv=tscv)
Random K-fold on multi-scan medical images measures memorized patients, not diagnosis.

scikit-learn: i.i.d. data “rarely holds in practice”; with group structure “it is safer to use group-wise cross-validation”. For LLM and RAG evals, hold out by time: test only on documents and questions created after the training cutoff.

Leakage gives you a test score for a task the model will never see in production. Step 1 is entity leakage: the same patient is in train and test, so the model can recognize the patient instead of the disease; GroupKFold keeps each patient in one fold. Step 2 is temporal leakage: TimeSeriesSplit trains on the past and tests on the future, and gap=7 drops the rows at the boundary. Step 3 is preprocessing leakage: a scaler fit on all rows has seen the test statistics; put it inside a Pipeline so it is fit per fold. Steps 4 to 6 walk the code for each split. The evidence is large: Kapoor and Narayanan found leakage in 329 papers across 17 fields. Analogy: a student who sees the exam questions the night before gets a high grade, but the grade does not measure what the student knows. Likely question: "What if I have no patient id?" Answer: then you cannot fix it with an algorithm; group definitions are domain knowledge, so get the metadata or find near-duplicates as a proxy.
