Vertex AI RAG Engine manages the corpus, chunking and retrieval behind one client

rag_engine.py · adapted from the quickstart; check exact kwarg names

import agentplatform
from agentplatform import types
from google import genai
from google.genai import types as genai_types

client = agentplatform.Client(project=PROJECT, location="us-central1")
corpus = client.rag.create_corpus(display_name="policies")
client.rag.import_files(corpus.name, paths=["gs://bucket/policies/"],
    transformation_config=types.RagFileTransformationConfig(
        chunking_config=types.RagFileChunkingConfig(
            chunk_size=512, chunk_overlap=100)))
ctx = client.rag.retrieve_contexts(rag_resources=[corpus.name],
    rag_retrieval_config=types.RagRetrievalConfig(
        top_k=3, vector_distance_threshold=0.5),
    text="What is the refund window?")

rag_tool = genai_types.Tool(retrieval=genai_types.Retrieval(
    vertex_rag_store=genai_types.VertexRagStore(...)))  # corpus ref
gem = genai.Client(vertexai=True, project=PROJECT, location="us-central1")
resp = gem.models.generate_content(model="gemini-3.5-flash",
    contents="What is the refund window?",
    config=genai_types.GenerateContentConfig(tools=[rag_tool]))

This is the managed version of the pipeline from the previous slide. Step 1: one client, one corpus. Step 2: import_files does parsing, chunking and embedding; here the chunking config is 512 tokens with 100 overlap, the same numbers as the quickstart. Step 3: retrieve_contexts gives you the raw chunks; use it in your retrieval eval, before any generation. Step 4: for answers, give Gemini a Retrieval tool that points at the corpus, so grounding and citations come back with the response. Analogy: the RAG Engine is a managed library; you bring the books and the questions. Step 5 is the real-world warning: the API names moved in 2026, so pin the SDK and check the live quickstart. Likely question: "Why not always use the managed engine?" Answer: you trade control of chunking, hybrid weights and reranking for less infrastructure.
