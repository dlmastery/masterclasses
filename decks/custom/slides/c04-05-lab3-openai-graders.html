from openai import OpenAI
GRADE_SRC = r'''
import json, re
def grade(sample, item) -> float:
    m = re.search(r"\{.*\}", sample["output_text"], re.DOTALL)
    if not m:
        return 0.0
    try:
        out = json.loads(m.group(0))
    except Exception:
        return 0.0
    if not {"decision", "refund_amount", "reason"} <= out.keys(): return 0.0  # schema gate
    if out.get("decision") != item["gold_decision"]:
        return 0.0
    try:
        ok = abs(float(out.get("refund_amount", -1)) - float(item["gold_amount"])) <= 0.01
    except (TypeError, ValueError):
        ok = False
    return 1.0 if ok else 0.5
'''
policy = {"type": "python", "name": "policy", "source": GRADE_SRC}
tag = {"type": "string_check", "name": "tag", "operation": "ilike",   # must cite the policy id
       "input": "{{sample.output_text}}", "reference": "{{item.policy_id}}"}
grader = {"type": "multi", "name": "refund_grader", "graders": {"policy": policy, "tag": tag},
          "calculate_output": "0.8 * policy + 0.2 * tag"}
item = {"gold_decision": "approve", "gold_amount": "49.99", "policy_id": "RP-30"}
sample = ('<answer>{"decision": "approve", "refund_amount": 49.99, '
          '"reason": "Unopened, day 12 of 30 (RP-30)"}</answer>')
ns = {}
exec(GRADE_SRC, ns)                                  # 1) free local unit test first
print("local policy score:", ns["grade"]({"output_text": sample}, item))
client = OpenAI()                                    # 2) server-side checks
print(client.fine_tuning.alpha.graders.validate(grader=grader))
run = client.fine_tuning.alpha.graders.run(grader=grader, model_sample=sample, item=item)
print("reward:", run.reward, "sub:", run.sub_rewards, "errors:", run.metadata.errors)

Step 3 of Lab 3 ports the refund reward from step 1 to an OpenAI python grader: grade(sample, item) keeps the same schema gate, so it returns 0 for unparseable output, a missing key or a wrong decision, 0.5 for the right decision with the wrong amount, and 1.0 when both match. A string_check grader adds 0.2 for citing the policy id, and the multi grader combines them with the formula 0.8 * policy + 0.2 * tag, where the formula names must match the graders keys. Always exec the source locally first: it is free, and the step 2 completions give 1.0 for good, 0.5 for wrong_amt, 0.0 for the hack, the broken answer and a deny. Without the gate line the hack scores 0.5 here too, so port the gate with the logic. Then validate and run it on the server; a sample that passes both sub-graders must print 1.0, which checks the formula.
