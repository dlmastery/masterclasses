import pandas as pd
import pandera.pandas as pa
from pandera.typing import Series

class ClaimsContract(pa.DataFrameModel):
    claim_id: Series[str] = pa.Field(
        unique=True, str_matches=r"^CLM-\d{6}$")
    policy_id: Series[str] = pa.Field(
        str_length={"min_value": 8, "max_value": 8})
    claim_type: Series[str] = pa.Field(
        isin=["auto", "home", "travel", "health"])
    amount_usd: Series[float] = pa.Field(gt=0, le=250_000)
    incident_date: Series[pd.Timestamp] = pa.Field()
    reported_date: Series[pd.Timestamp] = pa.Field()
    adjuster_note: Series[str] = pa.Field(nullable=True)
    @pa.dataframe_check(
        error="reported_date must be on/after incident_date")
    def reported_after_incident(cls, df) -> Series[bool]:
        return df["reported_date"] >= df["incident_date"]
    class Config:
        strict = True   # unknown columns fail the contract
        coerce = True   # "1200" -> 1200.0, ISO str -> Timestamp

This is the first step of Lab 6: the claims intake rules, which used to live in a wiki page, become one pandera DataFrameModel in its own module, claims_contract.py. Walk the focus bands: each Field states one column rule, the dataframe_check compares two columns in the same row, and Config turns on strict mode and coercion, so the strings in the nightly file become floats and Timestamps before any check runs. The table on the right is the batch in nightly_batch.py: the lab's pd.DataFrame dict with 4 rows, every value a string, and adjuster_note as the seventh, nullable column. Six cells break a field rule, and row 3 also breaks the row check, which reports all 6 of its listed columns, so the report in step 2 has 6 plus 6, 12 failure cases. Install the pandas extra, or import pandera.pandas fails in a clean venv. Analogy: the class is the building code, and the producer's CI and the training job are two inspectors who read the same book. Likely question: "Why not just write asserts?" Asserts stop at the first failure and give no table; step 2 shows lazy=True returning all 12 failure cases in one report.
