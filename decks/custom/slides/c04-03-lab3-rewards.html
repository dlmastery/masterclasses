Two refund rewards in TRL's signature: format and gated decision

refunds_rl/refund_rewards.py · trl 1.16.0 reward contract
import json, re
ANSWER_RE = re.compile(r"<answer>\s*(\{.*?\})\s*</answer>", re.DOTALL)
DECISIONS = {"approve", "deny", "escalate"}
REQUIRED = {"decision", "refund_amount", "reason"}

def _parse(text):  # the JSON dict inside <answer>...</answer>, or None
    m = ANSWER_RE.search(text)
    try:
        obj = json.loads(m.group(1)) if m else None
    except json.JSONDecodeError:
        return None
    return obj if isinstance(obj, dict) else None

def format_reward(completions, **kwargs):  # 0.2 = parses, 3 keys, valid decision
    out = []
    for c in completions:
        obj = _parse(c[0]["content"])
        ok = obj is not None and REQUIRED <= obj.keys() and obj.get("decision") in DECISIONS
        out.append(0.2 if ok else 0.0)
    return out

def decision_reward(completions, gold_decision, gold_amount, **kwargs):
    out = []  # 1.0 decision + amount within $0.01 | 0.5 decision only | 0.0 otherwise
    for c, gd, ga in zip(completions, gold_decision, gold_amount, strict=True):
        if gd is None:  # no gold label: TRL skips this reward for the row
            out.append(None)
            continue
        obj = _parse(c[0]["content"])
        if obj is None or not REQUIRED <= obj.keys() or obj.get("decision") != gd:
            out.append(0.0)
            continue
        try:
            amount_ok = abs(float(obj.get("refund_amount")) - float(ga)) <= 0.01
        except (TypeError, ValueError):
            amount_ok = False
        out.append(1.0 if amount_ok else 0.5)
    return out

Lab 3 starts here and runs four slides: write the reward, test it, then port it to OpenAI graders and to Vertex Gemini RFT. This is the reward for the Acme refund-decision agent, written in the exact signature that TRL 1.16.0 GRPOTrainer calls, and it runs on a laptop CPU with no packages. Step 1: format_reward reads the text from c[0]["content"] because completions are message lists, and the **kwargs catch-all is required because TRL also passes prompts, completion_ids, trainer_state, log_extra, log_metric and every dataset column. Step 2: decision_reward asks for gold_decision and gold_amount by name, and TRL fills them from the dataset columns with the same names, so there is no glue code. Step 3: the schema gate means no partial credit unless all three keys are present; step 4: returning None for a row without a gold label tells TRL to skip this reward for that row, and zip with strict=True turns a silent misalignment into an error. Analogy: the reward is an exam marker who must refuse to mark a paper that is not on the official answer sheet. Likely question: "Why not just return 0.0 for unlabelled rows?" Because 0.0 is a real score that pushes the policy down, while None removes the row from this reward entirely. Next, step 2 runs the self-test and shows the hack it caught.
