import glob, re, torch
from peft import PeftModel
from transformers import AutoModelForCausalLM, AutoTokenizer
from common import refund_splits
BASE, PH = "Qwen/Qwen3-0.6B", re.compile(r"\{\{[^}]+\}\}")
tok, test = AutoTokenizer.from_pretrained(BASE), refund_splits()["test"]
for ck in sorted(glob.glob("qwen3-0.6b-refund-lora/checkpoint-*")):
    base = AutoModelForCausalLM.from_pretrained(BASE, dtype=torch.bfloat16)
    model, kept = PeftModel.from_pretrained(base, ck).eval(), 0
    for r in test:
        enc = tok.apply_chat_template(r["messages"][:2],   # SYSTEM + user
            add_generation_prompt=True, enable_thinking=False,
            return_tensors="pt", return_dict=True)
        out = model.generate(**enc, max_new_tokens=128, do_sample=False)
        reply = tok.decode(out[0, enc["input_ids"].shape[1]:])
        gold = set(PH.findall(r["messages"][2]["content"]))
        kept += gold <= set(PH.findall(reply))
    print(ck, "placeholder_kept", round(kept / len(test), 3))

The Lab 1 refund adapter saves one checkpoint per epoch, and we set load_best_model_at_end to False, so which one do we ship? The September paper on 60 math SFT runs compares two generation-based rules, generated accuracy and checkpoint agreement, with picking by validation NLL: they win by 0.71 and 0.85 percentage points. That sounds small, but it is free once you have the eval set, and a validation set of about 300 items instead of 32 adds about 0.3 more; the gain over simply keeping the final checkpoint stayed unresolved, so measure it on your task. The chart is a schematic: both rows start at zero, and the guide lines show that the lowest-loss checkpoint and the most accurate checkpoint are different columns. Click 2: the scoring script loads each checkpoint, generates greedily with the training prefix, and counts whether every placeholder of the gold reply survives. Click 3: our sweep shows the same trap: r64 has the lowest eval_loss but a worse intent score than r16, so we ship r16. Rank and learning rate change together in these three rows, which is why the second paper says: sweep the learning rate first, then compare ranks at a fixed rate. intent_exact runs the Gemma 4 router on each reply and compares its intent with the gold intent.
