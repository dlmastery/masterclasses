# Portable recipe: same JSONL, new provider
from google import genai
from google.genai import types
from google.genai.types import HttpOptions

DATA = "gs://your-gcs-bucket/your-tuning-data.jsonl"
client = genai.Client(
    http_options=HttpOptions(api_version="v1"))
job = client.tunings.tune(
    base_model="gemini-3.5-flash",
    training_dataset=types.TuningDataset(gcs_uri=DATA),
    config=types.CreateTuningJobConfig(
        tuned_model_display_name="support-tone-v1",
        epoch_count=1),
)
# Keep the eval set and the grader in your own repo.
Today, 23 October 2026, is a real turning point. Google removed tuning from the Gemini API in May 2025, so Gemini tuning lives only on Vertex AI. AWS launched Bedrock RFT in December 2025; the 66 percent gain is a vendor number, not an independent result. OpenAI announced its wind-down in May 2026, and today the o4-mini fine-tune snapshots shut down, so OpenAI RFT ends. Fireworks closed managed RFT and moved to a Training API, and Tinker gives raw training primitives: RL becomes code that you own. Analogy: do not build your house on a rented foundation without a copy of the blueprints. The code shows the blueprint idea: the same JSONL re-tunes on Vertex in a few lines. Likely question: "Which vendor should I pick?" Pick the one that fits today, but keep the data, the grader and the eval portable.
