# step1_inspect_mask.py - which tokens does SFT learn from? (CPU)
from transformers import AutoTokenizer
from trl import get_training_chat_template
from common import SYSTEM   # refunds system prompt, shared by all steps
tok = AutoTokenizer.from_pretrained("Qwen/Qwen3-0.6B")
# {{Order Number}} is literal Bitext text: the model must copy it
messages = [{"role": "system", "content": SYSTEM},
  {"role": "user", "content": "Where is my refund for {{Order Number}}?"},
  {"role": "assistant", "content": "I'm sorry for the wait. Let me check."},
  {"role": "user", "content": "Thanks. Can you check it now?"},
  {"role": "assistant", "content": "{{Order Number}}: it is on its way."}]
tpl = get_training_chat_template(tok) or tok.chat_template  # None: OK
orig = tok.apply_chat_template(messages, tokenize=False)
print("orig == patched:", orig == tok.apply_chat_template(
    messages, tokenize=False, chat_template=tpl))
out = tok.apply_chat_template(messages, chat_template=tpl, tokenize=True,
    return_dict=True, return_assistant_tokens_mask=True)
mask = out["assistant_masks"]       # 1 = in the loss, 0 = label -100
print(f"tokens={len(mask)} trained={sum(mask)}")
print(repr(tok.decode([t for t, m in zip(out["input_ids"], mask) if m])))
assert sum(mask) > 0, "no assistant tokens in the loss"   # run this in CI

Stock Qwen3 drops the earlier <think> block from history. TRL's template keeps it, so every turn trains the same way.
Mask 1 = trained. The trainer gives 0 positions label -100 (ignore_index).
<|im_end|> is trained, so the model learns to stop.
Train with an empty <think></think> → serve with enable_thinking=False: the same prefix, in steps 4 and 5.
Before we spend any GPU time, we print what SFT will actually learn from. This script runs on a laptop CPU in seconds. Step 1: TRL swaps the stock Qwen3 chat template for its training template, because the stock one drops the think block from earlier assistant turns, so history renders differently from the final turn; if TRL returns None, the template is already training-ready and we keep it. Step 2: the assistant mask is what assistant_only_loss turns into labels: a 0 becomes label -100, which cross-entropy ignores, so only the coral tokens are in the loss. Step 3: the end-of-turn token must be inside the trained span, or the model never learns to stop; the assert is the line to copy into CI. Analogy: it is a highlighter over the transcript, and the model only studies the highlighted lines. The counts are illustrative and depend on the tokenizer version. The rule to remember: we train with an empty think block, so every inference call in steps 4 and 5 must pass enable_thinking=False, which prefills the same block. Likely question: "What about Gemma 4?" TRL 1.16 does not patch its template and raises a ValueError; we fix that with Unsloth later in this chapter.
