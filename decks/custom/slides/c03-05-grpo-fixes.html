DAPO and Dr. GRPO fix entropy collapse and length bias, and TRL ships them as defaults

1 · Clip-Higher

Set εlow 0.2 and εhigh 0.28. Rare tokens can gain probability. It “avoids entropy collapse”.

2 · Dynamic sampling

Drop prompts with group accuracy 0 or 1. They give zero advantage and zero gradient.

3 · Token-level loss

Average the loss over all tokens in the batch, not per sample. Long answers keep their weight.

4 · Overlong shaping

Apply a soft length penalty. Max length 16,384 tokens, with a 4,096-token cache before it.

5 · Dr. GRPO: length bias

GRPO “artificially increases response length”, mostly for wrong answers. Fix: divide by a constant, drop the std term.

grpo_verifiable.py · adapted from the TRL reward-function pattern

import re
from trl import GRPOConfig, GRPOTrainer

def correct_answer(completions, ground_truth, **kwargs):
    texts = [c[0]["content"] for c in completions]  # conversational
    preds = [re.search(r"\\boxed\{(.+?)\}", t) for t in texts]
    return [1.0 if p and p.group(1).strip() == gt else 0.0
            for p, gt in zip(preds, ground_truth)]

def format_reward(completions, **kwargs):
    return [0.2 if "<think>" in c[0]["content"] else 0.0
            for c in completions]

args = GRPOConfig(loss_type="dr_grpo", scale_rewards=False,  # Dr. GRPO
                  num_generations=8, beta=0.0, use_vllm=True)
trainer = GRPOTrainer(model="Qwen/Qwen2.5-0.5B-Instruct",
                      reward_funcs=[correct_answer, format_reward],
                      args=args, train_dataset=dataset)
trainer.train()

Each card is one bug in vanilla GRPO and its fix. Clip-Higher lets low-probability tokens grow, so the policy keeps exploring. Dynamic sampling removes groups where every answer has the same reward, because those groups give no gradient and waste compute. Token-level loss stops long answers from being down-weighted, and overlong shaping stops truncated answers from getting a hard zero. Dr. GRPO shows that the per-sequence length normalization and the std division push the model to write longer wrong answers. Analogy: a teacher who divides marks by essay length makes wrong essays longer, because the penalty per word gets smaller. Then walk the code: two reward functions and a config that turns on the Dr. GRPO settings. Likely question: "Why is beta 0 the default?" Answer: 2025 evidence showed the KL term is not needed for RLVR, and dropping it removes the reference model from memory.
