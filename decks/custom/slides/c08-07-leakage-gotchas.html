import pandas as pd
from sklearn.compose import make_column_transformer
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.model_selection import GroupKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import TargetEncoder
from lab7_leakage_splits import df, y                  # Lab 7: 400 customers x 15 events

feats = [f"f{i}" for i in range(7)]
enc = make_column_transformer((TargetEncoder(), ["customer_id"]), ("passthrough", feats))
pipe = make_pipeline(enc, HistGradientBoostingClassifier(max_iter=200, random_state=0))
auc = cross_val_score(pipe, df[["customer_id", *feats]], y, groups=df["customer_id"],
                      cv=GroupKFold(n_splits=5, shuffle=True, random_state=0), scoring="roc_auc")

1 · Encoder fitted before the split
SymptomCV ROC-AUC is higher than production. CauseA scaler, target encoder or vocabulary saw all rows. sklearn: "never call fit on the test data". An all-row customer_fraud_rate makes GroupKFold AUC jump. FixEvery transform in a Pipeline passed to cross_val_score. Same rule for dedup thresholds, tokenizer training, RM calibration.
2 · Agent picks a future feature
SymptomAn agent-built model uses a feature that does not exist at prediction time. CauseLeakBench, MIMIC-IV (430k admissions): leak in 10/10 unconstrained runs, 0/10 with an admission-time constraint. Renaming changes neither: "a name-based filter fails". FixAn "available at prediction time" contract column, checked by timestamp: feature_ts <= prediction_ts.
3 · The drift monitor breaks
SymptomPSI = inf, or ValueError: `bins` must increase monotonically, when an array CauseAn empty bin gives log(0). Business bin edges are unsorted or repeat. Fixnp.clip(share, eps, None), edges = np.unique(edges). Set a minimum window: 10 bins and < 500 rows give ~0.05 PSI noise.

Three leaks that survive a code review, because the split itself looks correct. Step 1 and 2: a customer_fraud_rate computed on all rows puts each test customer's own labels into a feature, so GroupKFold AUC jumps; the fix is a TargetEncoder inside the Pipeline, so cross_val_score re-fits it on the four training folds only. Step 3 and 4: LeakBench shows coding agents pick a feature that does not exist at prediction time in 10 of 10 unconstrained runs, and renaming the column to something like x17 does not change that, so only a timestamp rule, feature_ts at or before prediction_ts, catches it. Step 5: the drift monitor from Lab 7 step 1 breaks on empty bins and unsorted business bin edges; clip with eps, use np.unique, and set a minimum window size. Analogy: a guard who checks name badges lets in anyone who borrows a badge, but a guard who checks the arrival time does not. Likely question: does the Pipeline slow the cross-validation down? A little, because the encoder is fitted five times, and that is the cost of an honest number. Hand-off: the next slide shows that the same leaks appear in three October 2026 papers outside fraud.
