Chroma Context-1 post Repo context-1-data-gen
Chroma Context-1 is a 20B retrieval subagent: gpt-oss-20b with a LoRA adapter. It does not answer questions; it returns ranked documents to a downstream reasoner. The key point for this chapter is the data pipeline: an LLM generates a task and extracts supporting quotes, and a deterministic check confirms that each quote exists in the source text, otherwise the task is dropped. Chroma measured human agreement with that verifier per domain, from 84.4% on web to 98.3% on legal, before training with SFT and then CISPO with a recall-weighted reward. This is gate 1 of Lab 9 (grounded in the context) made deterministic: an exact quote match instead of an LLM judge. Analogy: a fact-checker who must find the exact sentence in the book before a quiz question goes into the exam. Likely question: "Why weight recall 16x?" A retriever that misses the answer chunk caps the reasoner, so they reward finding it first and anneal to 4x to win back precision.
