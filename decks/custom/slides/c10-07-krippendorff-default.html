import krippendorff
import numpy as np
from sklearn.metrics import cohen_kappa_score
from statsmodels.stats.inter_rater import aggregate_raters, fleiss_kappa

codes = [[0, 2, 1, 2, 0, 1],               # rater 1: 0=answer 1=clarify 2=escalate
         [2, 2, 1, 0, 0, 1]]               # rater 2   (raters x items)
bad = krippendorff.alpha(reliability_data=codes)               # default: interval
good = krippendorff.alpha(reliability_data=codes, level_of_measurement="nominal")
print(f"interval {bad:.3f}   nominal {good:.3f}")

ana = [3, 2, 0, 1, 3, 2, 0, 3, 1, 2, 3, 0]   # HR relevance grades, ordinal 0-3
ben = [3, 2, 0, 2, 3, 1, 0, 3, 1, 2, 2, 0]
chen = [2, 2, 1, 1, 3, 2, 0, 3, 0, 2, 3, 1]
humans = np.array([ana, ben, chen])          # raters x items  (krippendorff)
table, _ = aggregate_raters(humans.T)        # items x raters  (statsmodels)
print(f"fleiss {fleiss_kappa(table, method='fleiss'):.3f}")
alpha_ord = krippendorff.alpha(reliability_data=humans, level_of_measurement="ordinal")
print(f"ordinal alpha {alpha_ord:.3f}")
print(f"cohen {cohen_kappa_score(ana, ben):.3f}  quadratic "
      f"{cohen_kappa_score(ana, ben, weights='quadratic'):.3f}")

Lab 9 step 4 passed level_of_measurement="nominal" to krippendorff.alpha; this slide shows why. It is the quietest bug in the chapter: krippendorff.alpha uses the interval level unless you say otherwise, so our answer, clarify and escalate codes become the numbers 0, 1 and 2 on a ruler, and the same two raters score 0.083 instead of 0.542. Step 2 is the fix: pass "nominal" for categories and "ordinal" for Likert or 0-3 grades. Step 3 is the second trap: statsmodels aggregate_raters wants items by raters, krippendorff wants raters by items, and a wrong orientation gives a wrong number with no error. Step 4: on an ordinal scale, unweighted Cohen kappa punishes a one-grade miss like a three-grade miss, so Ana and Ben go from 0.664 to 0.905 with quadratic weights; and the lenient LLM judge drops the panel alpha from 0.852 to 0.755. Analogy: averaging shirt colours as if red, green and blue were 0, 1 and 2. Likely question: should we just make the LLM judges agree with each other more? The Agreement Without Alignment paper shows that clearer rubrics raise inter-judge alpha by 0.069 but not agreement with experts, so keep a human anchor.
