refunds/grade.py · no SDK import
import json, re
def grade(sample, item) -> float:
    m = re.search(r"\{.*?\}", sample["output_text"], re.DOTALL)
    try:
        out = json.loads(m.group(0)) if m else None
    except json.JSONDecodeError:
        out = None
    if not isinstance(out, dict):
        return 0.0
    if out.get("decision") != item["gold_decision"]:
        return 0.0
    try:
        amt = float(out["refund_amount"])
        ok = abs(amt - float(item["gold_amount"])) <= 0.01
    except (KeyError, TypeError, ValueError):
        ok = False
    return 1.0 if ok else 0.5
Parse defensively. No JSON, bad JSON or a JSON list gives 0.0. The grader never raises.
Gold labels come from the dataset row (item), not from a vendor API.
Smooth score: 1.0 right amount, 0.5 right decision only, 0.0 wrong.
