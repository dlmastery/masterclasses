These three September papers set the noise floor for our release decision. The evalstats paper shows that below about 100 items the bootstrap interval is too narrow: the percentile method covered the true difference only 88% of the time instead of 95%, so use Wilson for pass rates, and Acme's thin Spanish slices with 8 to 29 items are exactly this regime. The Pinned paper re-ran pinned temperature-0 judges on identical inputs and found about 5% of verdicts flip, and about 40% of close calls, so run the judge at least three times and publish the flip rate. The SWE-bench paper is the leaderboard version: with exact paired McNemar tests, none of the 29 adjacent pairs separate, so report rank bands. Analogy: a bathroom scale that moves half a kilo between readings cannot tell you that you lost 200 grams. A likely question is whether more items fix it: for pass rates yes, but only paired tests on the same items use the data efficiently.
