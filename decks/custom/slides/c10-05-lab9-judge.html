import krippendorff
import numpy as np
from sklearn.metrics import cohen_kappa_score, confusion_matrix
rng = np.random.default_rng(11)
N_CAL, N_PROD = 300, 4000
truth = (rng.random(N_CAL) < 0.80).astype(int)          # 1 = answer is policy-correct
def noisy(labels, tpr, tnr):
    flip = np.where(labels == 1, rng.random(len(labels)) > tpr, rng.random(len(labels)) > tnr)
    return np.where(flip, 1 - labels, labels)
human_a, human_b = noisy(truth, 0.97, 0.93), noisy(truth, 0.95, 0.90)   # two HR reviewers
judge = noisy(truth, 0.95, 0.60)                          # lenient judge: misses bad answers
gold = human_a                                            # adjudicated label in real life
tn, fp, fn, tp = confusion_matrix(gold, judge, labels=[0, 1]).ravel()
tpr, tnr = tp / (tp + fn), tn / (tn + fp)
print(f"raw agreement judge-vs-human {np.mean(judge == gold):.3f}")
print(f"Cohen kappa human-human {cohen_kappa_score(human_a, human_b):.3f}  "
      f"judge-human {cohen_kappa_score(gold, judge):.3f}")
print(f"judge TPR={tpr:.3f}  TNR={tnr:.3f}   (TNR = catches bad answers)")
# Krippendorff alpha: 3 raters x 300 units, human_b only rated 150 units (missing = nan).
rel = np.vstack([human_a, np.where(np.arange(N_CAL) < 150, human_b, np.nan), judge]).astype(float)
print(f"Krippendorff alpha (nominal, 3 raters, missing ok) "
      f"{krippendorff.alpha(reliability_data=rel, level_of_measurement='nominal'):.3f}")
# Production: judge-only labels on 4000 answers whose true pass rate is 0.72.
prod_truth = (rng.random(N_PROD) < 0.72).astype(int)
prod_judge = noisy(prod_truth, 0.95, 0.60)
def rogan_gladen(p_obs, tpr, tnr):
    return np.clip((p_obs + tnr - 1) / (tpr + tnr - 1), 0, 1)
boots = []
for _ in range(2000):                                     # resample BOTH calibration and prod
    i, j = rng.integers(0, N_CAL, N_CAL), rng.integers(0, N_PROD, N_PROD)
    g, jd = gold[i], judge[i]
    b_tpr, b_tnr = jd[g == 1].mean(), 1 - jd[g == 0].mean()
    boots.append(rogan_gladen(prod_judge[j].mean(), b_tpr, b_tnr))
print(f"prod pass rate: judge-observed {prod_judge.mean():.3f}  corrected "
      f"{rogan_gladen(prod_judge.mean(), tpr, tnr):.3f}  95% CI {np.round(np.percentile(boots, [2.5, 97.5]), 3)}"
      f"  (truth {prod_truth.mean():.3f})")
labels=[0, 1] keeps the 2x2 shape. Raw agreement is 0.877, but TNR is 0.593: the judge catches only 59% of bad answers.
Human-human kappa 0.812 is the ceiling, not 1.0. The judge gets 0.580. Alpha takes nan for the 150 missing ratings.
Rogan-Gladen inverts the judge's error rates: 0.799 becomes 0.727 (truth 0.726). It needs TPR + TNR > 1.
Resample calibration AND production items. Only 300 labels give a wide CI: buy human labels on the failure class.

This is the last step of the HR lab: can the LLM judge replace the two HR reviewers? On 300 labelled answers the judge agrees with the humans 87.7% of the time, which sounds fine, but the confusion matrix shows it passes 24 of the 59 bad answers: its TNR is only 0.593. Compare kappa with the human-human kappa of 0.812, because that is the real ceiling, and the judge reaches 0.580. Then we use the judge alone on 4,000 production answers: it reports 79.9% pass, and the Rogan-Gladen formula uses the measured TPR and TNR to correct that to 72.7%, almost exactly the hidden truth of 72.6%. The bootstrap resamples both the calibration labels and the production answers, so the CI from 0.628 to 0.798 is honest, and wide: the fix is more human labels on bad answers. Analogy: a bathroom scale that reads 3 kg heavy is still useful once you measure the error and subtract it. Likely question: "Why pass level_of_measurement='nominal'?" Because the default gives a silently wrong answer: the gotcha after the next slide shows it.
