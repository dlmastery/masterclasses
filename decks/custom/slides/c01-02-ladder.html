Read the ladder bottom-up: each rung needs more data and more time than the one below, so you climb only when the eval says the current rung is not enough. The Acme refunds assistant starts at prompt only and passes 41% of the refund eval; all gauge numbers are illustrative. Long context helps a little, but the Acme knowledge base is bigger than about 200k tokens, so we move to RAG, which fixes the fact half. SFT with LoRA (low-rank adapters, a cheap way to fine-tune) fixes the format half. DPO (direct preference optimization: train on chosen versus rejected answers) and RL or RFT (reinforcement fine-tuning against a grader) stay closed until you have preference pairs or a reward you trust. Analogy, as on the chapter slide: the handbook fixes missing facts, coaching fixes behaviour. One real number: in OpenAI's Icelandic grammar case, adding RAG to a fine-tuned GPT-4 dropped BLEU (overlap with reference text, higher is better) from 87 to 83, because the task was behaviour and the retrieved text added noise. Likely student question: "Why not skip to RL?" RL needs at least one correct sampled answer per prompt to learn anything; the probe slide at the end of this chapter shows how to check.
