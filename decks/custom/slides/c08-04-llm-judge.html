Position bias

In pairwise grading, the judge prefers the answer in one fixed position.

Fix: judge both orders

Swap A and B. Count a win only if it holds in both orders. Else score a tie.

Verbosity bias

The judge gives longer answers higher scores.

Fix: control length

Use length-controlled scoring (Length-Controlled AlpacaEval, arXiv 2404.04475). Write “do not reward length” in the rubric.

Self-preference

The judge prefers outputs of its own model family (self-enhancement).

Fix: another family

Use a judge from a different model family than the candidate. The bias is not fully solved.

Vague 1–5 scale

A Likert score does not say what “good” means, so labels vary.

Fix: binary per criterion

One pass/fail judge per failure mode. G-Eval (arXiv 2303.16634) adds a CoT rubric; DeepEval GEval uses it.

Also check

Rubric drift → freeze and version the judge prompt like code. Never validated → expert calibration split with TPR, TNR, κ. Reference leakage → grade against a reference only where one exists.

Correct the pass rate (Rogan-Gladen)

θ = (p_obs + TNR − 1) / (TPR + TNR − 1)

Bootstrap the CI over the calibration items and the eval items together.

judge_agreement.py · from 07-eval-design §8

from sklearn.metrics import cohen_kappa_score, confusion_matrix
# human, judge: 0/1 labels on the calibration split
k = cohen_kappa_score(human, judge)
tn, fp, fn, tp = confusion_matrix(
    human, judge, labels=[0, 1]).ravel()
tpr, tnr = tp/(tp+fn), tn/(tn+fp)
print(f"kappa={k:.2f}  TPR={tpr:.2f}  TNR={tnr:.2f}")
# p_obs: the judge pass rate on the eval set
theta = (p_obs + tnr - 1) / (tpr + tnr - 1)  # Rogan-Gladen
An LLM judge is a measuring instrument, so calibrate it before you trust its readings. Zheng et al. found GPT-4 agrees with humans as often as humans agree with each other, but they also found four biases. Steps 1 to 4 flip each bias card to its fix: both orders for position, length control for verbosity, another model family for self-preference, and binary checks for vague scales. Step 5 is the validation: experts label a calibration split, and the confusion matrix gives TPR, TNR and kappa; these counts are an example. Step 6 uses those two rates to correct the pass rate the judge reports on the eval set. Analogy: a bathroom scale that reads 2 kilograms high is still useful once you know the offset. Likely question: "Why kappa and not raw agreement?" Raw agreement goes up with class imbalance; kappa removes chance agreement.
