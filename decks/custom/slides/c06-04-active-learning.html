Active learning spends the labeling budget on uncertain and diverse examples

Loop: seed → train → score the pool → select a batch of B → a human or an LLM labels it → add → repeat until the budget ends.

Uncertainty only

Least confidence 1 − max p, margin p1 − p2, or entropy. It is cheap. But near points get the same score, so one batch holds redundant examples.

Uncertainty + diversity

Core-set (Sener and Savarese, ICLR 2018): greedy k-center in embedding space. BADGE (Ash et al., ICLR 2020): embed each point as the last-layer loss gradient, with the predicted label as a hypothetical label. The norm gives uncertainty, the direction gives diversity. Then run k-means++ seeding. It “balances uncertainty and diversity” with no hand-tuned trade-off.

LLM era and open problems

Uncertainty: LLM disagreement or self-consistency. Diversity: sentence embeddings. Route to an LLM annotator or a human. Problems: cold start; sampling bias (test on a separate random sample); small gains over random with strong embeddings.

Weak supervision: many noisy voters give one probabilistic label

Labeling functions (rules, regexes, LLM prompts) vote or abstain. The LabelModel learns the accuracy of each function from their agreements, without ground truth. An end model then trains on the probabilistic labels.

Active learning asks one question: which unlabeled example should a human label next? Step 1 shows the pool, a few labeled seed points and the current decision boundary. Step 2 picks by uncertainty only: the picks clump in one part of the boundary, so ten labels teach the model almost one thing. Step 3 picks with uncertainty plus diversity, as core-set and BADGE do: the picks spread along the whole boundary. Step 4 runs the loop and the labeled set grows from 6 to 16. Step 5 shows the other way to get labels cheaply: weak supervision, where many noisy labeling functions vote and a label model learns how much to trust each one. Tell students that Snorkel OSS still teaches the idea well, but it has had no release since 2024 and has open CVEs. Analogy: a student with ten questions for the teacher should not ask ten versions of the same question. Likely question: "Does active learning still help with foundation models?" Answer: often less than expected; always compare against random sampling on a random test set.
