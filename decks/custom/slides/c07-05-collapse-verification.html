Synthetic data collapses a model when it replaces real data, not when it is anchored and added

Replace: training on model output causes “irreversible defects in the resulting models, where tails of the original content distribution disappear”.

Paper Shumailov et al., Nature 631, 2024

Accumulate: “accumulating the successive generations of synthetic data alongside the original real data avoids model collapse”.

Paper Is Model Collapse Inevitable?, 2024

Did verification help?

SFT distillation from a strong teacher: “none gave significant performance improvements” (OpenThoughts, about verification and answer filtering).

RLVR rewards and code: verification is essential. Tulu 3 puts it in the reward; Llama 3 kept only code that passed all checks.

Anchored synthesis works: Phi-4 “substantially surpasses its teacher model on STEM-focused QA”.

Paper Phi-4 Technical Report

Mitigations for the quality card

  • Keep a real-data anchor in every mix.
  • Flag provenance: source=synthetic.
  • Control diversity: personas, Magpie, temperature.
  • Dedup synthetic outputs against each other.
  • Track distinct-n and embedding spread.
  • Verify with programs, not self-judgment.

Collapse by curation: every lab filters for “educational-looking” text. That risks one narrow style and lost tails.

Step 1 shows generation 0: real data, with its rare tails shaded on both sides. Step 2 replaces the data with model output each generation: the model over-samples what is common and under-samples what is rare, so the tails go first and the peak gets narrow; in the Nature paper a prompt about medieval architecture became a list of jackrabbits by generation 9. Step 3 is the fix from Gerstgrasser and Schaeffer: keep the real data and add each synthetic generation next to it, and the error stays bounded. Step 4 is an open question for the room: OpenThoughts found that verification did not improve SFT distillation from a strong teacher, but RLVR and code need it, because a wrong reward or broken code teaches the wrong thing directly. Analogy: a photocopy of a photocopy loses detail; keep the original on the desk. Likely question: "So is synthetic data safe?" Yes when it is anchored, diverse, deduplicated and checked; Phi-4 and SmolLM3 (APO pairs with Qwen3-32B chosen and Qwen3-0.6B rejected) show that.
