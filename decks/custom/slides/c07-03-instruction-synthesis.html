from distilabel.models import TransformersLLM
from distilabel.steps.tasks import MagpieGenerator

generator = MagpieGenerator(
    llm=TransformersLLM(
        model="meta-llama/Meta-Llama-3-8B-Instruct",
        magpie_pre_query_template="llama3",
        generation_kwargs={"temperature": 1.0,
                           "max_new_tokens": 256},
        device="mps",
    ),
    only_instruction=True,
    num_rows=5,
)
generator.load()
result = next(generator.process())
OpenThoughts, 1,000+ ablations: more teacher answers per question grow a source “by at least 16x”. The “top 1 or 2” sources beat many. “QwQ-32B is a stronger teacher than DeepSeek-R1”. OpenThinker3-7B: AIME25 53%, GPQA-D 54%.
Show the four generators one at a time; each one solves a different problem. Self-Instruct grows a task pool from a few seeds and drops near-duplicates. Evol-Instruct makes existing instructions harder (in depth) or wider (in breadth). Magpie is the clever one: give an aligned model only the template up to the user turn, and it writes a realistic user question by itself, so you need no seed prompts. Persona Hub crosses one prompt with many personas to get diversity at scale; Tulu 3 used persona data for its math, code and instruction-following subsets. In the code, the only Magpie-specific setting is the pre-query template, and only_instruction=True asks for the questions only. Analogy: Magpie is like a microphone left open at a call centre; the model fills the silence with the kind of question it has heard most. Likely question: "Which teacher should I use?" Test it; OpenThoughts found that QwQ-32B taught better than DeepSeek-R1, although R1 scores higher. Note the risk in the repo cite: distilabel is now community-maintained.
