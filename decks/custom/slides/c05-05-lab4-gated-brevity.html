import re
# literal backslash; r"\boxed" would mean word-boundary + "oxed"
BOX_RE = re.compile(r"\\boxed\{([^{}]*)\}")
def _is_correct(text, gold):
    m = BOX_RE.findall(text)
    try:
        return bool(m) and abs(float(m[-1].replace(",", "").replace("$", "")) - float(gold)) < 0.01
    except ValueError:
        return False
def gated_brevity_reward(completions, completion_ids, solution, trainer_state=None,
                         log_metric=None, target_tokens=120, warmup_steps=50, **kwargs):
    """Brevity credit ONLY for correct answers (anchor = correctness), ramped in after warm-up."""
    step = trainer_state.global_step if trainer_state is not None else warmup_steps
    ramp = min(1.0, step / warmup_steps)
    out, gated = [], 0
    for c, ids, gold in zip(completions, completion_ids, solution, strict=True):
        if not _is_correct(c[0]["content"], gold):
            out.append(0.0)          # wrong + short earns nothing (no auxiliary-only credit)
            gated += 1
            continue
        out.append(ramp * max(0.0, 1.0 - len(ids) / (2 * target_tokens)))
    if log_metric is not None:
        log_metric("brevity/gated_frac", gated / len(out))
        log_metric("brevity/ramp", ramp)
    return out
if __name__ == "__main__":
    class S: global_step = 25
    comps = [[{"content": r"...so \boxed{8500}"}], [{"content": r"\boxed{1}"}],

Wrong answers get 0.0: a TAG-style anchor on correctness.

This is step 4 of the claims lab: we want shorter answers, but only short answers that are right. Step 1: the regex needs a literal backslash before boxed, and an answer counts as correct when the last boxed number is within one cent of the gold payout. Step 2: TRL hands trainer_state to every reward function, so the brevity credit ramps from 0 to 1 over the first 50 steps, and at step 25 it is exactly one half. Step 3 is the gate: a wrong answer gets 0.0 no matter how short it is, which is the minimal version of TAG from arXiv 2610.21404, where gating gave 0.581 pass@4 against 0.220 for a plain sum. Think of a taxi driver who is paid for a fast trip only when the passenger reaches the right address. Likely question: "Why not just add 0.1 times a length score?" Because inside a GRPO group a short wrong answer then beats a long right one, and the policy learns to be short and wrong.
