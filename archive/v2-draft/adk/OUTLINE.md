### c01-08-paper.html - Over-claiming tool descriptions cut task success from 89% to about 30%
- **id:** `adk-c01-paper`  **type:** paper
- **content:** Kicker '<span class=pill>arXiv</span> Oct 2026'. Paper card 1: arXiv 2610.28454 'Toolflation: Seller Agents Distort Tool Markets Through Spontaneous Generative Engine Optimization' (2026-10-20): when descriptions over-claim, buyer agents fall back to picking tools by list position; task success fell from 89% to about 30% under one model. ### c10-07-gotcha-deploy.html - Deploys lose sessions, duplicate instances or return 403 by default
- **id:** `adk-c10-gotcha-deploy`  **type:** gotcha
- **content:** Kicker '<span class=pill>Gotcha</span> Deployment'. Card 1 Symptom: users lose their conversation after a scale event. Cause (adk.dev/deploy/cloud-run): without --session_service_uri 'the deployed container falls back to the in-memory session and artifact services ... sessions and artifacts are lost whenever a Cloud Run instance is recycled.' Fix: --session_service_uri="agentengine://$AGENT_ENGINE_ID" (or a SQLAlchemy URL). Card 2 Symptom: two Agent Runtime instances and a client that talks to the old one. Cause: without --agent_engine_id every 'adk deploy agent_engine' creates a NEW instance (cli_deploy.py L1893-1898); on a failed update only a newly created instance is deleted. Fix: pass --agent_engine_id on updates. Card 3 Symptom: 403 Forbidden on curl after --no-allow-unauthenticated. Cause: you sent an access token. Fix: an identity token (gcloud auth print-identity-token) and roles/run.invoker. Footer: 'The installed Agent Platform SDK exposes Client.agent_engines rather than Client.runtimes...' -> google-cloud-agentplatform>=2.2; version skew 'AttributeError: 'LlmAgent' object has no attribute 'mode'' came from an unpinned 'google-adk>=1.20.0' resolving differently in the cloud (#6156) - pin versions in requirements.
- **visual:** Three cards per step; step 4 fix code; card 2 bespoke: each deploy arrow spawns a new instance box (1, 2, 3) until --agent_engine_id makes the arrow update box 1 in place.
- **code:** Fix snippet: adk deploy cloud_run --project=$P --region=$R --session_service_uri="agentengine://$AGENT_ENGINE_ID" hr_agent -- --no-allow-unauthenticated\nadk deploy agent_engine --project=$P --region=$R --agent_engine_id=$AGENT_ENGINE_ID hr_agent
