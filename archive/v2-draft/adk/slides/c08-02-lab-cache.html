import pathlib
from google.adk import Agent
from google.adk.agents.context_cache_config import ContextCacheConfig
from google.adk.apps import App
from google.genai import types
HANDBOOK = pathlib.Path("handbook.md").read_text(encoding="utf-8")
agent = Agent(
    name="handbook_agent", model="gemini-3.5-flash",
    static_instruction=types.Content(
        role="user", parts=[types.Part(text=HANDBOOK)]),
    instruction="Customer: {customer_name}. Cite the section.")
app = App(name="bluefin_support", root_agent=agent,
    context_cache_config=ContextCacheConfig(
        min_tokens=4096, ttl_seconds=900, cache_intervals=10))

static_instruction goes first, never templated. With it set, ADK sends instruction (and {customer_name}) as user content after the prefix. The prefix stays byte-stable.
min_tokens is checked against the previous request's prompt_token_count; the model minimum (4,096 on Gemini 3) still applies. cache_intervals: invocations that reuse one cache before ADK refreshes it. Defaults are 1800 s and 10; the lab uses 900 s.
Turn 1 prints cached=None: the cache starts on turn 2. Cached tokens cost less; storage bills for each hour of TTL.

This is step one of the Bluefin lab: the handbook agent sends the same long handbook on every request, so we cache that static prefix. Before you run it, put about 3,100 words of plan terms in handbook.md; if cached stays None on turn 2 as well, check the size with client.models.count_tokens, because Gemini 3 needs 4,096 tokens before it caches. Walk the focus steps: static_instruction carries the handbook and is never templated, and once it is set ADK sends the instruction, with its {customer_name} placeholder, as user content after the prefix, so you do not move anything by hand. ContextCacheConfig sets a 4,096-token minimum and a 15-minute TTL; min_tokens compares against the previous request's prompt size, so turn 1 always shows cached=None. Think of the prefix as a binder the model keeps open on the desk: you pay full price to open it once, then a lower price per turn, plus rent for every hour it stays open. A likely question: "Does caching cost extra?" Cached input tokens are cheaper, but the cache also bills storage per hour of TTL, which is why the cost-levers slide tunes the TTL to real pauses. Compaction also lives on that slide, because this three-turn demo never reaches a compaction threshold.
