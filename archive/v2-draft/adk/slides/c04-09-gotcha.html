Gotcha Dynamic graphs

Dynamic nodes need rerun_on_resume and use_sub_branch to stay correct

1 · the parent cannot resume SymptomValueError: A node must have rerun_on_resume=True. Reason is that dynamically scheduled nodes might be interrupted, and the workflow wakes-up/re-runs the parent node, so it can get the child node response. CauseThe parent calls ctx.run_node with the default rerun_on_resume=False. _dynamic_node_scheduler.py:769-774 Fix@node(rerun_on_resume=True) on every parent. Nested parents need it too.
2 · the workers read each other SymptomInterleaved, garbled events across children. The hotel auditor's context holds the dinner auditor's "line 1" output. Causeuse_sub_branch was left False. Before 2.12, a shared-event-list bug did the same (#7488). Fixuse_sub_branch=True on every gathered call. Upgrade to google-adk>=2.12.
3 · a child fails without a sound SymptomA child fails and nothing reports it. Causeasyncio.create_task: "errors are silently swallowed". agents/context.py:453-456 FixAwait the child directly or through asyncio.gather.
run_id

A custom run_id="1" collides with auto ids. Use f"line-{i}".

return value

A sync generator node discards return value. Yield Event(output=...).

expense_audit/agent.py · google-adk 2.13.0
import asyncio
from google.adk import Agent, Context, Event, Workflow
from google.adk.workflow import node

auditor = Agent(
    name="auditor", model="gemini-3.5-flash",
    instruction=("You audit one expense line from the user message: "
                 "meals <= $75/person, no alcohol, hotels <= $250/night."),
)

@node(rerun_on_resume=True)               # fix 1: every caller
async def orchestrate(ctx: Context, node_input: str):
  lines = [l.strip() for l in node_input.split(";") if l.strip()]
  raw = await asyncio.gather(*[            # fix 3: never create_task
      ctx.run_node(auditor, node_input=l,
                   use_sub_branch=True,    # fix 2: one branch each
                   run_id=f"line-{i}")     # not run_id="1"
      for i, l in enumerate(lines)])
  yield Event(output=raw)                  # not: return raw

root_agent = Workflow(name="expense_audit", edges=[("START", orchestrate)])
These three bugs bite the orchestrator from the Northwind expense audit, and each one has a one-line fix in the code on the right. First, any node that calls ctx.run_node must set rerun_on_resume=True, because on resume ADK re-runs the parent from the top and replays the finished children from history; without it you get the ValueError shown, and nested parents need the flag too. Second, set use_sub_branch=True on every gathered call so each auditor sees only its own events; before 2.12 a shared event list leaked one worker's output into another, so upgrade as well. Third, never start children with asyncio.create_task: the animation shows that child dying without a log line, while the same child under gather raises in the parent. Think of create_task as sending a junior adjuster out with no phone: if the car breaks down, the office never hears. A likely question: "Why must run_id contain a letter?" Numeric ids collide with the ids ADK generates, so use f"line-{i}". Next: two papers that measure what these graph shapes cost.
