Do this once before Lab 1. Press once: check that python3 is 3.11 or newer, because 2.12.0 raised the minimum and many macOS and Ubuntu LTS machines still default to an older Python; if pip says the package requires a different Python, this is the cause. Then make a virtual environment and pin google-adk to exactly 2.13.0; thirteen minor releases shipped between 2.0.0 on 19 May and 2.13.0 on 23 October. Press again: get a Gemini API key in Google AI Studio; GOOGLE_GENAI_USE_ENTERPRISE=FALSE says "use the key, not a Cloud project", and the labs call gemini-3.5-flash. On Windows, export does not work in PowerShell or cmd, so put both values in a .env file in the agent folder; adk run loads it on every OS. Press again: pip show must say 2.13.0, and adk --help proves the CLI is on your PATH; the first real model call is Lab 1. Press again: only Lab 8 (Memory Bank) and Lab 10 (deploy) need a Google Cloud project with billing, and those labs show their own setup and their own pins (mcp, a2a-sdk, agents-cli). Last press: the old variable name GOOGLE_GENAI_USE_VERTEXAI still works but raises a DeprecationWarning in google-adk 2.x (utils/env_utils.py), and GOOGLE_GENAI_USE_ENTERPRISE wins if both are set. Analogy: pinning is like a recipe that names the exact flour brand, so every student gets the same cake. Likely question: "Can I use uv instead of pip?" Yes; pin the same version.
