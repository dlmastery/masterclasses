import asyncio, json, sys
from typing import Literal, Optional
from pydantic import BaseModel, Field
from google.adk import Agent
from google.adk.runners import InMemoryRunner
class ClaimIntake(BaseModel):
    reasoning: str = Field(description="One sentence: the facts behind the labels.")
    claim_type: Literal["auto_collision", "auto_glass", "home_water", "home_theft", "other"]
    severity: Literal["low", "medium", "high"] = Field(
        description="low < $2k, medium $2k-$10k, high = injury or > $10k")
    policy_number: Optional[str] = Field(None, description="POL-######, or null")
    incident_date: Optional[str] = Field(None, description="YYYY-MM-DD, or null if unknown")
    estimated_loss_usd: Optional[float] = None
    injuries_reported: bool
intake_agent = Agent(name="claim_intake", model="gemini-3.5-flash",
    instruction="Extract a ClaimIntake from the email. Never guess a value.",
    output_schema=ClaimIntake, output_key="claim")
async def main(email: str) -> None:
    runner = InMemoryRunner(agent=intake_agent, app_name="claims_api")
    await runner.run_debug(email, quiet=True)   # ids: debug_user_id, debug_session_id
    s = await runner.session_service.get_session(app_name="claims_api",
            user_id="debug_user_id", session_id="debug_session_id")
    print(json.dumps(s.state["claim"]))         # a dict, not a ClaimIntake
asyncio.run(main(open(sys.argv[1]).read()))

This is step 1 of the Northwind claims API: turn a first-notice-of-loss email into a typed record. Walk the four focus steps. First, the reasoning field comes first and the Literal types close the label sets; the severity description gives the model the money bands, so $6,400 is medium. Second, the email says "Oct 19" with no year, and the instruction says never guess, so incident_date stays null. Third, output_schema validates the reply and output_key stores it. Fourth, state receives a plain dict from model_dump(exclude_none=True), so the null incident_date is not in state at all; read optional keys with .get(), and call ClaimIntake.model_validate(claim) when you want the typed object back. run_debug creates its own session with user_id "debug_user_id" and session_id "debug_session_id", which is why get_session uses those ids. Setup: GOOGLE_GENAI_USE_ENTERPRISE=0 selects an AI Studio key, 1 selects Agent Platform (the former Vertex AI); on PowerShell use $env:GOOGLE_API_KEY="...". This script runs outside adk web, so export the variables; a .env file is only loaded by adk run and adk web. Analogy: the schema is the paper claim form, and the small print under each box is part of the instructions.
