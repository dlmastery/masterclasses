from typing import Literal
from google.adk import Agent, Context, Event, Workflow
from pydantic import BaseModel, Field
MAX_ROUNDS = 3
class Review(BaseModel):
  grade: Literal["compliant", "needs_fix"]
  feedback: str = Field(description="What to change to meet the policy.")
def brief(node_input: str):
  yield Event(state={"brief": node_input, "feedback": "", "round": 0})
write_copy = Agent(name="write_copy", model="gemini-3.5-flash", output_key="draft",
    instruction="Write a 2-sentence ad for: {brief}. Previous draft (may be "
                "empty): {draft?} Feedback to apply (may be empty): {feedback?}")
review_copy = Agent(name="review_copy", model="gemini-3.5-flash",
    output_schema=Review, output_key="review",
    instruction="Policy: no guaranteed returns, no 'risk-free', must say "
                "'Capital at risk.' Grade this ad: {draft}")
def gate(ctx: Context, node_input: Review):
  ctx.state["round"] = ctx.state["round"] + 1
  if node_input.grade == "compliant":
    yield Event(route="done")
  elif ctx.state["round"] >= MAX_ROUNDS:
    yield Event(route="escalate")
  else:
    yield Event(state={"feedback": node_input.feedback}, route="retry")
def publish(draft: str):               # draft is read from ctx.state
  yield Event(message=f"PUBLISHED:\n{draft}")
def escalate(draft: str, round: int):  # both read from ctx.state
  yield Event(message=f"Escalated to Legal after {round} rounds.\n{draft}")
root_agent = Workflow(name="copy_review", edges=[
    ("START", brief, write_copy, review_copy, gate),
    (gate, {"retry": write_copy, "done": publish, "escalate": escalate})])

Two ways to break the cycle

This is the evaluator-optimizer pattern for Northwind's ad copy on a unit-linked savings policy. It is the first LLM step of the lab, so copy_review needs a .env with GOOGLE_GENAI_USE_ENTERPRISE=FALSE and a GOOGLE_API_KEY from Google AI Studio; on Vertex AI set it to TRUE with your project and location instead. write_copy drafts, review_copy grades the draft against the compliance policy, and gate decides. Walk the bands: brief seeds round 0 and an empty feedback; the question mark in {draft?} and {feedback?} makes a state placeholder optional, so it renders empty on the first pass, while {brief} without it would raise if the key were missing. On a retry the writer sees its previous draft and the feedback, so it revises instead of starting over. Gate is the only thing that stops the loop, because a graph cycle has no max_iterations; it counts rounds and gives two exits, publish when compliant and escalate to Legal at MAX_ROUNDS. publish and escalate get draft and round because function parameters that are not node_input or ctx are looked up in ctx.state by name. Think of a junior copywriter and a compliance officer: after three rejections the draft goes to a lawyer instead of a fourth try. In the trace, @2 means the second run of that node, so you can measure cost per round. On Windows, pipe to findstr node_path instead of grep. A likely question is why not build a second write_copy for the back-edge: validation rejects duplicate names, and an unrouted back-edge is rejected as an unconditional cycle. Step 4 moves from a fixed graph to workers that start at run time, one per expense line.
