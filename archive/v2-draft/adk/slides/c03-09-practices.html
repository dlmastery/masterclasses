Graph rules for the support desk, each with its reason

1Routing route_ticket

  • The LLM labels into a Literal set; a function routes (unit-testable).
  • Add DEFAULT_ROUTE: an unmatched route only logs. YAML: one key per label.

2Data edges and state

  • Same Pydantic class on both edge ends: the build checks it.
  • Pass data on edges; use state for values many nodes read.
  • yield Event(message=…) on end nodes; adk run hides output-only events.

3Structure Workflow(edges=…)

  • At most one terminal output, or a JoinNode (page_oncall emits only a message).
  • single_turn or task nodes in graphs; chat only right after START.
  • Topology and prompts in YAML; logic in Python.

✕Never

  • Load YAML from user input: name: imports Python.
  • Swallow exceptions in a node: the engine cannot see the failure (Ch 5).

This slide turns the chapter into rules you can check in code review. Group one is routing: the model only classifies into a closed Literal set, and a plain function decides the route, so a rule like "p1 always pages on-call" gets a unit test; add a DEFAULT_ROUTE edge because an unmatched route only logs, and in the YAML version give every Literal label its own key. Group two is data: the build checks producer and consumer schemas on each edge, pass data on edges, keep state for values many nodes or prompts read, and yield a message on end nodes because adk run prints nothing for output-only events. Group three is structure: one terminal output or a JoinNode (Lab 3 works because page_oncall emits only a message), single_turn or task nodes in graphs with chat only right after START, and YAML for topology and prompts. The Never card has two rules: never build YAML from user input, because name: imports Python, and never swallow exceptions inside a node, because the engine then cannot see the failure; Chapter 5 shows the retries this breaks. Analogy: the LLM is the triage nurse who writes the label, and the function is the hospital rule book that sends the patient to a ward. Likely question: "Why not let the LLM return the route directly?" You can, but then a casing slip like "Billing" ends the branch with only a log line, and you cannot unit-test the rule.
