from mcp.server.mcpserver import MCPServer
mcp = MCPServer("claims-handbook-server")
POLICIES = {
    "glass": "Glass repair has no deductible on comprehensive policies.",
    "rental": "Rental car covered up to 30 days at $40 per day.",
    "towing": "Towing covered up to 50 miles per incident.",
}
@mcp.tool()
def search_policy(topic: str) -> str:
    """Search the claims handbook. topic is one of: glass, rental, towing."""
    return POLICIES.get(topic.lower(), f"No policy found for '{topic}'.")
@mcp.tool()
def list_topics() -> list[str]:
    """List claims-handbook topics that search_policy understands."""
    return sorted(POLICIES)
if __name__ == "__main__":
    # mcp 2.x: host and port go to run(); the path defaults to /mcp
    mcp.run(transport="streamable-http", host="127.0.0.1", port=3000)

claims_agent/agent.py · adds handbook_tools
from google.adk.tools.mcp_tool import StreamableHTTPConnectionParams
# above: the step 2 imports, payout_needs_human and claims_tools
handbook_tools = McpToolset(
    connection_params=StreamableHTTPConnectionParams(
        url="http://127.0.0.1:3000/mcp",   # path defaults to /mcp
        timeout=5.0,                       # connect, default 5.0 s
        sse_read_timeout=300.0),           # streamed reads, default 300 s
    tool_filter=["search_policy", "list_topics"],
    tool_name_prefix="handbook",           # handbook_search_policy
)
root_agent = LlmAgent(
    name="claims_desk", model="gemini-3.5-flash",
    instruction=("You help claims adjusters. Look up a claim before approving "
                 "it. Answer coverage only from handbook_search_policy."),
    tools=[claims_tools, handbook_tools],
)

This is step 3 of the Northwind claims desk: the claims handbook runs as its own MCP server over streamable HTTP, in terminal 2, and claims_desk mounts it as a second toolset. Unlike stdio, this server is a network service: many agents can share it, and it keeps running when the agent stops. Step 1: in mcp 2.x, host and port go to run(), not to the MCPServer constructor, and the endpoint path defaults to /mcp, so the agent URL must end in /mcp. Step 2: StreamableHTTPConnectionParams sets a 5 second connect timeout and a 300 second read timeout for streamed responses. Step 3: the same filter and prefix as step 2, so the model sees handbook_search_policy and handbook_list_topics, and the two servers cannot collide on a name. Step 4: the instruction tells the model to answer coverage questions only from the handbook tool. Think of the stdio server as a cook inside the restaurant, and the HTTP server as a supplier across the street that many restaurants use. A likely question: "Do I still start claims_server.py myself?" No, McpToolset starts it over stdio; only the handbook server needs its own terminal. Step 4 sends each broker's identity to this server.
