Step six scores the simulated chats. Simulated cases have no golden turns, so we use only reference-free metrics: hallucinations, simulator quality and our own rubrics; a trajectory metric fails here with "expected_invocations is needed by this metric". The type field picks the simulator; older configs without it are treated as llm_backed and ADK logs a warning, and we cap the chat at 8 turns instead of the default 20. The rubric no_overlimit_promise scores 0.0 because the agent told the customer the 820 dollar refund was approved before a supervisor saw it, so the run fails even though the ticket was given. Then close the loop like any bug: add one sentence to the instruction, run the same eval set again, and keep the run green.
