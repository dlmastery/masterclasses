ticket_triage/agent.py · 1 of 2 · schema, classify, route
from typing import Literal
from google.adk import Agent, Event, Workflow
from google.adk.workflow import DEFAULT_ROUTE
from pydantic import BaseModel, Field
class Triage(BaseModel):
  labels: list[Literal["billing", "outage", "how_to", "other"]] = Field(
      description="All labels that apply to the ticket.")
  priority: Literal["p1", "p2", "p3"]
def intake(node_input: str):
  yield Event(state={"ticket": node_input})
classify = Agent(name="classify", model="gemini-3.5-flash",
    instruction="Classify this support ticket. Ticket: {ticket}",
    output_schema=Triage, output_key="triage")
def route_ticket(node_input: Triage):
  routes = list(node_input.labels)
  if node_input.priority == "p1" and "outage" not in routes:
    routes.append("outage")                   # p1 always pages on-call
  yield Event(output=node_input.model_dump(), route=routes)
ticket_triage/agent.py · 2 of 2 · branches and edges
billing = Agent(name="billing", model="gemini-3.5-flash",
    instruction="Draft a billing reply for: {ticket}. Mention invoice lookup.")
def page_oncall(node_input: dict):          # gets route_ticket's output
  yield Event(message=f"PAGED on-call (priority={node_input['priority']}).")
how_to = Agent(name="how_to", model="gemini-3.5-flash",
    instruction="Answer the product question in 4 steps: {ticket}")
def human_queue():
  yield Event(message="Routed to the human L1 queue.")
root_agent = Workflow(name="ticket_triage", edges=[
    ("START", intake, classify, route_ticket),
    (route_ticket, {"billing": billing, "outage": page_oncall,
                    "how_to": how_to, DEFAULT_ROUTE: human_queue}),
])

The LLM must answer in Triage: closed Literal labels and a priority.
Code decides: p1 always adds outage. A list route runs every matching branch.
billing and page_oncall both run. page_oncall yields only a message, so the graph has one terminal output.
"other" has no key, so DEFAULT_ROUTE ("__DEFAULT__") catches it. It runs only when no key matches.
Read the code with the bands while the ticket token moves through the graph. Step 1: the Triage schema. The model can only pick labels and a priority from closed Literal sets, so it cannot invent "Billing" with a capital B. Step 2: route_ticket is plain Python. It decides that p1 always pages on-call, and because the route is a list, every matching branch runs. Step 3: the double-charge outage ticket runs billing and page_oncall. That does not break the one-terminal-output rule, because page_oncall yields only a message; only billing ends with an output. Step 4: the thank-you ticket is labelled "other", which has no key in the edge map, so DEFAULT_ROUTE sends it to the human queue. DEFAULT runs only when no key matches; if the labels were ["other", "billing"], billing would run and the default would not. Import DEFAULT_ROUTE from google.adk.workflow, because the top-level package does not export it. Think of the LLM as the nurse who writes the label and the function as the hospital rule book that picks the ward. A likely question is why not let the LLM route directly: a function rule is unit-testable and costs no tokens. Next: the same router as YAML that a PM can review.
