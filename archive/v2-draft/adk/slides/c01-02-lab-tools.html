Two typed Python functions become the refund desk's tools

refund_agent/agent.py
from typing import Annotated, Literal
from pydantic import Field
from google.adk import Agent
ORDERS = {  # A-1001 and A-1003 omitted: same shape
    "A-1002": {"email": "li@example.com", "total_usd": 1299.0,
               "days_since_delivery": 41, "category": "electronics"}}
RETURN_WINDOW_DAYS = {"apparel": 30, "electronics": 30, "grocery": 0}
def lookup_order(order_id: Annotated[str, Field(description="Order ID, e.g. A-1001")]) -> dict:
    """Look up an order. Always call this before answering a refund question."""
    order = ORDERS.get(order_id.strip().upper())
    if order is None:
        return {"status": "error", "error_message": f"No order with ID {order_id}."}
    return {"status": "success", "order": order}
def check_refund_eligibility(order_id: str,
        reason: Literal["changed_mind", "damaged", "wrong_item"] = "changed_mind") -> dict:
    """Refund policy: 30-day window; grocery is final sale; damaged or wrong items qualify."""
    order = ORDERS.get(order_id.strip().upper())
    if order is None:
        return {"status": "error", "error_message": f"No order with ID {order_id}."}
    if reason != "changed_mind":
        return {"status": "success", "eligible": True, "rule": "defect_override"}
    window = RETURN_WINDOW_DAYS[order["category"]]
    eligible = order["days_since_delivery"] <= window
    return {"status": "success", "eligible": eligible, "window_days": window}
root_agent = Agent(
    name="refund_agent", model="gemini-3.5-flash",
    instruction=("You are a refund desk assistant. Use lookup_order, then check_refund_eligibility. "
                 "Quote the rule you applied. Never promise a refund the tool did not approve."),
    tools=[lookup_order, check_refund_eligibility])

Field(description=...) becomes the description of the order_id parameter.

The whole docstring becomes the tool description, verbatim. ADK does not parse an Args: section.

Literal[...] becomes an enum, so the model cannot invent a reason. A default makes reason optional.

Pass plain functions in tools=[...]. The agent name must be a Python identifier.

This is the run-it-Monday slide: install google-adk 2.13.0 on Python 3.11 or newer, run adk create, and replace agent.py with this code. Step through the four focus bands: the Annotated Field text becomes the order_id parameter description, the whole docstring becomes the tool description verbatim (ADK does not parse an Args: section), the Literal becomes an enum and the default makes reason optional, and the functions go straight into tools. Analogy: the signature and docstring are the label on a drawer; the model never opens the drawer, it only reads the label. In .env, use GOOGLE_GENAI_USE_ENTERPRISE; the old GOOGLE_GENAI_USE_VERTEXAI still works but raises "DeprecationWarning: GOOGLE_GENAI_USE_VERTEXAI is deprecated, please use GOOGLE_GENAI_USE_ENTERPRISE instead". Likely question: "Where do per-parameter descriptions go if Args: is ignored?" Put them in Field(description=...), and keep the docstring for when to call the tool and what it will not do.
