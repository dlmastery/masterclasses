refund_flow/agent.py · part 1 of 4 · parse_request
from google.adk import Agent, Context, Event, Workflow
from pydantic import BaseModel

ORDERS = {
  "A-1001": {"amount": 89.00, "days_since_delivery": 12, "category": "electronics"},
  "A-1002": {"amount": 1450.00, "days_since_delivery": 41, "category": "furniture"},
}

def parse_request(node_input: str) -> str:
  """'refund A-1001 arrived broken' -> 'A-1001'."""
  order_id = next(t for t in node_input.split() if t.upper().startswith("A-")).upper()
  return order_id
refund_flow/agent.py · part 2 of 4 · check_policy
class RefundCase(BaseModel):
  order_id: str
  amount: float
  days_since_delivery: int
  eligible: bool

def check_policy(ctx: Context, node_input: str) -> RefundCase:
  order = ORDERS[node_input]
  eligible = order["days_since_delivery"] <= 30          # 30-day policy
  ctx.state["refund_case"] = {"order_id": node_input, **order, "eligible": eligible}
  return RefundCase(order_id=node_input, amount=order["amount"],
      days_since_delivery=order["days_since_delivery"], eligible=eligible)
refund_flow/agent.py · part 3 of 4 · write_reply
# {refund_case} reads ctx.state, not the RefundCase on the edge
write_reply = Agent(
    name="write_reply",
    model="gemini-3.5-flash",
    instruction=("You are a refunds agent. Case: {refund_case}. "
                 "If eligible is true, confirm the refund amount. Otherwise "
                 "explain the 30-day policy politely and offer store credit. "
                 "Max 3 sentences."),
    output_key="reply_text",
)
refund_flow/agent.py · part 4 of 4 · audit_log and the graph
def audit_log(reply_text: str):   # bound from ctx.state["reply_text"]
  yield Event(message=f"[audit] reply length={len(reply_text)} chars. "
                      "WORKFLOW COMPLETED.")

root_agent = Workflow(
    name="refund_flow",
    edges=[("START", parse_request, check_policy, write_reply, audit_log)],
)

This is step 1 of the Acme support desk: a refund ticket goes through four nodes in a fixed order. Step 0 is the setup box: install the pinned version, make the folder with an __init__.py that imports agent, and put the Gemini API key in .env. On Windows, create the empty file in your editor or with New-Item instead of touch. Then press through the nodes; each press shows the code for that node only. A plain Python function becomes a FunctionNode, and its type hints become its schemas. check_policy writes refund_case into ctx.state and also returns a typed RefundCase to the next node. The write_reply prompt reads {refund_case} from state, not the RefundCase on the edge, and stores its answer under output_key reply_text. audit_log gets reply_text by name from state, because parameter binding defaults to state, and it yields an Event with a message so adk run prints it. Think of the chain tuple as an assembly line that checks each part fits before the line starts: the Workflow compares the schemas on every edge where both ends declare a type, when you build it. A likely question: "Why yield an Event instead of return?" A plain return only sets the node output, and adk run prints nothing for output-only events. Next slide: follow the data through this run.
