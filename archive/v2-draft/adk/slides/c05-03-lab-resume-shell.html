def issue_refund(order_id: str, final_amount: float, draft: str):
  key = f"refund-{order_id}"        # idempotency key: same on every retry
  yield Event(message=f"REFUNDED ${final_amount:.2f} on {order_id} "
                      f"(idempotency key {key}).\n{draft}")
def notify_rejected(order_id: str):
  yield Event(message=f"Refund for {order_id} rejected by manager.")
root_agent = Workflow(name="refund_approval", edges=[
    ("START", intake, draft_reply, manager_gate),
    (manager_gate, {"approved": issue_refund, "rejected": notify_rejected,
                    "revise": draft_reply}),
])

This is the same refund_approval agent from step 1; the left panel shows the rest of the file, including the idempotency key refund- plus the order id that issue_refund sends. Monday at 10:00 the customer asks for 820 dollars, the gate pauses, adk run saves the session under refund_approval/.adk and exits with code 2, so a script can tell "paused" from "done". On Tuesday the manager answers from a brand-new process: adk run sees the open interrupt in the session and sends the reply as a FunctionResponse with the interrupt id; the note routes to revise, draft_reply writes a new draft, and the gate pauses again with a new id ending in _2, because a revise pass is a new run of the node. The fourth click shows the type trap: replies are JSON-parsed when possible, so the word approve stays a string, 42 becomes an int and true becomes a bool, and ManagerDecision.model_validate rejects all three; only a JSON object becomes a ManagerDecision. The last click separates two ideas people mix up: answering a HITL pause is a new turn and works from adk run with no ResumabilityConfig, because the Runner finds the paused run from the response id; ResumabilityConfig is for continuing an interrupted or crashed invocation from your own Runner code, which step 4 uses and which adk web and adk run do not support. On Windows, cmd needs the inner quotes escaped, and Windows PowerShell 5.1 needs the escaped form inside single quotes. Next, step 3 turns to the payout half: the ACME-GmbH payout and a flaky gateway.
