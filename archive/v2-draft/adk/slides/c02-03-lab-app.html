from typing import Any, Optional
from google.adk import Agent
from google.adk.apps import App
from google.adk.plugins import LoggingPlugin
from google.adk.plugins.base_plugin import BasePlugin
from google.adk.tools import BaseTool, ToolContext
def lookup_policy(policy_number: str) -> dict:
    """Return coverage for a policy number like POL-448120."""
    return {"status": "success", "policy_number": policy_number,
            "collision_deductible_usd": 500,
            "coverage": ["collision", "glass", "liability"]}
class AuditPlugin(BasePlugin):
    def __init__(self) -> None:
        super().__init__(name="audit")
    async def before_tool_callback(
            self, *, tool: BaseTool, tool_args: dict[str, Any],
            tool_context: ToolContext) -> Optional[dict]:
        log = tool_context.state.get("audit_log", [])
        tool_context.state["audit_log"] = log + [f"{tool.name}({tool_args})"]
        return None                         # None: the tool runs
root_agent = Agent(name="claims_assistant", model="gemini-3.5-flash",
    instruction="Answer coverage questions. Always call lookup_policy first.",
    tools=[lookup_policy])
app = App(name="claims_api", root_agent=root_agent,
          plugins=[LoggingPlugin(), AuditPlugin()])

Step 1 extracted the claim. Now a second agent, claims_assistant, answers coverage questions, and we package it as an App with two plugins in agents/claims_api/. The two agents are joined in a later chapter, so for now the user types the policy number. Walk the code top to bottom: the tool returns a dict; the AuditPlugin hook is keyword-only and writes one audit entry into state before every tool call; returning None lets the tool run, and returning a dict would replace the tool result. The App holds the agent and the plugins as one deployable unit. App has three more config fields (events compaction, context cache, resumability) that later chapters use, and it rejects unknown fields. The loader that adk run, adk web and adk api_server share imports agent.py through __init__.py ("from . import agent"); if the module has a variable named app it uses that App and its plugins, otherwise it wraps root_agent. Put the .env file with GOOGLE_API_KEY in agents/claims_api/. At the adk run prompt, type the coverage question; the audit log is visible in the adk web State tab or through the session GET on the next slide. Analogy: the App is a building, and plugins are the security desk in the lobby. Never pass plugins to the Runner: that is deprecated, and with app= it raises; the practices slide repeats this.
