Three errors stop most first runs: names, root_agent and the call cap

Invalid agent name: 'refund-agent'. Agent names must be valid Python identifiers (letters, digits, and underscores only). CauseADK imports the agent folder as a Python package. A hyphen breaks it. FixUse refund_agent for the folder and for name=. Never name an agent user.

These three errors stop most first runs, and all three come from the loader or the runner, not from the model. Steps 1 and 2: ADK imports your agent folder as a Python package and then looks for a variable called root_agent, so a hyphen or a variable named agent fails before any model call. Step 3: the default cap is 500 LLM calls per run; a tool that returns vague errors can make the model retry until it hits the cap. Step 4: set RunConfig(max_llm_calls=20) or ADK_MAX_LLM_CALLS so a loop fails fast and cheap, and log every tool call to see the loop. Analogy: the call cap is a circuit breaker, it protects the bill but it does not fix the wiring. A likely question is "Can I set temperature 0 to stop loops?": no, on Gemini 3 the docs say lower values can cause looping, so keep 1.0.
