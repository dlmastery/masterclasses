Agent Starter Pack still installs, but its README says it is in maintenance mode with critical fixes only, so new projects start with agents-cli, PyPI google-agents-cli 1.11.0. Walk the six commands: setup puts the CLI and the ADK skills into the coding agent, scaffold enhance wraps the existing hr_agent folder with app/agent_engine_app.py, Cloud Build, deployment and tests, then eval run, deploy, infra cicd and publish gemini. The Antigravity loop is the key idea: a Stop hook runs agents-cli eval run and prints decision continue with the reason, so the coding agent does not stop until the evals pass. Analogy: the Stop hook is a quality inspector who sends the box back to the bench. Two Gemini Enterprise rules cause most failures: the app location must match the Agent Runtime region, and the console Model Armor settings do not protect ADK agents, so the plugin stays in code; Gemini Enterprise also passes the user's email to the agent, which the own-salary-only check can use. Likely question: "Is publish the same as the REST registration call?" It registers the same adkAgentDefinition; the docs also show the curl call and the console path. Next: before a new revision takes live traffic, it goes through a canary behind an eval run.
