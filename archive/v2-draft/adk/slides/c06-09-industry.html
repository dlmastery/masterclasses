Uber published its cost program for agentic coding on 2026-08-27, and one line item is the MCP tool schema: about 50K to 70K tokens for 100+ tools, paid on every request before the model reads a word of the task. Their fixes are a gateway that resolves tools through a CLI and on-demand tool search, so the model sees only the tools it needs. Code mode goes further: a script batches tool calls, and one wide-table query fell from 1,431,594 to 900 tokens. Think of a mechanic who carries the whole workshop to every job instead of the two tools the job needs. For Northwind, set tool_filter on every toolset, and above about 50 tools split servers into AgentTool subagents, which matches the MCPacific +12 pp result. A likely question: "Is 50 tools a hard limit?" No, it is a rule of thumb, so measure tokens per request as you add tools. The last slide turns the chapter into ten checks.
