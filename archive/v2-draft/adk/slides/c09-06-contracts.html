from google.adk.apps import App
from google.adk.plugins import BasePlugin

class OutcomeContractPlugin(BasePlugin):
    RECOVERY = {"lookup_order": ["escalate_to_human"]}
    def __init__(self):
        super().__init__(name="outcome_contracts")
    async def after_tool_callback(self, *, tool, tool_args, tool_context, result):
        if tool.name != "lookup_order" or result.get("status") != "success":
            return None
        amount = result.get("amount")
        if isinstance(amount, (int, float)) and amount > 0:
            return None
        return {"status": "error", "violated": "amount > 0",
                "recovery_tools": self.RECOVERY["lookup_order"], "raw_result": result}

app = App(name="refund_agent", root_agent=root_agent,
          plugins=[OutcomeContractPlugin()])
Return None: keep the tool result. Return a dict: it replaces the result.
adk eval and adk web load app from agent.py before root_agent.

import asyncio
from types import SimpleNamespace
from refund_agent.agent import OutcomeContractPlugin

def test_negative_amount_becomes_error():
    bad = {"status": "success", "order_id": "ORD-102", "amount": -79.0}
    out = asyncio.run(OutcomeContractPlugin().after_tool_callback(
        tool=SimpleNamespace(name="lookup_order"), tool_args={},
        tool_context=None, result=bad))
    assert out["recovery_tools"] == ["escalate_to_human"]

Agents watch the error channel, not the content: when a tool says HTTP 503 they notice 91 percent of the time, but when lookup_order returns a well-formed negative amount they notice only 59 percent, and with nothing wrong they raise a false alarm 27 percent of the time (arXiv 2610.10062). Here the harm is real: a refund of minus 79 dollars charges the customer, and our 500 dollar metric still passes it. A prompt line telling the model to check each result did not change detection in the paper, so we put the check in code: an after_tool_callback in a plugin, where returning None keeps the result and returning a dict replaces it. The Outcome Monitors paper (arXiv 2608.19303) shows the receipt must name a recovery tool, here escalate_to_human: on the ToolMaze tool-use benchmark success went from 10.9 to 28.1 percent, and removing the tool list removed the gain. We define app in agent.py because adk eval and adk web look for app before root_agent there. Analogy: a smoke detector wired into the pipe, instead of a note asking the agent to sniff the air. A likely question is "how do I test it without a broken API?": call the callback directly from pytest with the bad dict, as test_contract.py does.
