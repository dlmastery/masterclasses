from google.adk import Agent
from google.adk.agents.context_cache_config import ContextCacheConfig
from google.adk.agents.run_config import RunConfig
from google.adk.apps.app import App, EventsCompactionConfig
from google.genai import types
ROOT_MODEL = "gemini-3.5-flash"       # re-benchmark every few weeks
SUB_MODEL = "gemini-3.1-flash-lite"   # cheaper, if evals pass
bill_lookup = Agent(name="bill_lookup", model=SUB_MODEL)
support = Agent(name="handbook_agent", model=ROOT_MODEL,
    sub_agents=[bill_lookup],
    generate_content_config=types.GenerateContentConfig(
        thinking_config=types.ThinkingConfig(thinking_level="medium")))
app = App(name="bluefin_support", root_agent=support,
    context_cache_config=ContextCacheConfig(
        min_tokens=4096, ttl_seconds=3600),        # 5 min -> 1 h
    events_compaction_config=EventsCompactionConfig(
        token_threshold=400_000, event_retention_size=10))
run_config = RunConfig(max_llm_calls=25)  # loop guard, not a budget
# pass it: runner.run_async(..., run_config=run_config)

Uber writes its AI bill as six terms multiplied together, and every cost lever attacks one term. Users, sessions, turns and requests grew on purpose, so they are greyed out: weekly users went up 7 times and weekly agentic requests 9.4 times from February to August. The levers hit tokens per request and price per token: reasoning effort defaults to Medium, compaction runs at 400K even on 1M-context models, subagents default to a cheaper model, which Uber calls the most impactful lever, and the interactive cache TTL went from 5 minutes to 1 hour because idle gaps kept invalidating the cache. In the ADK code, thinking_level sets the reasoning effort, because Gemini 3 defaults to high, and SUB_MODEL is a Flash-Lite model, kept only if your evals pass. The post gives no spend multiple: it says total AI spend has "relatively stabilized since April", so the spend lane is a flat band with no scale, and cost per 1,000 requests is down almost 34% from the peak. Think of a phone bill: you cannot stop people calling, but you can change the tariff and the length of each call. A likely question: "Why no hard caps?" Hard caps block real work; Uber shows a live cost counter, Slack nudges and an anti-pattern dashboard instead, and in ADK max_llm_calls is only a guard against runaway loops, which you pass to run_async. Chapter 9 turns to evals, so you can prove that a cheaper model or a new compaction setting did not break the answers.
