import pathlib, sys
from google.adk.agents import LlmAgent
from google.adk.tools.mcp_tool import McpToolset, StdioConnectionParams
from mcp import StdioServerParameters
SERVER = pathlib.Path(__file__).parent / "claims_server.py"
def payout_needs_human(**kwargs) -> bool:  # gets the call's args
    return float(kwargs.get("approved_amount", 0)) > 1000
claims_tools = McpToolset(
    connection_params=StdioConnectionParams(
        server_params=StdioServerParameters(
            command=sys.executable, args=[str(SERVER)]),  # same venv
        timeout=10.0),                          # default 5.0 s
    tool_filter=["get_claim", "approve_claim"],  # no purge_claim
    tool_name_prefix="claims",                  # claims_get_claim
    require_confirmation=payout_needs_human,
)
root_agent = LlmAgent(
    name="claims_desk",
    model="gemini-3.5-flash",
    instruction=("You help claims adjusters. Look up a claim before "
                 "approving it. Pay at most the claimed amount."),
    tools=[claims_tools],
)

This is step 2 of the Northwind claims desk: the agent connects to the claims MCP server from step 1 and gets only the tools it needs. Walk the four focus steps. Step 1: use StdioConnectionParams so you can set the timeout to 10 seconds; its default is 5.0 seconds, and a bare StdioServerParameters has no timeout at all. sys.executable starts the server in the agent's own virtual environment. Step 2: tool_filter matches the server's original names, so purge_claim stops at the bar and never reaches the model. Step 3: tool_name_prefix renames the rest to claims_get_claim and claims_approve_claim. Step 4: ADK calls the payout rule with the arguments of the call, so with **kwargs one rule covers every tool; 1,800 dollars is over the limit, and ADK emits adk_request_confirmation before the call runs. On Confirm the tool runs; on Reject the model gets "This tool call is rejected." Note that the rule sees the arguments the model sent: if the model sends 999, no human is asked, which is why the server keeps its own limit (layer 3). Think of a bank teller: some drawers are locked, every drawer has a label, and big withdrawals need a manager's signature. A likely question: "Is the filter enough?" No, other MCP clients can call the server directly, so the server checks amount and role itself. Step 3 adds the claims handbook over streamable HTTP.
