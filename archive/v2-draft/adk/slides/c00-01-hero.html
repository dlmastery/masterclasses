This course is hands-on, and the first picture is the whole idea. Press once: the Workflow graph appears; amber nodes are plain Python functions, which ADK wraps as FunctionNodes for you, and coral nodes are Agent calls (Agent is an alias of LlmAgent). Press again: classify, the only model call on this path, labels the ticket "refund"; pick, plain code, sends that label out as the route, so the model produces a value and code picks the edge. Press again: one refund ticket runs START, intake, classify, pick, refund, audit, and the answer branch is skipped. Last press: refund writes its result to session.state, the dict that all nodes share, and audit reads it from there. ReAct tool loops are not gone: an LlmAgent with tools still works, Lab 1 uses one, and a Workflow puts it inside a graph where it matters. Analogy: the graph is the rail track and the model is a signal operator who reads the ticket; the track decides where the train can go. Likely question: "Is answer a model call too?" Yes, but only on the question path. Next: the same graph in Python.
