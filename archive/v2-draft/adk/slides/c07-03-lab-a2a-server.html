Step 2 of the Acme refund team: the same refund_agent from refund_core.py is now a network service that other teams call over A2A. The server file is three lines: import the shared agent, and wrap it with to_a2a. to_a2a builds a Starlette app, and when the server starts it builds the agent card from the agent: the name and description from the constructor, one skill for the agent itself, whose name is "model", and one skill per tool with the docstring as its description. The card is served without auth, so it copies description and never the instruction. The most common bug is the URL inside the card: to_a2a only writes protocol, host and port into the card, and uvicorn is what binds the socket, so both must say 8001; the default port 8000 is also what adk web uses in step 3. Think of the card as a business card: if the phone number on it is wrong, the caller rings someone else. A likely question: "Is the card JSON exactly this?" The values come from ADK's agent_card_builder.py; the exact A2A 1.0 layout can differ, so read your own curl output. Next, support triage consumes this card with RemoteA2aAgent.
