claims_agent/claims_server.py · adds login · agent-style error
from mcp.server.mcpserver import MCPServer
mcp = MCPServer("claims-server")
CLAIMS = {"CLM-1001": {"policy": "AUTO-77", "status": "open", "amount": 1800.0}}
SESSION = {"valid": False}
@mcp.tool()
def login() -> dict:   # with tool_name_prefix="claims" the agent sees claims_login
    """Start a new claims-system session. Call it when a tool says the session expired."""
    SESSION["valid"] = True
    return {"status": "ok"}
@mcp.tool()
def get_claim(claim_id: str) -> dict:
    """Return policy, status and claimed amount (USD) for a claim id like CLM-1001."""
    if not SESSION["valid"]:
        return {"status": "error", "message": "Session expired. "
                "Call claims_login first, then call claims_get_claim again."}
    return {"status": "ok", "claim_id": claim_id, **CLAIMS[claim_id]}

plugins/agent_errors.py · for servers you cannot edit
import re
from google.adk.plugins.base_plugin import BasePlugin
HUMAN_STEP = re.compile(r"\b(Run|Open|Edit) [^.]*\.\s*")   # human-only steps

class AgentErrorPlugin(BasePlugin):
    def __init__(self):
        super().__init__(name="agent_errors")
    async def after_tool_callback(self, *, tool, tool_args, tool_context, result):
        text = str(result)
        if "error" not in text.lower():
            return None                       # normal results pass through
        cleaned = HUMAN_STEP.sub("", text)    # keep the cause, drop the step
        return {"result": cleaned} if cleaned != text else None
# register once: App(..., plugins=[AgentErrorPlugin()])
45% -> 84% credential recovery (paper) arXiv 2609.35381
An error message is a prompt: the model reads it and tries to do what it says. arXiv 2609.35381 (2026-09-28) audited 3,001 errors from 150 popular MCP servers; 62 of 67 credential steps ask for a terminal command, a config change or a web page, which a tool-only agent cannot do. With a terminal step, mean recovery from an expired credential was 45% (GPT-6 Astra fell to 6%); naming a login tool ("Call ticket_login first.") gave 84%, and naming the call to repeat after a rate limit lifted recovery from 6% to 88%. On our own server we add a login tool and name it the way the model sees it: with tool_name_prefix="claims" that is claims_login, and login must also go into tool_filter. For third-party servers, the AgentErrorPlugin deletes the human-only sentence and keeps the cause, which the paper measured at 82%. Likely question: "Why not just retry in code?" Do both: back off in code for 429s, and still tell the model which call to repeat. Next, the three ways an MCP toolset fails, one of them silent.
