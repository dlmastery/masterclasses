labs/ci/eval_gate.sh · run from labs/
set -euo pipefail                  # google-adk[eval]==2.13.0
export PYTHONPATH=$PWD             # importlib finds refund_policy
CFG=refund_agent/test_config.json
test -f "$CFG" || { echo "missing $CFG"; exit 1; }   # no silent defaults

adk eval refund_agent refund_agent/refund.evalset.json \
  --config_file_path="$CFG" --print_detailed_results | tee eval.log
N=$(grep -c '^Eval Id:' eval.log || true)
test "$N" -eq 2 || { echo "ran $N of 2 cases"; exit 1; }   # update N
grep -q 'Metric: refund_policy_score' eval.log || exit 1

# known-bad: expects issue_refund on ORD-555, so it MUST fail
if adk eval refund_agent refund_agent/known_bad.evalset.json \
     --config_file_path="$CFG"; then
  echo "gate passed a known-bad case"; exit 1
fi
Issue #7258 safety_v1 flip Issue #6951 zero cases pass
All three failures look like success: the pipeline is green, so nobody looks. First: a typo in the config path is not an error; ADK logs "No config file supplied or file not found. Using default criteria." and scores with the defaults, so the 500 dollar rule never runs; the script checks the file first. Second: before 2.13.0 adk eval always exited 0, and a pipe into tee hides the exit code unless pipefail is on, so the script also counts the cases that ran; update that number when you add cases. On the pytest path, before 2.10.0 AgentEvaluator also passed an evalset with zero cases (#6951). Third: safety_v1 resolved to the unversioned latest metric, which became safety_v3 and scores in the opposite direction; this is fixed in 2.10.0, but the behavior also depends on the google-cloud-aiplatform version, so pin both, and keep a known-bad case that must fail. The known-bad file is a copy of the large refund case that expects issue_refund for 820 dollars, so a correct agent fails it. Analogy: test the smoke alarm with smoke, not by looking at the green light. A likely question is "Why does the known-bad case fail?": the correct agent escalates instead of refunding, so the trajectory metric must fail it.
