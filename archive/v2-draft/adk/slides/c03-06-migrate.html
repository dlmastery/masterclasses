support_desk/agent.py · google-adk 2.13.0
from google.adk import Agent, Workflow
from support_desk.tools import lookup_order   # the same tool as in 1.x
intake = Agent(name="intake_agent", mode="single_turn",
               model="gemini-3.5-flash", tools=[lookup_order],
               instruction="Look up the order, then summarize the finding.")
synth = Agent(name="synthesizer_agent", mode="single_turn",
              model="gemini-3.5-flash",
              instruction="Write the customer reply from the intake finding.",
              include_contents="default")      # sees upstream conversation
root_agent = Workflow(name="support_workflow",
                      edges=[("START", intake, synth)])

single_turn: a one-shot worker. task: asks the user for missing slots, then exits typed. chat: free conversation, only right after START.

Repo issue #5780 Docs ADK 2.0 migration
This build step migrates the 1.x Acme support pipeline. SequentialAgent still runs but is deprecated in 2.x, so port it to a Workflow with one chain tuple. Step 1 shows the trap: inside a Workflow, single_turn agent nodes default to include_contents='none', so the second agent gets only its system instruction plus a placeholder user turn, and it answers "Understood. Provide request" (issue 5780). The legend under the code names the three modes: single_turn is a one-shot worker, task asks the user for missing slots and then exits with a typed result, chat is free conversation. Step 2: set include_contents="default" on the node that needs the history, and the ticket text and the intake finding come back. Analogy: the second clerk got a sticky note that says "do your job" instead of the customer's letter. Step 3: make -W error::DeprecationWarning a CI gate so you find every SequentialAgent, ParallelAgent and LoopAgent. Also run the graph through the Runner; never call workflow.run(ctx=...) yourself, because that skips the Runner event-queue consumer that saves tool-call events. A likely question: "Can I keep a chat agent in the graph?" Only right after START; anywhere else you get "GraphValidationError: The agent 'synthesizer_agent' has been added to the workflow with mode='chat' following node 'intake_agent'. This is not supported..." Use task mode when the node must ask the user for missing slots. Next: two gotchas in graph routing and validation.
