# imports, HERE, lookup_order as in Lab 7 step 5, plus:
from google.adk.tools.skill_toolset import SkillLifecycleConfig, SkillLifecycleMode
CATALOG = {"refund-policy": "refund return chargeback prorate"}  # 1 line per folder

def preselect(ticket: str, k: int = 3) -> list:
    words = set(ticket.lower().split())           # swap for BM25 or embeddings
    rank = lambda s: len(words & set(CATALOG[s].split()))
    top = sorted(CATALOG, key=rank, reverse=True)[:k]
    return [load_skill_from_dir(HERE / "skills" / s) for s in top]

def build_agent(ticket: str) -> LlmAgent:
    skills = SkillToolset(skills=preselect(ticket), additional_tools=[lookup_order],
        code_executor=UnsafeLocalCodeExecutor(),
        lifecycle_config=SkillLifecycleConfig(
            default_mode=SkillLifecycleMode.BOUNDED, max_active_skills=3))
    return LlmAgent(name="refund_skill_agent", model="gemini-3.5-flash", tools=[skills])

Two papers from October say that a skill library does not scale by adding folders. Paper 1: with 1,000 irrelevant skills in the library, the agent loads the needed skill only 27.4% of the time, and in about half the tasks it loads nothing at all, which is the zero-load rate; a cheap ranking step in front keeps recall at 73.9%. The paper's advice is to preselect once you pass about 50 skills, so 1,000 is where it fully collapses, not where the problem starts. Paper 2: two skills for the same job do not blend; one takes over and the other's rules disappear, and one merged file with one correct worked example brings compliance back to 96 to 99%. The code builds one short-lived agent per ticket: preselect ranks a one-line catalog and loads only the top 3 folders, and the BOUNDED lifecycle caps active skills at 3. A third paper, arXiv 2608.14036, adds that 65.7% of skill wins come from procedural anchoring, so write skills as procedures. Think of a new hire handed 1,000 binders: they read none, so you hand them the three that matter today. A likely question: "Is EAGER discovery enough?" EAGER puts the catalog into the system instruction up front instead of behind list_skills; with a large catalog you still preselect.
