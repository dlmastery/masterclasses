Interview drill: choose the right connector, payload and transport

Another team owns billing. Do you connect to it with MCP or A2A?
Ask what they expose. If they expose tools and data that you call as typed functions, use MCP (McpToolset with a tool_filter). If they expose an opaque agent with its own model, memory and policy that takes tasks, use A2A (RemoteA2aAgent on your side, to_a2a on theirs).
Why store a generated image as an artifact, not in state or in the history?
State is small JSON that is written into every event. History sends the bytes again on every turn. An artifact is a versioned Part in GCS. The model sees a filename, and load_artifacts attaches the bytes to one request only when the model needs them.
How do you keep a live voice session running for one hour?
Enable context_window_compression: it removes the 15-minute audio and 2-minute audio + video caps. Enable session_resumption: it survives the ~10-minute connection resets. Handles stay valid for 2 h, and ADK retries up to 5 times. Add your own cost budget, because max_llm_calls does not cap run_live.
Why must the user identity come from trusted state, not from a tool argument?
Prompt injection can change the arguments that the model writes. Read the identity from session state in a before_tool_callback (the validate_tool_params pattern on adk.dev/safety). Block the call when the argument does not match.

Ask each question, let the room answer, then press to show the model answer. Question 1 tests the core distinction of the chapter: MCP gives you transparent functions, and A2A gives you a peer that you cannot see inside. Question 2 is about cost and correctness: binaries in history are resent and billed on every turn, and state is the wrong store for bytes. Question 3 has three numbers that interviewers like: 10 minutes per connection, 15 minutes for audio and 2 minutes for audio plus video without compression. Question 4 is a security question: treat every model argument as attacker-influenced, the same way you treat form input in a web app. Analogy for question 4: a bank teller checks your ID card, not the name you say.
