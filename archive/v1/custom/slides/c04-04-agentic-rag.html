Left is the pipeline from the previous slides: one retrieval, one LLM call. Right is the agentic loop from the Singh et al. survey (arXiv 2501.09136, v4 April 2026). Step 2: the agent plans sub-questions. Step 3: it picks a tool — vector search, SQL, web or an API — and retrieves. Step 4: it reflects; the evidence is not enough, so it loops and re-queries with another tool. Step 5: the evidence is enough, so it answers with citations. Watch the counter: the loop costs 2 to 10 times more LLM calls and latency than the one-shot pipeline. Analogy: one-shot RAG is a single library search; agentic RAG is a research assistant who keeps searching until the case is closed. Step 6 links this to context engineering and to RL: Genspark trained its agent with RFT and it made 33% more tool calls with 10% higher quality. Likely question: "How do you stop the loop?" Set a maximum number of hops and a token budget, and let the reflect step return a calibrated "enough evidence" decision.
