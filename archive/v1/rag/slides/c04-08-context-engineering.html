Definition: "the set of strategies for curating and maintaining the optimal set of tokens (information) during LLM inference." LangChain (2 Jul 2025) names four buckets: Write, Select, Compress, Isolate. RAG is Select. Sub-agents return "a condensed, distilled summary of its work (often 1,000-2,000 tokens)".

Just-in-time retrieval: the agent keeps "lightweight identifiers (file paths, stored queries, web links, etc.)" and loads the content through tools when it needs it. A hybrid strategy loads some data up front and lets the agent explore the rest (suited to legal or finance work).

Load agent skills the same way: by identifier, just in time.

Practitioners: Hamel Husain and Ben Clavié ("Stop Saying RAG Is Dead"): naive single-vector search is dead, retrieval is not. Bischof and Chaurasia: "Stop searching for the perfect embedding. Build specialized representations and route intelligently."

Post Anthropic: context engineering Post LangChain
Context engineering is the 2025 frame that replaced prompt engineering: the job is to choose which tokens the model sees, and RAG is only one of four ways to do it. Select brings in retrieved chunks; Compress replaces a long trace with a short summary; Isolate gives each sub-agent its own window and brings back only 1,000 to 2,000 tokens; Write keeps notes outside the window so the agent can read them later. The last step is just-in-time loading: the agent holds cheap identifiers such as a path, a stored query or a link, and pays for the content only when a tool call loads it. Skills and long instructions work the same way: keep a short index in the prompt and load the full text on demand. Analogy: a chef keeps the recipe names on the wall and takes a recipe card from the drawer only when an order needs it. Likely question: "Is RAG dead?" No; naive single-vector top-k is out of date, but selecting evidence is now a core part of every agent.
