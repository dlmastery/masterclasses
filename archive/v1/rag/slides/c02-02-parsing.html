parse.py · Docling README quickstart

from docling.document_converter import DocumentConverter

source = "https://arxiv.org/pdf/2408.09869"  # local path or URL
converter = DocumentConverter()
result = converter.convert(source)   # layout, tables, OCR
md = result.document.export_to_markdown()  # -> Markdown
print(md)
# CLI: default pipeline, then the GraniteDocling VLM
# $ docling https://arxiv.org/pdf/2206.01062
# $ docling --pipeline vlm --vlm-model granite_docling <url>

Show the same illustrative page three ways. Step 1: pdftotext reads straight across the page, so the two columns interleave and the table becomes a row of loose numbers. Step 2: a layout parser such as Docling keeps the reading order and writes a real Markdown table. Step 3: a VLM tier (GraniteDocling, LlamaParse agentic, Gemini) reads charts, but it costs more per page, so route only the hard pages to it. Steps 4 to 6 walk the Docling quickstart: convert, export to Markdown, then the CLI with the VLM pipeline. Analogy: a photocopy of a newspaper read left to right across both columns. Likely interview question: "When do you pay for VLM parsing?" Answer: when tables, charts or scans carry the answer; measure retrieval on those pages before and after.
