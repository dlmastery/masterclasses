from google import genai
client = genai.Client()
q = client.models.embed_content(
    model="gemini-embedding-2",
    contents="task: question answering | "
             "query: What is late chunking?",
    config={"output_dimensionality": 768})  # MRL
d = client.models.embed_content(
    model="gemini-embedding-2",
    contents="title: Late Chunking | "
             "text: Late chunking pools ...",
    config={"output_dimensionality": 768})

Start with the picture: every chunk is a point, and the query is a new point in the same space. The index returns the five chunks with the smallest angle to the query, which is the highest cosine similarity. Then walk the table. The 001 paper reports an MMTEB mean of 68.32, 5.09 points above the next model; Qwen3-Embedding-8B was #1 on MMTEB on 5 Jun 2025 with 70.58, and it has open weights. Gemini Embedding 2 is the new default on Google because it puts five modalities in one space, but it uses text prefixes, not task_type, and it cannot share an index with 001. Analogy: two embedding models are two maps with different projections; a coordinate from one map points to the wrong place on the other. Likely question: "Which model is best?" Answer: the leaderboard sub-boards disagree and some vendors do not submit, so build a golden set from your own queries and measure recall@k before you choose.
