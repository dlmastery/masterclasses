  • 01Measure first. Build a 100–500 item golden set. Gate every merge in CI (RAGAS, LangSmith experiments, adk eval).
  • 02Parse well. Use a layout parser for the bulk and a VLM tier for hard pages.
  • 03Chunk simply. Start with ~200-token recursive or structure-aware chunks. Add Contextual Retrieval.
  • 04Retrieve hybrid. Run BM25 + dense search and fuse the lists with RRF (k = 60).
  • 05Rerank. Cut ~150 candidates to ~20. Send few chunks. Put the best chunks first and last.
  • 06Skip the index when you can. Under ~200k static tokens, cache the whole corpus in the prompt.
  • 07Workflows before agents. Use a router, Adaptive-RAG or a corrective loop with max_iterations. Budget multi-agent search at ~15x tokens.
  • 08Load context just in time. Keep knowledge, instructions (skills) and tool context behind identifiers. Load them when a step needs them.
  • 09Trust nothing retrieved. Treat retrieved text and MCP tool output as data. Filter ACLs inside the query. Remove PII at ingest.
  • 10Operate it. Trace on OpenTelemetry. Set freshness SLOs. Re-embed blue/green.

This is the one slide to photograph. Step 1 is the lifecycle: a golden set, a CI gate, shipping with traces, online judges plus user feedback, human labels that recalibrate the judge, and red-teaming that feeds new cases back into the golden set. Step 2 is the ordered checklist. The order matters: measurement comes first, because every later choice (chunk size, hybrid weights, reranker, agents) is a guess without it. Item 7 answers the "workflows" question: a workflow is a fixed code path with LLM steps, so it is cheaper to test, trace and cap than an autonomous agent. Item 8 answers the "skills" question: load instructions and knowledge just in time by identifier, the same principle as retrieval. Step 3 lists what is still open in October 2026: how to evaluate agentic and deep-research systems, the lack of agent trajectory data, the token cost of multi-agent search, injection through tools and MCP, when graphs pay off, and context rot at very long inputs. Step 4 gives the best next resources. Analogy: the checklist is a pilot's pre-flight list; skipping item 1 is flying without instruments. Likely question: "If I can do only three things this week?" Build the golden set, add hybrid search with RRF, and add a reranker.
